## 0. 本次定位变更

| 项 | 旧（Demo） | 新（正式） |
|---|---|---|
| 性质 | 验证性 Demo | **正式游戏第一阶段** |
| 进化语义 | 达阈值 → 进入下一阶段 | **局内突变构筑节点**，不离开细胞阶段 |
| 阶段范围 | 细胞→器官→生物 三段 | **只做细胞阶段，做到内容巨大** |
| 单局时长 | 25-30 分钟 | **约 60 分钟** |
| 内容量 | 12 张卡 / 5 敌人 | **卡牌 120+ / 敌人 30+ / 主动技能 28 / 词缀 32** |
| 代码 | 独立场景 demo，不接主流程 | **接入正式 GameApp 流程，模块化框架** |
| 战斗规模 | 数十敌人，逐个 GameObject | **数千至上万敌人，数据导向内核** |

一句话定位：

`在一小时的微观生态战场中，用吞噬与突变把一个漂流细胞培养成能改造整片生态的原核霸主。`

**每个大阶段一小时**是全项目统一标准。细胞阶段是第一个按此标准做满的阶段，也是后续所有阶段的框架样板。

## 1. 产品承诺

1. 细胞阶段是一个**可独立成立的完整游戏模式**，不是教程。
2. 进化是**局内构筑节点**，一局内会触发 20 次以上。
3. 同样一局细胞阶段，不同卡组形成**明显不同的生存方式**，而不是数值高低差异。
4. 一小时体验有清晰弧线：**求生 → 立足 → 争夺 → 支配 → 灾变 → 加冕**。
5. 内容量足够支撑重复游玩：单局只能见到全部内容的 20% 左右。

---

## 2. 设计支柱

- **吞噬是核心动词**
  资源、体积、突变、构筑机会全部由吞噬驱动。任何新机制都要回答"它如何改变吞噬"。

- **进化是局内构筑**
  进化节点只改变能力、生态关系与规则，不切换阶段。

- **肉鸽来自机制组合**
  卡牌优先改变**行动后果、资源转化、敌我关系、环境规则**。纯数值卡占比不超过 15%。

- **一小时必须有阶段感**
  细胞阶段内部分 6 个生态时期，每期换敌人、换事件、换卡池、换压力类型。

- **内容巨大但系统复用**
  大量内容由**卡牌 × 词缀 × 敌人行为参数 × 事件**组合产生。不为单张卡做独立系统。

- **反支柱**
  不做纯数值堆叠；不做需要读长文本才能理解的卡；不做只在 UI 上变化的"假构筑"；不做一局内必须查表才能玩的复杂度。

## 3. 单局节奏（60 分钟）

| 时间 | 生态时期 | 玩家体验 | 核心压力 | 敌人规模 |
|---|---|---|---|---|
| 0:00-8:00 | `原生漂流期` | 熟悉移动、吞噬、体积判定 | 大型威胁、危险区 | 80-200 |
| 8:00-18:00 | `初次突变期` | 拿到首批突变卡，方向成型 | 食物竞争、追猎者 | 200-500 |
| 18:00-30:00 | `生态争夺期` | build 开始联动，敌人特化 | 群体围堵、资源稀缺 | 500-1500 |
| 30:00-45:00 | `异化扩张期` | 污染、筑巢、召唤、连锁放电 | 精英细胞、生态反扑 | 1500-4000 |
| 45:00-56:00 | `微观灾变期` | 高强度事件轮换，build 完全体 | 多源压力同时出现 | 4000-10000 |
| 56:00-60:00 | `原核霸主战` | 最终压力测试 | 首领 + 环境崩坏 | 首领 + 3000+ |

敌人规模是**框架设计目标**，实际由压力预算动态调节（见 §9）。规模抬升本身就是"从猎物到霸主"的表达。

## 4. 核心循环

```
短循环（秒级）
  移动 → 判断能否吞噬 → 吞噬/规避/反击 → 吸收营养质与进化能

中循环（1-3 分钟）
  积累进化能 → 升级 → 3 选 1 突变卡 → 改变玩法规则 → 继续积累

长循环（8-12 分钟）
  推进生态时期 → 解锁新卡池/敌人/事件 → 击败时期精英 → 进入下一时期
```

## 5. 资源系统

| 资源 | 用途 | 来源 | 消耗 |
|---|---|---|---|
| `生命值` | 生存 | 吞噬、再生、卡牌 | 受击、毒区、透支卡 |
| `营养质` | 局内货币：刷新、补给、修复 | 食物、尸体、事件 | 商店、事件、修复 |
| `突变质` | 稀有构筑资源：升级卡、锁定路线 | 精英、事件、特殊食物 | 强化突变、移除负面 |
| `进化能` | 经验条，满则升级选卡 | 吞噬、击杀、事件、碎片 | 达阈值清空并提高阈值 |
| `污染度` | 高风险强度资源，越高越强越危险 | 异化卡、污染事件 | 触发灾变、解锁高阶卡 |
| `体积` | 决定可吞噬对象与被吞噬风险 | 吞噬成长 | 受击、分裂、脱壳 |

`体积` 是本阶段独有的核心状态量：它同时是攻击力、防御力和移动惩罚。变大让你能吃更多，但也更慢、更容易被大型目标锁定。多数卡牌围绕"如何绕过体积限制"设计。

## 6. 进化节点（局内构筑）

### 6.1 触发方式

- `进化能` 达到当前阈值（主要来源）
- 吞噬高价值目标直接获得大量进化能
- 击败精英细胞 → 精英进化
- 完成生态事件 → 事件奖励选择
- 进入新生态时期 → 一次保底选择

### 6.2 选择形式

| 类型 | 形式 | 说明 |
|---|---|---|
| 常规升级 | 3 选 1 | 主要构筑来源 |
| 精英进化 | 4 选 1 | 至少 1 张稀有及以上 |
| 污染进化 | 3 选 1 | 卡强但附带代价 |
| 修复进化 | 2 选 1 | 低血/弱构筑补偿，保底机制 |
| 遗产进化 | 3 选 1 | 45 分钟后，原核遗产卡 |

### 6.3 升级阈值曲线

```
threshold(n) = base * pow(growth, n) + linear * n
base = 100, growth = 1.115, linear = 18
```

配合各时期进化能产出，形成目标频率：

| 时间段 | 目标升级间隔 | 累计升级次数 |
|---|---|---|
| 0-10 min | 60-90 秒 | 7-9 |
| 10-30 min | 90-150 秒 | 16-20 |
| 30-50 min | 150-210 秒 | 22-27 |
| 50-60 min | 210+ 秒 | 24-30 |

一局结束时玩家通常持有 **24-30 张卡**、**3-5 个主动技能**、**1-2 条路线核心机制**、**1-2 个明显代价**。

### 6.4 卡池解锁

| 生态时期 | 新增卡池 |
|---|---|
| 原生漂流期 | 基础吞噬、基础机动、基础生存 |
| 初次突变期 | 六条路线核心卡 |
| 生态争夺期 | 稀有卡、跨路线联动卡 |
| 异化扩张期 | 电化连锁、尸体联动、强控制 |
| 微观灾变期 | 异化卡、污染代价卡、终局补强 |
| 原核霸主战前 | 原核遗产 |

## 7. 六条路线

每条路线有**核心机制**（改变规则）、**资源引擎**（自我循环）、**终局形态**（完全体表现）。

### 7.1 吞噬扩张 `Devour`
- 核心机制：`破体` 降低吞噬体积门槛；尸体可二次吞噬
- 资源引擎：连吃层数 → 吞噬收益递增
- 终局形态：滚雪球巨型细胞，正面碾压
- 关键词：变大、撕裂、吞噬阈值、尸体回收、压迫

### 7.2 机动猎食 `Agile`
- 核心机制：`标记` + 冲刺穿体；位移即输出
- 资源引擎：冲刺命中返还体力 → 连续冲刺
- 终局形态：全屏高速穿刺，敌人无法集火
- 关键词：冲刺、残影、标记、穿体、风筝

### 7.3 电化统治 `Electric`
- 核心机制：`导电` 状态 + 电弧连锁传播
- 资源引擎：体力溢出转电荷 → 强化下次放电
- 终局形态：全场导电网络，一次放电清屏
- 关键词：放电、导电、连锁、电荷、过载

### 7.4 孢子繁殖 `Spore`
- 核心机制：部署附属体，战场替你工作
- 资源引擎：附属体击杀返还能量 → 更多附属体
- 终局形态：数百附属体组成的自走军团
- 关键词：孢子、分裂、召唤、感染、群体

### 7.5 菌毯筑巢 `Nest`
- 核心机制：改造地形，菌毯区域改变双方规则
- 资源引擎：菌毯面积 → 回复与吞噬收益
- 终局形态：把半张地图变成自己的生态位
- 关键词：领地、菌毯、锚点、回复、地形

### 7.6 异化污染 `Corrupt`
- 核心机制：`污染度` 作为可投入的强度资源
- 资源引擎：污染度越高卡效果越强，但生态压力同步上升
- 终局形态：霸主形态，用生命换取压倒性输出
- 关键词：污染度、代价、灾变、强突变、不可控

**路线不是排他的**。玩家可混搭；跨路线联动卡是稀有卡的主要设计方向。

## 8. 卡牌系统

### 8.1 稀有度

| 稀有度 | 占比 | 设计要求 | 一局出现 |
|---|---:|---|---|
| `普通` Common | 40% | 效果清晰，直接改变一次行动后果 | 大量 |
| `稀有` Rare | 33% | 至少与两类系统产生组合 | 中等 |
| `史诗` Epic | 17% | 改变一条路线的运作方式 | 少量 |
| `异化` Aberrant | 8% | 强机制变化 + 明确副作用 | 稀少 |
| `原核遗产` Legacy | 2% | 定义整局策略，45 分钟后出现 | 1-2 张 |

### 8.2 卡牌结构（数据模型）

每张卡是**触发器 + 效果列表 + 词缀**的组合，不写独立逻辑：

```
CardSpec {
  Id, Name, Route, Rarity, UnlockPhase
  MaxStack          // 可叠加层数
  Triggers[]        // OnDevour / OnKill / OnHit / OnDash / OnTick / OnLevelUp / OnZap / OnLowHp ...
  Effects[]         // 数据化效果：加属性 / 施加状态 / 生成实体 / 改规则 / 转化资源
  Affixes[]         // 词缀，见 §8.4
  Cost { Pollution, Drawback }
  SynergyTags[]     // 用于抽卡权重与推荐联动展示
}
```

这使"内容巨大"成为**配表工作**而非编码工作。新增卡牌 = 加一行 Luban 配置。

### 8.4 词缀池（32 条）

词缀附加在卡牌与事件奖励上，是内容量的乘数。

| 词缀 | 效果方向 | 词缀 | 效果方向 |
|---|---|---|---|
| `增殖` | 生成更多附属体/残块 | `导电` | 与电系联动 |
| `腐蚀` | 持续削弱体积/护壳/速度 | `回流` | 返还体力/冷却/营养 |
| `裂变` | 结束时生成次级效果 | `拟态` | 复制上次触发的弱版 |
| `饥饿` | 低资源时更强 | `稳态` | 静止/筑巢时更强 |
| `过载` | 强化但自损 | `共生` | 附属体越多本体越强 |
| `贯穿` | 效果穿透目标 | `弹射` | 命中后跳向下一目标 |
| `滞留` | 留下持续区域 | `引力` | 拉拽附近目标 |
| `恐惧` | 逼退小型敌人 | `标记` | 施加易伤标记 |
| `寄生` | 附着并持续削弱 | `虹吸` | 转化敌方资源 |
| `硬化` | 提高受击阈值 | `蜕变` | 受击时转换形态 |
| `连锁` | 触发次数递增 | `共振` | 多目标间互相加成 |
| `淤积` | 效果延迟但加倍 | `催化` | 缩短其他冷却 |
| `分食` | 大目标死亡裂成小块 | `孵化` | 延迟生成友方单位 |
| `晶化` | 命中累积破碎层数 | `潮汐` | 周期性强弱交替 |
| `噬骨` | 对高体积目标增伤 | `游离` | 效果可脱离本体存在 |
| `逆熵` | 消耗污染度换取回复 | `献祭` | 消耗自身资源大幅强化 |

### 8.5 抽卡权重规则

```
weight = baseWeight(rarity)
       * phaseUnlockGate
       * routeAffinity(玩家已有卡的路线分布)      // 1.0 ~ 1.8，鼓励成型
       * synergyBonus(与已有卡的 SynergyTags 交集) // 1.0 ~ 1.5
       * antiDupePenalty(已达 MaxStack 则为 0)
       * pityBonus(连续未出稀有则提高)
```

- 保底：连续 4 次未出稀有及以上，第 5 次强制稀有。
- 低血保底：生命 < 30% 时，选项池注入至少 1 张生存向卡。
- 路线亲和让 build 能成型，但上限 1.8 倍避免锁死。

## 9. 敌人与刷怪

### 9.1 压力预算系统

刷怪不写死数量，而由**压力预算**驱动：

```
budget(t) = phaseBase(t) * difficultyCurve(t) * playerPowerFactor
playerPowerFactor = f(卡牌数, 属性总量, 击杀速率, 当前生命)
```

导演从当前时期的可用敌人池中，按 `cost` 采购敌人直到填满预算。这让：
- 强 build 自动遇到更多/更硬的敌人（动态难度）
- 弱 build 不会被压死（保底下调）
- 新增敌人 = 加一行配置 + 一个 `cost`

### 9.4 首领：原核霸主（3 阶段）

## 14. 与后续阶段的接口

细胞阶段虽然独立成立，但必须为多阶段留出继承接口（框架层面见 `Game_Framework_Design.md` §7）。

细胞阶段结束时产出 `StageOutcome`：

```
StageOutcome {
  StageId = Cell
  DominantRoute      // 主导路线
  RouteScores[]      // 六路线得分分布
  KeyCards[]         // 定义性卡牌（史诗/异化/遗产）
  FinalStats         // 最终属性快照
  PollutionLevel     // 污染度终值
  Achievements[]     // 局内达成
  Statistics         // 统计数据
}
```

后续器官/生物阶段读取此结构决定起始能力池，**但细胞阶段本身不依赖任何后续阶段存在**。当前版本 `StageOutcome` 只用于结算展示与图鉴解锁。

## 16. 设计风险与控制

| 风险 | 表现 | 控制办法 |
|---|---|---|
| 一小时中段乏味 | 25-40 分钟"已成型但未完全体"的平台期 | 生态事件密度在此区间提高；异化卡在 30 分钟解锁 |
| 卡牌过多导致不可读 | 玩家不知道自己在干什么 | 路线亲和权重让 build 收敛；HUD 显示路线分布 |
| 内容巨大但同质 | 135 张卡里 100 张是数值卡 | 强制纯数值卡 ≤ 15%；每张卡必须回答"它如何改变吞噬" |
| 万敌规模下可读性崩坏 | 玩家看不清自己在哪 | 敌人视觉分层（体积/颜色/轮廓）；玩家单位始终最高对比度 |
| 动态难度被滥用 | 玩家故意压制自己 build 换低难度 | 压力预算下限随时间硬性抬升，playerPowerFactor 只影响上浮部分 |
| 阶段框架为细胞阶段特化 | 后续阶段无法复用 | 内核只认"agent + 数据"，不认"细胞"；见框架文档 |
| 反应组合数爆炸导致数值失控 | 某两个词缀叠加秒杀首领，或完全无感 | 反应表逐条打表评审，非公式自动生成；首批仅 6 条，Play 冒烟实测后再扩 |
| 催化卡让强力词缀过滥 | "全场导电"之类过滤范围太宽，替代原有构筑深度 | 催化卡过滤条件必须收窄到 Trigger 或单一 SynergyTag，不允许无过滤"全局加词缀" |

## 17. 战斗化学反应系统（反应矩阵 / 催化卡 / 反应连锁）

> **Status: Superseded（2026-08-11）** — 实现与派工 **禁止** 以本节为准。  
> **新权威**：`DesignDocs/最新改动需求/AUTHORITY_AND_CONFLICTS.md` → 冻结总案 + `化学引擎-ClaudeCode需求规格.md` 等。  
> **原因**：旧案是「Status×Status + 催化注入 Affix」挂在现有热更 StatusSystem；新案是做法 C 的独立 ChemEngine（Packet/管道/基元，零 Unity 核心）+ 代谢切片双系统。二者不可并行实现。  
> 下文整节仅作历史对照；冲突表见 `AUTHORITY_AND_CONFLICTS.md` §2。已存在的 `ReactionSystem.cs` 半成品 **勿继续扩**，接入时另窗审计。

### 17.1 反应矩阵 ReactionMatrix

**规则**：当一个效果对某目标施加一个新状态时，若目标身上已经存在另一个（不同的）活跃状态，且这两个状态在反应表里登记了一条规则，则触发一次数据驱动的**二级效果**（复用现有 `EffectSpec` / `IEffectExecutor` 调度，不新增执行链路）。

```
ReactionRule {
  Id
  StatusA, StatusB      // 无序对；两个状态都在目标身上时命中
  ResultEffect          // 复用 EffectSpec：二级效果内容
  ConsumeMask           // 触发后清除哪些状态（0 = 都不清）
  Cooldown              // 同一目标 + 同一反应对的最短触发间隔，防止刷屏
}
```

初版 6 条（覆盖多路线交叉，验收基准）：

| 反应对 | 效果 | 呼应路线 |
|---|---|---|
| 导电 × 腐蚀 | "电解"：下次电伤翻倍，并把腐蚀沿电弧连锁传染给下一目标 | Electric × Devour/Nest |
| 导电 × 过载 | "殉爆"：目标原地爆炸，过载状态被消耗 | Electric × Corrupt |
| 晶化(3 层) × 任意物理命中 | "碎裂"：额外真实伤害 + 0.4s 硬直，晶化层数清零 | 通用 |
| 标记 × 恐惧 | "溃逃踩踏"：逃跑中的标记目标撞击路径上的其他敌人造成小范围伤害 | Agile × Corrupt |
| 寄生 × 破体 | "破巢"：寄生目标直接跳过吞噬体积门槛 | Devour |
| 腐蚀(滞留区域内) × 导电 | 区域内所有腐蚀单位一起触发一次电弧连锁 | Nest × Electric |

**判定时机与性能**：挂在 `StatusSystem.ApplyTimed` / `ApplyTimedArea` 施加新状态的那一刻查表一次（O(1)，不是逐帧扫描），符合 `Game_Framework_Design.md` §5.6 "热更层每帧与敌人数无关"的红线。`Main/Sim` 只在状态位不够用时加纯数据位（`SimStatus` 目前 32 位用了 13 个，位空间充足），**反应判定逻辑本身不进内核**。

### 17.2 催化卡 Catalyst Card

一种新卡类别：**不带自己的 `Effects`**，而是登记一条"词缀挂载规则"，运行时动态注入到其他卡/技能匹配的效果上：

```
CatalystRule {
  FilterTrigger        // 可选：只挂载到指定 Trigger（OnHit / OnDevour / ...）的效果
  FilterSynergyTag      // 可选：只挂载到带指定 SynergyTag 的卡
  FilterRoute            // 可选：只挂载到指定路线的效果
  InjectAffix            // 注入的词缀（§8.4 已有词缀池，不新增词缀种类）
}
```

过滤条件**必须**至少收窄到 Trigger 或单一 SynergyTag 之一（§16 风险控制），不允许"全场所有效果都加词缀"这种无过滤规则。

首批 6 张（每张都便宜、单独拿到时几乎无效，价值完全来自"和什么卡搭"）：

| 卡名 | 规则 |
|---|---|
| 带电体液 | 所有 `OnHit` 效果获得【导电】 |
| 溶解外壳 | 所有近战效果获得【腐蚀】 |
| 共振腔 | 所有电化路线效果获得【共振】 |
| 捕食反射 | 所有 `OnDevour` 触发的效果获得【回流】 |
| 冰晶膜 | 所有持续伤害类效果获得【晶化】 |
| 群体信息素 | 所有 `Spawn` 效果获得【共生】 |

### 17.3 反应连锁 OnReaction（深度构筑，第三优先级）

反应矩阵每次成功触发时广播一次 `ReactionEvent{TargetId, ReactionId, StatusA, StatusB}`。新增 `OnReaction` 触发器种类（追加进 §8.2 `Triggers[]` 枚举），卡牌可以订阅"反应本身"，例如"每次发生反应，回复 2 营养质"或"反应命中范围内额外施加一次弱化晶化"。

这一层让反应结果本身变成可以被叠加/强化的资源，形成"反应触发新反应"的深层连锁——是组合出"意料之外的化学反应"的最上层，放在反应矩阵与催化卡都验证过手感之后再做。

### 17.4 与现有系统的边界

- 不新增词缀种类、不新增效果 `Kind`——反应矩阵和催化卡都是**已有 32 词缀 + 9 类效果**的重新组合方式，符合"内容巨大是配表工作"的原则。
- 表现（爆炸特效、电弧连线等）复用 `story-002`/`story-010` 已建立的可插拔 Presenter，判定逻辑里不夹带任何 VFX 调用。
- 首版范围内**不**引入元素强度衰减/槽位类系统（如"每回合反应次数上限"之外的复杂经济），避免一次性做成不可平衡的系统；这些留作 P2 按实测数据决定是否需要。
