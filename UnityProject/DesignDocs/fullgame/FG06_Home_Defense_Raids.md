## 1. 玩家目的

- 偏经营的玩家：设计出**自己会打出连锁反应**的防线，突袭来了只需要开倍速看它运转。
- 偏战斗的玩家：突袭时接入炮塔或驻防机器，亲自上阵。
- 所有玩家：远征时家园遇袭，要面对"回去守，还是继续远征"的抉择。

## 3. 需求

### 3.1 炮塔

**FGR-DEF-001 炮塔是固定底盘的机器**
- 炮塔在数据上是一台机器：底盘为"固定底盘"，有蓝图（作战组件、3×3 电路、常规固件、可选的接入口）。
- 炮塔像建筑一样放置和施工，占地由作战组件决定（**初值：轻型 2×2，重型 3×3**）。
- 有耐久、热量、耗电。出现在机器名册的"炮塔"分类里，不能参加远征。
- 组件兼容规则见 FGR-FW-012（冲刺器不能装在炮塔上）。

**FGR-DEF-002 射界与射程**
- 默认 360° 旋转，转速由组件决定。射程由组件决定。
- 己方屏障不阻挡己方炮塔的弹道（炮塔越过墙射击）。
- 放置时预览射程范围。

**FGR-DEF-003 目标模式（玩家设定）**
- 模式：最近、最高威胁、精英优先、最低耐久、优先攻击正在破坏建筑的敌人。
- 可以逐座设置，也可以批量设置。炮塔**只按玩家选的模式选目标**，不做额外判断。

**FGR-DEF-004 补给**
- 所有炮塔从电网取电。
- 带流体类固件的炮塔需要接管线，消耗对应流体（例如"漏油"消耗燃油）。
- 补给不足时停火，并给出原因（"缺燃油"）。

**FGR-DEF-005 接入炮塔**
- 带接入口的炮塔可以被玩家接入，插入核心固件（FG01）。炮塔不能移动，但玩家可以亲自瞄准。

### 3.2 其他防御建筑

**FGR-DEF-010 屏障**
- 1×1，可以拖拽建造，三个等级，耐久递增。

**FGR-DEF-011 闸门**
- 己方单位可以通过；对敌人等同于屏障。
- 只对己方单位开启，这是明确写死的规则，不是智能判断。

**FGR-DEF-012 护盾发生器**
- 圆形护盾，吸收弹体；耗电随承受的伤害上升。
- 护盾值耗尽时进入过载，关闭一段时间（**初值：20 秒**）后重启。

**FGR-DEF-013 陷阱发射器**
- 按装配的固件，在一条线或一片区域上持续铺设场地效果，例如油膜带、冷却液带、电磁场。
- 靠管线供给流体，靠电网供电。
- 用来和炮塔组合出阵地反应，例如"漏油带 + 燃迹炮塔 = 火墙"。

**FGR-DEF-014 维修无人机站**
- 在覆盖范围内，自动修理建筑、炮塔和屏障，消耗维修件。
- 突袭时优先修理正在受攻击的目标。无人机是可见的实体，可能被击落，击落后由站点重新生产。

**FGR-DEF-015 自动重建**
- 被摧毁的建筑、炮塔、传送带、管线原地留下带设置的虚影。
- 开启"自动重建"规则的区域，材料到位后由机器按原样重建。

### 3.3 突袭导演

**FGR-DEF-020 触发**

| 触发 | 说明 |
|---|---|
| 暴露阈值 | 30、60、90 分别对应 1、2、3 级突袭；超过 90 后，周期性发生 4 级突袭 |
| 剧情节点 | 例如击败某阵营首领后，该阵营发动报复突袭 |
| 静默夜 | 每次静默夜必定发生突袭（FG07） |
| 巨构阶段完工 | 第三幕，每个阶段完工触发一次（FG11） |
| 化工净化塔针对 | 化工阵营优先袭击净化塔（FG09） |
| 低强度骚扰 | 小规模侦察骚扰，有频率上限 |

- 两次突袭之间至少间隔 1 个游戏日（剧情突袭除外）。

**FGR-DEF-021 预算与编成**
- 预算 = 等级基础值 × 幕系数 × 难度系数 × 间隔系数（距离上次突袭越久越大）。具体公式在 FG16。
- 从所选阵营的突袭编成表里，按单位点数凑满预算。
- 阵营选择："最受刺激"的阵营，也就是暴露贡献最多的阵营（使用它的技术、摧毁它的节点）。暴露面板显示各阵营的贡献。

**FGR-DEF-022 反制**
- 突袭编成会针对玩家防线里用得最多的反应或固件类别，但只在该阵营自己的技术树内选择对策（沿用 GDD:293 原则）。
- 情报面板可以提前看到这次突袭会针对什么（需要监听站）。

**FGR-DEF-023 出发地与行进**
- 突袭部队从所选阵营**离目标最近的活跃据点**出发（FGR-GEN-034），**沿地形实际行进**过来（层级寻路，FGR-ARC-015）；行进途中可以被发现、被拦截。
- 目标可以是家园，也可以是前哨站：靠近阵营领地、价值高的前哨站更容易被盯上。
- 没有合适据点时（例如该阵营已被平定），从迷雾外"远方来袭"。越往后的幕，据点越多，来袭方向越多。
- 摧毁某个方向的据点，会降低该方向的突袭频率。
- 舰队突袭用空投舱（FG11）。

**FGR-DEF-024 预警**
- 突袭部队出发时发出预警，**行进路程就是预警时间**。导演保证最短预警 1.5 个游戏小时（1x 下约 75 秒）：最近的据点太近时，推迟出发或改用更远的据点。
- 有监听站时，最早可以提前 1 个游戏日，并附带阵营、规模、方向。
- 预警界面：倒计时、地图上的来袭方向箭头、编成（如果有情报）。

### 3.4 敌方攻城行为

**FGR-DEF-030 按职能选目标**
- 突击型：直扑归还核心。
- 破坏型：优先攻击发电设施和信号设施（信号塔、超控阵列、电塔）。
- 攻城型：优先攻击炮塔和屏障。
- 敌人头顶显示职能图标，玩家能读懂它们要去哪里。

**FGR-DEF-031 寻路**
- 用流场朝目标前进；屏障会阻挡。
- 路线被完全堵死时，敌人攻击最短路线上最薄弱的那段屏障。**不允许靠完美迷宫让敌人永远走不到。**
- 闸门对敌人等同于屏障。
- 屏障有变化时，流场增量更新。

**FGR-DEF-032 撤退**
- 超过时间上限（**初值：1 个游戏小时**），或者损失超过 70%，突袭部队撤退，沿原路返回出发的据点，途中可以被追击。

### 3.5 玩家在突袭中

**FGR-DEF-040 在家时**
- 可以接入炮塔或驻防机器，也可以对驻防机器下达战略命令。

**FGR-DEF-041 远征时家园遇袭**
- 远征 HUD 弹出紧急通知，带倒计时。
- 远征 HUD 上有一个家园状态小窗：归还核心和关键建筑的耐久、剩余敌人。
- 玩家可以选择：
  - 把信号跳回家园（FGR-SIG-051），远征队交给 AI。
  - 让信号留在远征队那边，家园自己守。

**FGR-DEF-042 倍速观战与自动暂停**
- 突袭到达时自动暂停（设置项，默认对前 3 次突袭开启）。
- 突袭时可以开 2x 或 3x 观战。

**FGR-DEF-043 驻防机器**
- 驻防岗的机器守在指定点，或者按玩家画的巡逻路线巡逻（FG04 岗位）。按教义交战，可以接受命令。

### 3.6 结果

**FGR-DEF-050 突袭结算**
- 结束条件：敌人全灭或撤退。
- 结算内容：造成和承受的伤害、击杀数、各反应的伤害贡献、损失（建筑、炮塔、机器）、战利品。

**FGR-DEF-051 残骸**
- 敌人被击毁后留下残骸（地面物），由机器搬去回收站（得到废料）或解析台（得到技术数据）。
- 少数情况下掉落未解析模块或加密固件（概率低于远征）。

**FGR-DEF-052 离家报告**
- 远征期间发生的突袭写进离家报告：过程时间线、损失、谁（哪座炮塔、哪台机器）贡献最大。

**FGR-DEF-053 失败**
- 归还核心被摧毁即战役失败，沿用现有失败界面（ER7-FAIL-01），提供读取自动存档的选项。

### 3.7 难度

**FGR-DEF-060 突袭强度**
- 预设：建造者（只有剧情突袭，而且规模最小，面向纯经营玩家）、标准、严酷。
- 自定义：频率、规模、预警时间三个滑条。
- 游戏中途可以修改，修改记录在存档里（用于成就判定，FG15）。

### 3.8 防御总览

**FGR-DEF-070 防御面板**
- 所有炮塔的列表：状态、补给、目标模式、击杀数。
- 覆盖热力图：显示炮塔火力覆盖。
- 薄弱点：沿预测的突袭路线，标出火力覆盖不到的区段。

## 4. 正常游戏补全清单

- 放置炮塔时预览射程；放置屏障时预览对流场的影响（敌人会改走哪里）。
- 批量设置目标模式；复制炮塔设置。
- 炮塔可以改名，记录击杀数。
- 突袭历史：列出每次突袭的时间、阵营、结果，可以回看结算。
- **第一次突袭**：突袭导演保证第一次突袭为 1 级、规模很小。配套的引导（怎么看预警、怎么观战、怎么修理）在 FG15-UX-04 统一实现。
- 各类防御建筑都有图鉴条目；敌方每种单位都有图鉴条目，写明职能和弱点。
- 预警和突袭都有明确的音乐和音效变化。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 玩家用屏障把核心完全围死 | 敌人攻击最短路线上最薄弱的屏障；玩家看得到敌人在拆哪段墙 |
| 炮塔缺燃油 | 停火，原因写明；阈值补给规则会触发补给 |
| 远征中家园遇袭，玩家不回去 | 家园按自动化结果结算，与玩家在场观察时一致（FGR-BASE-021） |
| 突袭期间静默夜开始 | 信号断开，所有炮塔只跑本地常规固件；接入口为空 |
| 突袭期间存档 | 读档后敌人位置、耐久、流场、炮塔热量完全一致 |
| 自动重建时材料不足 | 虚影等待材料，不会重复扣料 |
| 护盾过载 | 关闭并倒计时重启，UI 显示 |
| 维修无人机站被毁 | 无人机坠毁，自动重建规则开启时，站点会被重建 |
| 两次突袭时间重叠 | 按导演规则不会发生（有最短间隔）；剧情突袭除外，剧情突袭与普通突袭合并为一波 |
| 建造者难度 | 只有剧情突袭，规模最小；核心被毁仍判失败 |

## 6. 存档

## 9. 人工体验审核

1. 看着自己的防线自动打出连锁反应时，是否有"大功告成"的满足感？
2. 远征中收到家园遇袭通知时，这个抉择让人紧张还是烦躁？
3. 突袭频率是否合适？会不会打断玩家想做的事？
