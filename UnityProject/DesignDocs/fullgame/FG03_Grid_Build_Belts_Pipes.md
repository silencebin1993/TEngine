## 1. 玩家目的

- 在上帝视角里**自由规划家园**，搭出一条**不用自己管也会一直运转**的产线。
- **看得见**物料在流动；产线出问题时，**一眼能找到原因**。
- 后期可以**批量、复制、升级**，不必一格一格重复操作。

## 2. 与 Demo 的差距

| 项 | Demo 现状 | 正式版 |
|---|---|---|
| 建造 | 固定锚点，只能在预设空地上解锁 | 格网自由放置、旋转、拆除、搬迁 |

| 可复用 | 工作单（`HomeValleyWorkOrders`）、电网优先级（`HomeValleyPowerGrid`）、仓储（`HomeValleyCargo`）、地面物（`GroundItems`） | — |

## 3. 需求

### 3.1 格网建造

**FGR-LOG-001 格网与分层**
- 按 FGR-ARC-001 实现：地形、污染、占用、传送带、管线、迷雾六层。地图按种子生成、按区块无限延伸（FG17）；地形和污染的初始分布来自家园生成器（FGR-GEN-030、031）。
- 地形类型：可建地、水源、油井、金属矿脉、稀土矿脉、废墟、悬崖（不可建）。

**FGR-LOG-002 建造菜单**
- 分类：物流、采集、加工、制造、能源、研发、情报、防御、信号、环境、存储、终局。
- 支持搜索（按名称和用途）。
- 快捷栏：玩家可以把常用建筑拖进快捷栏，用快捷键直接选取（键位见 FG13）。
- 未解锁的建筑显示为灰色，悬停说明解锁条件。

**FGR-LOG-003 放置预览**
- 虚影跟随鼠标，显示占地、朝向、输入输出端口的箭头。
- 合法和不合法用**颜色加图案**区分（色盲安全）。
- 不合法时显示原因：已被占用、地形不符、污染过重、需要放在矿脉 / 水源 / 油井上、超出已探索区域、超出电力覆盖（只警告，不阻止）。
- 按旋转键旋转 90°，放置前后都能旋转。
- 显示建造成本和当前库存是否足够（不足也允许放置虚影，见 FGR-LOG-006）。

**FGR-LOG-004 拖拽建造**
- 传送带、管线、墙可以按住拖拽，按路径预览，自动转角。
- 拖拽时显示长度和总成本。
- 拖拽时镜头贴边会自动平移。

**FGR-LOG-005 批量操作**
- 框选多个建筑。
- 复制和粘贴（包括建筑的设置，例如配方、过滤器、优先级）；粘贴时可以旋转。
- **布局库**：把一组建筑保存成命名布局，带缩略图，之后可以直接放置。布局库**跨存档共享**，存在玩家配置目录。
- 布局导出为文本和导入（可选，优先级 P2）。

**FGR-LOG-006 建造虚影与施工**
- 放置后先生成**建造虚影**，并生成施工工作单。
- 机器从仓库取材料，送到现场施工。施工需要时间。
- 材料不足时，虚影显示"等待材料：合金 ×12"，一旦有货就自动继续。
- 虚影外观与完工建筑明显不同。
- 施工队列可以查看、可以调整优先级。
- 取消虚影时，已经预留的材料全额退回。
- 前哨站等远处的施工：材料可以由机器走过去运、用传送带铺过去，或用投送舱送施工包（FG08 FGR-EXP-018）。

**FGR-LOG-007 拆除**
- 用拆除标记选中建筑，机器上门拆除。
- **全额返还**：建筑本身的材料、建筑内部缓存的物品、传送带上的物品，都送回最近的有空间的仓库。仓库全满时，返还物品变成地面物，由机器之后搬运。
- 需要确认的情况：一次拆除超过 20 座建筑；拆除归还核心、信号塔、超控阵列这类关键建筑。

**FGR-LOG-008 搬迁**
- 选中一座建筑拖到新位置：生成"拆除原建筑 + 在新位置放虚影"的组合任务，保留原设置。

**FGR-LOG-009 撤销和重做**
- 规划类操作可以撤销和重做：放置虚影、取消虚影、拆除标记、搬迁。
- 已经完工的建筑被撤销时，生成拆除任务，并提示玩家。
- 撤销栈至少 50 步（**初值**）。

**FGR-LOG-010 升级规划**
- 框选区域，把传送带、管线和建筑升级到已解锁的更高等级。
- 原地升级，保留设置；生成施工任务，按新旧材料的差额收费。

**FGR-LOG-011 吸管和复制设置**
- 吸管：对着已有建筑按快捷键，选中同类建筑，并带上它的朝向和设置。
- 复制设置：把 A 建筑的配方、过滤器、优先级粘贴到 B 建筑（同类或兼容类型）。

**FGR-LOG-012 建造限制**
- 污染 2 级及以上的格子不能建造（净化塔和传送带除外，见 FG07）。
- 污染 1 级的格子可以建造，但建筑受天气损伤加倍。
- 采集类建筑必须放在对应的资源点上。
- 归还核心周围一圈（**初值：3 格**）保留为通道，不能建造。
- 放置会让某座建筑变得机器无法到达时，给出警告（不阻止）。

**FGR-LOG-013 迷雾**
- 未探索的格子不能建造。探索靠信号塔覆盖范围扩张，或者由机器走过去。

### 3.2 传送带

**FGR-LOG-020 等级**
- 三个等级：T1、T2、T3，速度见第 10 章。单车道，每格最多 4 个物品（**初值**）。
- 方向在放置时确定；可以原地反转方向。

**FGR-LOG-021 连接**
- 传送带朝向建筑的输入端口时，把物品送进建筑；建筑的输出端口把物品推上传送带。
- 仓库有输入和输出端口；输出端口可以设置过滤器，只输出指定物品。
- 侧向汇入：传送带从侧面接入另一条传送带时，两路物品**交替汇入**，保证公平。

**FGR-LOG-022 分流器和合流器**
- 分流器：一进两出，默认 1:1；可以设置优先输出口；每个输出口可以设置物品过滤。
- 合流器：两进一出，可以设置优先输入口。

**FGR-LOG-023 地下传送带**
- 用来跨越其他传送带或建筑，最大跨度随等级提高（见第 10 章）。

**FGR-LOG-024 物品模型**
- 物品种类由表定义（FG04）。传送带可以运输任意固体物品。物品没有耐久。

**FGR-LOG-025 堵塞**
- 下游满了，传送带就停下，物品不会消失。
- 堵塞的传送带有明显的视觉标记（图案加颜色），悬停说明"下游 X 已满"。

**FGR-LOG-026 清带工具**
- 清空选中传送带上的物品：送到最近的仓库。仓库放不下时，询问玩家是否丢弃，并需要确认。

**FGR-LOG-027 损毁**
- 传送带有耐久，可能被突袭和天气损伤。
- 被摧毁时，上面的物品变成地面物；原位置留下虚影，按自动重建规则重建（FG06）。

**FGR-LOG-028 天气影响**
- 沙暴期间，露天传送带减速（**初值：-25%**）；在顶棚覆盖下不受影响（FG07）。

### 3.3 管线与流体

**FGR-LOG-040 流体与网络**
- 流体种类：水、原油、冷却液、燃油、酸液（由表定义，FG04）。
- 相连的管线组成一个流体网络，**一个网络只能有一种流体**。把两种不同流体的网络接在一起会被拒绝，并说明原因。
- 管线按所载流体上色，并有图标。

**FGR-LOG-041 泵**
- 泵必须放在对应的流体源上（水源、油井），按固定速率抽取。

**FGR-LOG-042 吞吐结算**
- 不做压力模拟。网络按"总供给和总需求"结算；网络的吞吐上限等于网络中**最低等级**管线的吞吐。
- 供给不足时，按消费者优先级分配（沿用电网的优先级 1～4）。
- 悬停管线时，显示网络的供给、需求、储量和瓶颈管段。

**FGR-LOG-043 储罐和阀门**
- 储罐：缓冲流体，可以设置为"只进 / 只出 / 双向"。
- 阀门：单向流动，也可以手动关闭。

**FGR-LOG-044 冲洗**
- 清空一个网络的流体，需要确认。

**FGR-LOG-045 结冰**
- 寒潮期间，**流量为 0 超过 1 个游戏小时**的管段会结冰，结冰的管段阻断流动。
- 寒潮结束后自动解冻。升级为伴热管的管段不会结冰。
- 结冰时有视觉效果和警告。

**FGR-LOG-046 破损泄漏**（FG-M6 接入）
- 管线被击穿时会泄漏，在地面留下对应流体的液洼，并带上对应标签：燃油留下油污，冷却液留下浸湿，酸液留下腐蚀。
- 泄漏会与战斗中的标签反应互动。例如燃油泄漏遇到燃烧，就会产生燃烧区。这是**有意设计的涌现玩法**，要写进图鉴和提示。

### 3.4 电力网络（扩展 ER3-PWR-01）

**FGR-LOG-060 电塔与子网**
- 电塔有覆盖范围；覆盖范围内的建筑自动接入电网；电塔之间在范围内自动相连。
- 互不相连的电网是独立的子网，各自结算容量和需求。
- 每座建筑保留优先级 1～4；子网供电不足时，按优先级依次断电（沿用现有逻辑）。

**FGR-LOG-061 电力信息**
- 每个子网都有发电、耗电、储能的曲线。
- 电力覆盖叠加层显示哪些建筑没有接入电网。

### 3.5 机器在物流中的角色

**FGR-LOG-070 分工**
- 传送带和管线负责**连续的大宗物流**。
- 机器负责：施工、拆除、维修、搬运地面物、把远征带回的货物卸到仓库或解析台、按常驻规则补给（FG04）。
- 机器被派去远征时，家园的施工和搬运能力会下降，远征准备界面要提前提示（FG08）。

### 3.6 可视化与诊断

**FGR-LOG-080 叠加层**
可以切换的叠加层：物品流向与吞吐、堵塞、电力覆盖、流体网络、污染、信号覆盖、突袭路径（FG06）、施工状态。

**FGR-LOG-081 悬停信息**
- 传送带：当前物品、速度、吞吐（件 / 分钟）。
- 建筑：状态和原因、端口、输入输出缓存。

**FGR-LOG-082 "为什么不工作"**
- 每座停工的建筑都给出原因，并尽量**追溯到根源**。例如："缺合金 → 上游精炼炉缺电 → 电网 2 超载"。原因条目可以点击，镜头跳到对应位置。

### 3.7 内核

**FGR-LOG-090 物流内核**
- 按 FGR-ARC-004 实现：AOT 内核，固定步长（**初值：20 Hz**），结果确定。
- 热更层每帧开销与物品数、传送带格数无关。
- 渲染：物品实例化绘制；镜头拉远到一定程度后切换为流动贴图。

## 4. 正常游戏补全清单

- 快捷栏、吸管、复制设置、放置前旋转、布局库、撤销和重做、升级规划、拆除规划（框选拆除）。
- 右键取消当前的放置模式；Esc 退出建造模式。
- 可以开关格线显示；放置时自动吸附到格网。
- 拖拽时显示长度和成本。
- 放置时预览电力覆盖、流体连接、端口方向。
- 建造菜单支持搜索，未解锁的建筑说明解锁条件。
- 战略暂停中可以继续规划（放虚影、拆除标记），恢复后才开工。
- 施工队列可以调整优先级；可以"优先建造这一片"。
- 所有建造相关的快捷键都可以重绑。
- 新玩家第一次打开建造菜单、第一次放传送带、第一次遇到堵塞时，各有一次非阻塞引导。
- 图鉴有"传送带""分流器""管线""流体网络""电塔"条目。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 放置虚影时材料不足 | 允许放置，虚影显示缺什么，有货后自动开工 |
| 施工途中材料被别的任务用掉 | 施工暂停，显示缺料，不重复扣料 |
| 拆除时仓库全满 | 返还物品变成地面物，之后由机器搬走，不会消失 |
| 两种流体的网络被连起来 | 拒绝，说明原因 |
| 传送带首尾相连成环 | 允许；环上的物品一直转，吞吐统计正确，不会刷出物品 |
| 分流器两个输出口都堵 | 分流器停止，上游堵塞，给出原因 |
| 施工中的建筑被突袭摧毁 | 已消耗的材料按比例掉落为地面物，虚影保留 |
| 存档时传送带上满是物品 | 读档后物品数量、种类、位置完全一致 |
| 在 3x 速度下 | 吞吐按比例提高，结果与 1x 跑同样的游戏时间一致 |
| 家园无人观察（玩家在远征） | 产线照常运行，结果与观察时一致（FGR-BASE-021） |
| 电塔被摧毁，电网断成两段 | 两个子网各自结算，优先级低的先断电，并发出警告 |
| 寒潮时流体网络没有流动 | 结冰，警告；寒潮结束后自动解冻 |
| 撤销一个已完工的建筑 | 生成拆除任务并提示，不会瞬间消失 |
| 传送带或管线跨越区块边界 | 物品和流体在区块之间连续流动；存读档后一致 |
