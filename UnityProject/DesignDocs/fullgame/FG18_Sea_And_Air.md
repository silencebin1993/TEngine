# FG18 海与空

> 状态：**Proposed（初稿，待用户确认细节）**。方向已由用户拍板（2026-10-15）：玩家加飞行底盘（带硬约束）、做完整海上单位、悬浮底盘保留。
> 需求前缀：`FGR-SEA`（水体与海上）、`FGR-AIR`（空中）；测试前缀：`FGT-SEA`、`FGT-AIR`。
> 决定编号：FG18-SEA-01（完整海上单位）、FG18-AIR-01（玩家飞行底盘）、FG18-HOV-01（悬浮两栖）。
> 里程碑：建议新增 **FG-M7S 海与空**，插在 FG-M7 与 FG-M8 之间（见 §10）；敌方海上单位随各阵营进 FG-M9～M11，白潮海上登陆进 FG-M13。
> 上游：[GDD 0.2](../ProjectA_GDD.md) §5.1、§6、§10；改动：[FG17](FG17_World_Generation.md)（世界生成）、[FG03](FG03_Grid_Build_Belts_Pipes.md)（建造）、[FG08](FG08_Expedition_Loot_Quests.md)（远征）、[FG09](FG09_Factions_Enemies_Leaders.md)（阵营）、[FG06](FG06_Home_Defense_Raids.md)（防御）。契约：[FG00](FG00_Completeness_Addendum.md)。

## 1. 玩家目的

- 海和天空是还没归还的两片地方：**海路**通往陆路到不了的资源、遗产和敌方侧翼；**天空**让你先看见、先赶到。
- 每一层都有自己的代价：**船离不开水，飞机离不开电，悬浮机两边都能去但两边都不最强**。选哪种底盘，本身就是一个取舍。
- 四个阵营的"前身"在海上也留下了东西：海底电缆、军港、浮油、离岸数据舱。白潮从天上来，也会落在海上。

## 2. 三层通行

**FGR-SEA-001 地形层与通行标签**
- 每格地形带一组通行标签；每种底盘带一组可通行标签。寻路沿用层级寻路框架（FGR-ARC-015），只是给连通图和流场加一个**通行标签维度**——与越野多足的地形免疫同一机制（FG17-CHS-01，ProjectA_FullGame_Design §17.3），不另起移动内核。
- 空中是独立的一层：飞行底盘不受地面地形阻挡，但受续航约束（FGR-AIR-002）。

| 地形 | 陆地底盘（轮式、履带） | 越野多足 | 悬浮 | 船体 | 飞行 | 可建造 |
|---|---|---|---|---|---|---|
| 可建地、废墟、矿脉 | 可 | 可 | 可 | 否 | 可 | 可 |
| 悬崖、废墟断层 | 否 | 可 | 否 | 否 | 可 | 否 |
| 海岸（陆水交界） | 可 | 可 | 可 | 可（靠岸） | 可 | 可（船坞落点） |
| 浅水（河、湖、近岸海） | 否 | 否 | 可 | 可 | 可 | 只能建栈桥（FGR-SEA-011） |
| 酸沼 | 可（持续腐蚀） | 可（持续腐蚀） | 可（腐蚀减半，**初值**） | 可（持续腐蚀） | 可 | 否 |
| 深水（外海） | 否 | 否 | 否 | 可 | 可 | 否（海上平台除外，FGR-SEA-013） |

## 3. 世界生成（改 FG17）

**FGR-SEA-002 外海与水系**
- 区域规划层（FGR-GEN-020）额外决定：一个**外海方向**（扇区，按种子），海岸线离核心 **300～600 格（初值）**；从内陆流向外海的 **2～4 条主要河流**；若干内陆湖泊。沉淀湖成为真正的湖：湖面是浅水，外圈是酸沼带（FGR-GEN-022 不变）。
- 外海扇区与四个阵营领地的方向可以重叠：领地向海延伸，形成沿海据点。**白潮滩头（预留区）优先放在海岸上**——"滩头"名副其实。
- 河流宽度 3～12 格（初值），在若干处生成**浅滩**（陆地底盘可通过的窄口），保证陆路仍然可达。

**FGR-SEA-003 起始区与可达性保证**
- 家园起始区保证（FGR-GEN-031）追加：半径 **200 格（初值）**内至少有一段河岸或海岸可以建船坞，且这段水域与外海连通。
- 生成校验（FGR-GEN-090）追加：所有首领场地、主线锚点**不依赖船也必须陆路可达**；海上锚点只放支线、资源和遗产。
- 同一种子生成同一套水系；水系只依赖种子，不进存档。

**FGR-SEA-004 海上锚点（手工锚点，FGR-GEN-024）**

| 锚点 | 内容 | 关联 |
|---|---|---|
| 沉船（旧时代货轮） | 人类遗产、旧时代蓝图、大量废料 | FG08 §6 人类遗产 |
| 海上油井平台废墟 | 可修复为海上平台，产油 | FGR-SEA-013 |
| 海底电缆登陆站 | 静默的海上据点，信号中继网络的海上一段 | FG09 静默 |
| 军港 | 铸造的海上据点，浅水炮艇的母港 | FG09 铸造 |
| 浮油带 | 澄净在海上"净化"的地方，有围油栏拖船 | FG09 澄净 |
| 离岸数据舱 | 超频用海水冷却的服务器舱，可夺取为冷却点 | FG09 超频 |

## 4. 建造（改 FG03、FG04）

**FGR-SEA-010 船坞**
- 只能建在海岸格，生产和改造船体底盘的机器；兼做船的维修与充电点。

**FGR-SEA-011 栈桥**
- 浅水格上可以建栈桥格；栈桥上可以放传送带、管线、电塔和轻型建筑（重型建筑不行）。
- 深水不能建栈桥。

**FGR-SEA-012 起降坪**
- 飞行底盘的充电点与起降点；家园、前哨站、海上平台都能建。

**FGR-SEA-013 海上平台**
- 由船拖到深水锚点（油井、沉船）上展开，作为**海上前哨站**，沿用 FG08 前哨站规则（仓库、维修、起降坪）。

## 5. 玩家底盘（共 7 种）

| 底盘 | 通行 | 定位 | 约束 |
|---|---|---|---|
| 搬运轮式 | 陆地 | 物流、施工 | 不变 |
| 战斗履带 | 陆地 | 主力输出 | 不变 |
| 维修悬浮 | 陆地 + 浅水 + 酸沼（**两栖**，FG18-HOV-01） | 支援，并把陆地和水面连起来 | 不进深水；在水面上速度 -20%（初值） |
| 固定底盘 | 不移动 | 炮塔与静态防御 | 不变；可建在栈桥和海上平台上 |
| 越野多足 | 陆地 + 悬崖 | 地形之外的可达性 | 不变 |
| **飞行（新）** | 空中 | 侦察迷雾、快速增援、跨越一切地形 | 见 FGR-AIR-002 |
| **船体（新）** | 浅水 + 深水 | 海上作战、海路运输、海上资源 | 离不开水；只能在海岸、码头、栈桥卸货 |

**FGR-AIR-001 飞行底盘定位**
- 不与越野多足抢功能位：越野多足**扛得动、走得久**，但慢；飞行**快、看得远**，但轻、续航短。
- 不与投送舱抢功能位：投送舱是一次性的远程投放（FG08）；飞行底盘是可反复使用、可被接入的机器。

**FGR-AIR-002 飞行底盘约束（硬约束）**
- **续航**：满电可飞约 **90 秒（初值）**，必须回到起降坪、充电塔覆盖区或船坞充电；电量耗尽时**迫降**——机器瘫痪在原地，不阵亡，等待回收（可恢复原则，GDD §2）。
- **载重档 = 轻**：只能装轻型作战组件和轻型结构模块（重甲、货舱、重型射弹组件装不上），编辑器显示原因。
- **怕对空**：所有标着"对空"的武器都能打它（FGR-AIR-010）。
- 被接入时同样触发机身形变（GDD §5.5）。

**FGR-SEA-020 船体底盘**
- 载重档 = 重：可装任意作战组件和结构模块；装货舱时可以**运兵**（运载其它机器渡海，FGR-SEA-030）。
- 搁浅规则：船不会主动驶入浅滩以外的浅水死角；被击退到陆地边缘时停在最近的可航格。

## 6. 作战规则

**FGR-AIR-010 对空、对海标签**
- 每个作战组件带一组目标标签：对地 / 对空 / 对海。默认：射弹（直射、弹丸）对地 + 对空 + 对海；抛射（曲射）对地 + 对海、**不对空**；格斗只对同层；无人机对地 + 对空 + 对海；力场与布区只影响同层。具体组件可以覆盖默认值，写在组件表里。
- 敌方遵守同一套标签（FGR-FAC-003）。已有的对空高炮、空爆炮台按"对空"标签工作，规则不变。

**FGR-SEA-021 跨层交战**
- 船可以炮击射程内的陆上目标，岸上的炮塔可以打射程内的船；空中单位不会被布区、地面力场影响。
- 落水：陆地底盘被击退进水里时，停在岸边最近的可通行格，不溺毁。

## 7. 远征与运输（改 FG08）

**FGR-SEA-030 海路远征**
- 远征队可以走海路：装货舱的船体机器运载其它机器渡海，到登陆点（海岸格）卸下。
- 海上平台可以当前哨站用；海路的补给线可被敌方海上单位截断，并有预警。
- 行军速度取决于最慢的那台（FG08）；海路段按船速计算。

## 8. 敌方的海与空（追加到 FG09）

每个地面阵营追加 1～2 个海上单位，由前身推出；它们也承担 FG09 里待补的专属行为。白潮不入海，但能从天上落在海上。

| 阵营 | 新单位（拟） | 层 | 专属语法（FGR-FAC-008） | 说明 |
|---|---|---|---|---|
| 静默 | 电缆中继潜伏艇 | 水面 | 中继跳转、静默潜伏 | 沿海底电缆中继节点跳点；补上"中继跳转"的普通单位承载 |
| 静默 | 回声猎手（改用三球轮三脚架造型） | 陆地 | 静默潜伏 | 全向静音滑行（灰模设计 05-2） |
| 铸造 | 浅水炮艇 | 水面 | 架炮驻锄（下锚后开火）、高抛曲射 | 军港母港 |
| 铸造 | 岸防炮台（固定） | 海岸 | 齐射弹幕（对海） | 军港与沿海据点 |
| 澄净 | 围油栏拖船 | 水面 | 铺管爬行（拖着浮式围油栏前进，切断即散） | 补上"铺管爬行"的承载单位 |
| 超频 | 水翼快艇 | 水面 | 冲刺—过热—停机 | 海上的超频猎犬 |
| 超频 | 离岸数据舱（固定） | 深水 | 蓄热连射 | 夺取后成为玩家的海上冷却点 |
| 白潮 | 轨道锚点（海上落点） | 海上 | 轨道锚点空降 | 白潮滩头优先放在海岸（FGR-SEA-002） |

- 静默"标记→远端打击"的打击源仍待补；建议：**回声炮位（新，固定，隐蔽）**——平时潜伏，只打被标记的目标。
- 已有的敌方空中单位（澄净灭活无人机、白潮清洗无人机、护卫无人机）不变，按 FGR-AIR-010 标签结算。
- 敌方超频猎犬改用**滚环单轮**造型（灰模设计 09-1）。

## 9. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 飞行机器在远征中电量耗尽 | 迫降、瘫痪、不阵亡；任务列表出现"回收"工作单；有低电预警 |
| 飞行机器被接入时电量低 | 接入照常；界面显示剩余续航；不偷偷补电 |
| 悬浮机器载着货驶向深水 | 寻路拒绝，提示"深水只有船能去" |
| 运兵船在海上被击沉 | 船上机器按"落水"规则：最近的可通行格若在射程外则瘫痪漂到最近海岸，不阵亡（**待用户确认**：是否改为阵亡） |
| 海上平台被摧毁 | 平台上的机器转移到最近的船或海岸；储物按 FG08 前哨站规则处理 |
| 敌方海上单位截断补给线 | 有预警；补给暂停并显示原因，不静默丢失物资 |
| 观察与不观察 | 海上和空中的结算与观察时一致（FGR-BASE-021） |

## 10. 里程碑与改动面

**建议新增 FG-M7S 海与空**（M7 之后、M8 之前，因为 M8 的远征、投送、前哨站都要用到海路和飞行）：
- 必须完成：水系生成与通行标签（FGR-SEA-001～004）；船坞、栈桥、起降坪、海上平台（FGR-SEA-010～013）；悬浮两栖、飞行底盘、船体底盘（§5）；对空对海标签（FGR-AIR-010）；跨层交战（FGR-SEA-021）；海上锚点两种（沉船、油井平台）。
- 出口旅程：在家园河岸建船坞 → 造一艘船 → 用悬浮机渡河维修 → 起飞一架飞行机侦察到沉船 → 海上平台开采 → 飞行机电量耗尽迫降后被回收。

**会回头改的已实现部分**（需要单独评估工作量）：
- FG17 世界生成（M0、M3 已实现）：规划层加外海扇区和河流；地形层加浅水、深水、海岸；起始区和可达性校验。
- 层级寻路（M0）：通行标签维度、空中层。
- FG03 建造合法性（M3）：栈桥、船坞落点、海上平台。

**美术影响**：新增玩家底盘灰模三种（飞行、船体，悬浮重新设计为两栖）；敌方海上单位约 7 个；环境件（海岸、浅水、深水、栈桥、船坞、海上平台、沉船）；水面 Shader（可回头）。

## 12. 待用户确认

1. 外海方向只有一个扇区，还是可以多个（多个会让海更大，但陆地领地更挤）。
2. 潜艇（水下层）做不做。**本稿默认不做**：只有水面层；静默的"潜伏艇"是半潜，靠静默潜伏规则隐藏。
3. 运兵船被击沉时船上机器的处理（本稿默认不阵亡，见 §9）。
4. 飞行底盘的续航初值和充电方式（本稿：90 秒，起降坪 / 充电塔覆盖区 / 船坞充电）。
5. FG-M7S 是否作为新里程碑插在 M8 之前（本稿建议是）。

## 13. 数值初值

全部进 FG16 统一调参。本文件里的初值：海岸线离核心 300～600 格；河流 2～4 条、宽 3～12 格；起始区船坞落点半径 200 格；悬浮水面速度 -20%、酸沼腐蚀减半；飞行续航 90 秒。
