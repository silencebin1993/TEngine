## 1. 玩家目的

- 研发建筑**一直在工作**，不是"造好解锁就闲着"。
- 在家里就能**发现新的化学反应**（熔合），并且**零风险地试新电路**（靶场投影）。
- 提前知道**敌人要来了、敌人会怎么针对我**（情报）。

| 项 | Demo 现状 | 正式版 |

## 3. 需求

### 3.1 研究点与仿真实验室

**FGR-RND-001 研究点产出**
- 仿真实验室持续消耗技术数据和电力，产出研究点（**初值：每分钟消耗技术数据 2，产出研究点 1**）。
- 可以建多座，产出相加。实验室有三个等级，等级越高转换效率越高。
- 技术数据不足或断电时，实验室停工，并给出原因。

**FGR-RND-002 研究进度**
- 研究按队列消耗研究点推进。没有实验室就无法推进研究。
- 研究可以取消，**已投入的进度保留在节点上**，下次继续，不会损失。

### 3.2 研发树

**FGR-RND-010 分支**
- 通用分支：工业、物流、能源、防御、信号、环境、远征。
- 阵营分支：静默、铸造、化工、超频。破解该阵营的第一件技术后开放。
- **初值**：约 70 个节点。

**FGR-RND-011 节点类型**
- 蓝图解锁（组件、结构模块、炮塔、底盘）
- 建筑解锁、建筑升级
- 效率（有上限，单项累计不超过 +30%，避免纯数值堆叠）
- 容量（仓库、储罐、电池）
- 槽位（超控阵列的各级，需要关键材料，见 FG04 3.4）

**FGR-RND-012 节点示例**

| 分支 | 节点示例 |
|---|---|
| 工业 | 电子组装台、组件工坊、精炼炉 T2、精炼塔 |
| 物流 | 传送带 T2 / T3、地下传送带、分流过滤、管线 T2、伴热管、布局库扩容 |
| 能源 | 燃油发电机、太阳能阵列、储能站、电塔 T2 |
| 防御 | 炮塔座 T2、护盾发生器、陷阱发射器、维修无人机站、自动重建 |
| 信号 | 超控阵列 T1～T3、信号塔 T2、信号中继模块 |
| 环境 | 净化塔 T2 / T3、顶棚、减震基座 |
| 远征 | 货舱扩容、远征编制 +1、行军加速、投送站 T2 |
| 阵营分支 | 该阵营的作战组件蓝图、结构模块蓝图、专属炮塔蓝图 |

**FGR-RND-013 研发树界面**
- 可以缩放、平移、搜索，按分支筛选。
- 节点状态：未解锁、可研究、研究中、已完成。
- 悬停节点显示它会解锁什么，并附预览（图标、说明，建筑的话还有占地）。
- 研究队列最多 5 项，可以拖动排序。
- 研究完成时发通知；新解锁的建筑在建造菜单上显示"新"标记，直到玩家看过一次。

### 3.3 解析台

**FGR-RND-020 队列**
- 敌方物品（未解析模块、加密固件、数据核心）由机器或传送带送进解析台，排入队列（**初值：8 项**）。
- 每项有解析时间和耗电；断电时暂停，保留进度。

**FGR-RND-021 解析结果**

| 物品 | 首次解析 | 重复解析 |
|---|---|---|
| 未解析模块 | 解锁对应的组件或模块蓝图，并产出技术数据；模块被消耗 | 只产出技术数据 |
| 加密固件 | **固件本身变成已破解**（不消耗），并解锁刻录蓝图 | 同样变成已破解 |
| 数据核心 | 技术数据，外加一条情报或背景资料 | 技术数据 |

- 加密固件解析后**不会被消耗**，玩家不会因为破解而失去战利品。

**FGR-RND-022 结果预览**
- 已知类型的物品，直接显示解析后会得到什么。
- 第一次遇到的类型显示"？？"，并提示"首次解析将解锁新蓝图"。

**FGR-RND-023 取消**
- 取消队列中的项目，物品原样退回。

**FGR-RND-024 空闲工作**
- 队列为空时，解析台处理送进来的残骸（来自突袭敌人的残骸，FG06），缓慢产出技术数据。

### 3.4 靶场与仿真投影

**FGR-RND-030 靶场**
- 8×8 的区域建筑，可以在里面摆放靶子。
- 靶子类型：重甲、高速、集群、护盾。每击败一种敌人，就解锁对应的阵营靶子。

**FGR-RND-031 仿真投影**
- 在靶场里投影任意一张已保存的蓝图，**不消耗任何资源**，不需要真的造出这台机器。
- 投影可以和靶子战斗，也可以被玩家**接入**，用来测试核心固件的效果（"你接入时"状态）。
- 投影不能离开靶场，不与靶场外的任何东西互动，也不会进入存档（存档时正在进行的测试直接结束）。
- 投影在视觉上有明显的全息效果，不会被误认为真实机器。

**FGR-RND-032 读数**
- 测试时显示：每秒伤害、各反应的触发次数、各标签的覆盖率、热量曲线、能耗。
- 可以把两次测试的结果并排对比。

**FGR-RND-033 快捷入口**
- 从蓝图编辑器和固件详情页，都能一键"送到靶场测试"。

### 3.5 熔合

**FGR-RND-040 模拟熔合**
- 在电路合成台选两条固件（都要已破解，不能是混合固件）。
- 先做"模拟熔合"：只花少量技术数据（**初值：5**），立刻出结果：
  - 有配方：显示混合固件的预览和正式熔合的成本。
  - 没有配方：显示"无反应"，**不消耗任何固件**。

**FGR-RND-041 正式熔合**
- 消耗两条父固件、芯片基板 ×2、技术数据（**初值：30**），需要时间，产出一条混合固件。
- 沿用现有合成台的原子事务：预留、完成、取消的规则不变，保证不会复制或丢失。

**FGR-RND-042 发现后量产**
- 配方第一次成功后，记入配方书，并解锁固件刻录台上的对应刻录蓝图。
- 之后在刻录台量产，不再消耗父固件，但成本更高（**初值：芯片基板 ×3**）。

**FGR-RND-043 配方数量**
- 正式版目标约 30 条熔合配方，由表定义。

**FGR-RND-044 线索**
- 每次远征或突袭结束后，仿真实验室分析战斗记录，生成线索。例如："燃烧与油污同时出现 12 次，可能与'燃迹 + 漏油'有关。"
- 线索分两种：部分线索（只知道一条父固件）和完整线索。

**FGR-RND-045 配方书**
- 显示已发现的配方、已有的线索；每个类别还剩多少个未发现（"流体类熔合还有 7 个未发现"）。

### 3.6 监听站与情报

**FGR-RND-050 情报产出**
监听站持续破译，按时间产出情报：

| 情报 | 内容 | 条件 |
|---|---|---|
| 突袭预报 | 时间窗口、阵营、规模、方向 | 默认 |
| 敌方反制预览 | 下一次远征各区域会怎么针对你 | 默认 |
| 首领弱点 | 首领的阶段机制和弱点 | 需要先在远征中遭遇过该首领 |
| 天气预报 | 未来 3 个游戏日的天气 | 监听站 T2 |
| 舰队信号片段 | 剧情线索 | 第二幕起 |

- 情报有有效期，过期的情报标为"已过时"。

**FGR-RND-051 情报面板**
- 按类型列出情报，显示有效期倒计时；新情报发通知。
- 突袭预报会在地图上标出来袭方向。

**FGR-RND-052 多座监听站**
- 可以建多座，破译速度提高，但边际收益递减（**初值：第 2 座 +50%，第 3 座 +25%**）。
- 监听站是突袭时的次要目标。

### 3.7 黑匣子陈列馆

**FGR-RND-060 黑匣子**
- 阵亡机器的黑匣子（远征时由其他机器带回，家园阵亡的直接回收）送进陈列馆。
- 陈列馆缓慢分析黑匣子，产出技术数据（**初值：每个黑匣子共产出 20 点，分 1 个游戏日产完**）。
- 同时作为纪念墙：列出每台阵亡机器的名字、编号、经历和阵亡地点。

### 3.8 技术数据流向

**FGR-RND-070 来源与去处**
- 来源：解析、残骸处理、遗迹终端、数据核心、黑匣子。
- 去处：研究点、模拟熔合、正式熔合、首次保存跨派系蓝图（沿用 Demo 规则）。
- 统计面板里可以看到技术数据的收入和支出。

## 4. 正常游戏补全清单

- 研发树有快捷键可以直接打开。
- 研究完成、解析完成、发现新配方、获得新情报时都有通知，点击可以定位。
- 实验室和解析台空闲时有提示（"解析台空闲：没有待解析的物品"）。
- 靶场可以保存靶子布置的预设。
- 配方书可以按类别筛选，线索可以按新旧排序。
- 所有研究节点、配方、情报类型都有图鉴条目。
- 新玩家第一次拿到敌方物品时，引导他把物品送进解析台；第一次拿到线索时，引导他去合成台。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 研究进行中技术数据耗尽 | 实验室停工，研究暂停，保留进度，给出原因 |
| 取消研究 | 进度保留在节点上 |
| 解析中途断电 | 暂停，保留进度；来电后继续 |
| 解析队列满 | 拒绝新物品，物品留在原处（传送带上会堵塞），给出原因 |
| 模拟熔合时选了混合固件 | 拒绝，说明"混合固件不能再次熔合" |
| 正式熔合途中被突袭打断（合成台被毁） | 事务回滚，父固件退回（或作为地面物掉落），不复制、不丢失 |
| 靶场测试中存档 | 测试结束，投影消失；读档后靶场处于空闲状态 |
| 投影被接入后，信号在投影里时静默夜开始 | 断链，弹回核心，投影消失 |
| 情报过期 | 标为"已过时"，不删除，直到被新情报替代 |

## 6. 存档

研究进度（每个节点）、研究队列、解析队列与进度、配方书与线索、情报列表与有效期、黑匣子分析进度、纪念墙名单。靶场投影不存档。

---

## 7. 性能

- 投影与真实机器共用战斗内核，但只在靶场范围内运行。同一时刻最多 6 个投影（**初值**）。
- 线索生成在远征或突袭结束时一次性完成，不在战斗中实时统计。

## 9. 人工体验审核

1. 发现一条新熔合配方时，有没有"我发现了一个秘密"的感觉？
2. 靶场是否真的让玩家更愿意尝试新组合？
3. 情报是否让玩家觉得"我能提前准备"，而不是信息过载？
