## 1. 玩家目的

- 每次出门都**有目标**（主线、支线、想要的某件技术），也**有惊喜**（三选一）。
- 带不回所有东西，**取舍本身就是构筑**。
- 敌人给的东西**种类丰富**：组件、固件、蓝图、数据、人类遗产。

## 3. 远征

**FGR-EXP-001 远征准备**
- 准备界面是一张检查单，分"硬约束"（不满足不能出发）和"提醒"（可以无视）。
  - 硬约束：人数在带宽允许范围内；至少一台机器；区域已解锁。
  - 提醒：没有信号中继；货舱容量低于建议值；预计会跨过静默夜；出发后家园劳动力下降多少；情报显示的敌方反制；机器伤势。
- 在准备界面可以编辑信号核（远征途中不能改，FGR-SIG-011）。
- 出发时锁定敌方反制（沿用 ER6-ADAPT-01）。

**FGR-EXP-010 转场**
- 单程转场 2 个游戏小时（**初值**）。转场期间，远征队处于"在途"状态，不在任何地图上，不能被接入。
- 家园全程照常运行。玩家的视角留在家园，可以正常操作，也可以开倍速。
- 到达时发通知，视角可以一键跳到远征区。
- 返程同样需要转场时间。

**FGR-EXP-020 区域列表**
- 每个区域都是按阵营模板生成的表面，关键地点是手工锚点（FG17 FGR-GEN-040～044）。下表写的是区域的正式名。

| 区域 | 阵营 | 威胁 | 危害 | 解锁条件 |
|---|---|---|---|---|
| 破碎都市 | 静默 | 低 | 电磁噪声 | 开局主线 |
| 铸造前哨（外围 + 核心区） | 铸造 | 中～高 | 熔渣热区 | 第一幕主线 |
| 沉淀湖 | 化工（澄净） | 中～高 | 酸沼 | 第二幕主线，需要"防腐涂层"蓝图 |
| 热寂数据城 | 超频 | 高 | 高温辐射 | 第二幕主线 |
| 白潮滩头（登陆场） | 舰队（白潮） | 最高 | 轨道打击 | 第三幕主线 |
| 遗迹点（若干） | — | 低 | 无 | 探索或情报揭示 |

**FGR-EXP-021 区域持久化**
- 按区块差异保存（FGR-GEN-050）：已探索的迷雾、被摧毁的敌方建筑、已开启的遗迹点和终端、敌方据点状态。

**FGR-EXP-022 敌方增援与平定**
- 首领被击败之前，该阵营每 N 个游戏日（**初值：3**）向区域补充兵力，已摧毁的据点有可能被重建。
- 首领被击败后，区域进入"平定"：残余敌人刷新率降低，精英每 7 个游戏日刷新一次（可以刷材料），首领不再刷新。
- 世界地图上显示每个区域的威胁等级和平定状态。
- 主区域之外按需无限延伸，威胁和奖励随距离上升；远处未探索的区块仍可能出现新前哨（FGR-GEN-043、044）。

**FGR-EXP-030 区域内容**
- 区域地图上标出：主线目标、支线目标、已知精英、终端、遗迹点、资源缓存、撤离点。
- 图例可以筛选。

**FGR-EXP-031 撤离与放弃（沿用 Demo 规则）**
- 撤离：在撤离点确认，已装载的货物全部带回。
- 放弃：在任何地方都可以，未装载的战利品丢失，已装载的货物和已归档的技术保留。
- 全灭：沿用 Demo 结算，信号回到家园。

**FGR-EXP-032 机器阵亡时的货物**
- 远征中机器阵亡，它货舱里的东西变成地面物，留在原地。其他机器可以捡起来。
- 黑匣子同样掉落，可以被捡回（FG05 黑匣子陈列馆）。

**FGR-EXP-050 远征结算**
- 在 Demo 结算的基础上增加：三选一的选择记录、任务进度、生成的熔合线索（FG05）、暴露变化、远征耗时、机器经历更新。
- 返回家园后，按"远征卸货"规则把货物送到仓库或解析台（FG04）。

## 4. 掉落

**FGR-LOOT-001 物品协议**
每件物品都有协议字段，决定它的去向：

| 协议 | 例子 | 去向 |
|---|---|---|
| 己方 | 自产的组件、固件 | 直接使用 |
| 中立 | 人类遗产、中立协议的固件和组件、材料、耗材 | **直接使用**：回家就能装配，或直接进产线 |
| 敌方加密 | 敌方固件、敌方接口组件、未解析模块、数据核心 | **需要反破解**：送解析台（FG05）；敌方固件在破解前可以由核心"裸跑"（FGR-SIG-060） |

- 界面上用图标加文字标明协议，并在详情里写明"需要解析"或"可直接使用"。

**FGR-LOOT-010 掉落来源**

| 来源 | 内容 | 方式 |
|---|---|---|
| 杂兵 | 废料、金属矿、稀土矿，小概率常见固件 | 普通掉落 |
| 精英 | 组件、稀有固件、加密数据 | 三选一数据包 |
| 首领 | 该阵营的核心固件和关键材料（固定），另加一个三选一数据包 | 固定 + 三选一 |
| 遗迹终端 | 蓝图、人类遗产、背景资料 | 固定 |
| 资源缓存 | 成批材料 | 固定 |
| 任务 | 关键材料 | 固定，不随机 |
| 事件 | 视事件而定（FG10） | 三选一或固定 |

**FGR-LOOT-020 三选一数据包**
- 精英死亡或事件完成时生成一个"待分拣数据包"。**不在战斗中弹出**，只在 HUD 上显示计数（"待分拣 ×3"）。
- 在撤离点确认撤离时，或在战略暂停中处理：面板显示 3 个候选。每个候选卡片写明：类型、稀有度、协议、占用货舱空间；从未见过的物品标"新"。
- 选 1 个装进货舱。货舱放不下时，提示玩家先丢弃别的东西，或者改选更小的候选。
- 没选的两个自动转化为少量技术数据（数字资源，不占货舱）。

**FGR-LOOT-021 候选池**
- 候选池 = 当前区域阵营池 + 通用池。
- 按稀有度抽取：普通 60%、精良 30%、稀有 9%、原型 1%（**初值**）。
- 同一个数据包内不重复。
- **保底**：连续 5 个数据包没有出现稀有及以上，下一个数据包必定有一个稀有位。

**FGR-LOOT-022 撤离前必须处理完**
- 确认撤离时，必须把所有未处理的数据包处理完。
- 放弃远征时，未处理的数据包全部丢失，确认框里会写清楚。

**FGR-LOOT-030 货舱**
- 货舱容量来自底盘（搬运轮式最大）和货舱结构模块。
- 物品占用空间（**初值**）：

| 物品 | 占用 |
|---|---|
| 材料 | 每 10 个占 1 |
| 固件 | 1 |
| 组件 | 3 |
| 数据核心 | 2 |
| 未解析模块 | 3 |
| 人类遗产 | 2 |
| 黑匣子 | 1 |

- 货舱界面：全队总容量条，每台机器的明细。
- 可以丢弃物品；在战略暂停中，可以在机器之间转移物品。
- 自动拾取：按材料种类开关（例如"自动拾取稀土矿：开"）。

## 5. 任务

**FGR-QST-001 任务类型**
- **主线**：推进剧情，给出关键材料，开启新区域。
- **支线**：区域任务，例如救援遗迹、摧毁监听节点、护送货物、夺回数据、清剿精英、调查异常。
- **家园指引**：可选的引导目标，例如"建造第一条传送带""撑过第一次静默夜"，给少量奖励。可以在设置里关闭。

**FGR-QST-002 任务来源**
- 任务来自核心备忘、监听站截获、终端和遗迹，**不做对话树**（沿用 GDD 的非目标）。

**FGR-QST-003 任务面板**
- 分"进行中 / 已完成 / 已失败"三栏。
- 每个任务写明：目标、所在区域、奖励预览、有无时限。
- 可以把最多 3 个任务固定到 HUD 的追踪栏；追踪中的任务在地图上有标记。
- 支线任务可以放弃；主线任务不能放弃。

**FGR-QST-004 失败与重试**
- 大多数任务不会永久失败。
- 有时限的任务到期前会提前警告，到期后标为失败，并说明原因。
- 主线任务失败时（例如护送目标被毁）可以重新开始，不会卡死剧情。

**FGR-QST-005 复用**
- 在现有目标追踪后端（`CampaignObjectiveTracker`）上扩展，保留其幂等判定。

**FGR-QST-020 关键材料清单**

| 关键材料 | 来源 | 用途 |
|---|---|---|
| 监听阵列核 | 静默首领（主线） | 超控阵列 T1；监听站 |
| 熔炉心 | 铸造主核心（主线） | 超控阵列 T2 |
| 防腐涂层蓝图 | 第二幕主线任务 | 进入沉淀湖 |
| 反应核 | 化工首领（主线） | 净化塔 T3 |
| 超算残核 | 超频首领（主线） | 超控阵列 T3 |
| 巨构蓝图 | 第三幕主线 | 返航工程 |
| 登陆场坐标 | 第三幕主线（监听站破译） | 进入登陆场 |

## 6. 遗迹与人类遗产

**FGR-EXP-040 遗迹**
- 远征区域和家园地图都有遗迹点，位置由生成器决定；手工设计的遗产每个世界各出现一次（FGR-GEN-033）。
- 人类遗产分四类：
  - 旧时代蓝图：独特的组件，例如人类制式重炮。
  - 预制固件：人类协议的固件，可以直接使用。
  - 纪念物：只有背景故事，放在核心保管库的展柜里展示。
  - 数据档案：背景资料加技术数据。
- 全游戏约 20 件（**初值**），图鉴有收集页。

## 7. 正常游戏补全清单

- 世界地图：每个区域的威胁、危害、平定状态、未完成任务数。
- 区域地图的图例可以筛选。
- 三选一时可以把候选和自己已有的同类物品比较。
- 离开区域前，确认框列出：未处理的数据包、地上还没捡的战利品。
- 任务更新时发通知；追踪栏可以折叠。
- 货舱快满时预警。
- 远征相关的快捷键可以重绑。
- 图鉴有各区域、各遗迹的条目。
- 第一次拿到数据包、第一次货舱满、第一次拿到加密固件时，各有一次引导。

## 8. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 三选一时货舱已满 | 提示先丢弃或改选更小的候选，不会强行塞进去，也不会丢失 |
| 有未处理的数据包就想撤离 | 撤离确认要求先处理完 |
| 放弃远征 | 确认框写明将丢失什么；确认后按 Demo 规则结算 |
| 机器阵亡，货舱里有关键材料 | 关键材料变成地面物，其他机器可以捡回；全灭时关键材料**不会**消失，而是留在区域里，下次可以取回 |
| 转场途中静默夜开始 | 在途状态不受影响，到达时按静默夜规则处理 |
| 转场途中家园遇袭 | 正常处理，远征队继续在途 |
| 主线护送任务失败 | 可以重新开始 |
| 存档在远征途中或转场中 | 读档后状态一致，不复制物品 |
| 区域平定后 | 精英按周期刷新，首领不再刷新 |

> 关键材料不会因为全灭而永久丢失，这条优先于 Demo 的"放弃远征丢失未装载战利品"规则，目的是防止卡死主线（FG00 B11）。

## 11. 人工体验审核

1. 三选一时，玩家是否真的在权衡，而不是每次都选同一类？
2. 货舱限制是有趣的取舍，还是单纯的麻烦？
3. 每次出门，玩家是否清楚自己要去干什么？

## 12. 数值初值

| 参数 | 初值 |
|---|---|
| 单程转场 | 2 个游戏小时 |
| 增援间隔 | 3 个游戏日 |
| 平定后精英刷新 | 7 个游戏日 |
| 稀有度权重 | 普通 60、精良 30、稀有 9、原型 1 |
| 保底 | 连续 5 个数据包无稀有，则下一个必出 |
| 人类遗产总数 | 约 20 件 |
