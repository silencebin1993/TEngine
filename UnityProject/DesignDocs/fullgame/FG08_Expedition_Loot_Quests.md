## 1. 玩家目的

- 远征是**真的走过去**：从家园出发，沿着连续的地形开进敌人的领地，镜头可以一路跟着。
- **离家越远，越难兼顾家园**：信号要靠中继一路铺过去；走出覆盖范围的远征队只能执行最后的命令。
- 每次出门都**有目标**（主线、支线、想要的某件技术），也**有惊喜**（三选一）。
- 带不回所有东西，**取舍本身就是构筑**。
- 打下的领地**可以收复**：净化、建设，与家园连成一片。

## 3. 远征

### 3.1 派遣

**FGR-EXP-001 派遣检查单**
- 从机器名册或战略地图选中机器，编成远征队，指定目的地，然后派遣。
- 派遣前显示检查单，分"硬约束"和"提醒"：
  - 硬约束（不满足不能派遣）：人数在信号带宽允许范围内；至少一台机器；目的地已探索或在迷雾边缘。
  - 提醒（可以无视）：路线有一段会走出信号覆盖；货舱容量低于建议值；预计会跨过静默夜；派遣后家园劳动力下降多少；情报显示的敌方反制；机器伤势；路线经过危害带。
- 可以在派遣界面编辑信号核（远征途中不能改，FGR-SIG-011）。

**FGR-EXP-010 行军**
- 远征队沿地形实际行进，使用层级寻路（FGR-ARC-015）。行进速度取决于最慢的那台（**初值**：搬运轮式 6 格/秒，维修悬浮 5，战斗履带 3.5）。
- 战略地图上显示路线、预计到达时间；镜头可以跟随，也可以离开。
- 途中会遇到敌方巡逻、危害带、事件，可以随时改变命令。

**FGR-EXP-011 远程指挥与信号覆盖**
- 在与核心连通的信号覆盖网络内（FGR-SIG-050），远征队可以接收命令，玩家可以接入其中的机器。
- 走出覆盖范围的远征队**只执行最后一条命令**和 AI 教义；回到覆盖范围后，控制自动恢复。
- 覆盖网络靠信号中继塔（建筑）和信号中继模块（机器）延伸。"越远越难管"就是正式版里"离家"的代价。

**FGR-EXP-012 远征队状态**
- 状态：待命、行军中、交战中、返程中、已返回。在机器名册、战略地图和 HUD 上都可见。
- 远征队回到家园，或回到带仓库的前哨站，本次远征结束并结算（FGR-EXP-050）。

### 3.2 投送

**FGR-EXP-013 投送站**
- 建筑，5×5（FG04），由研究解锁（**初值：第一幕末，约 8:30**）。可以建在家园或前哨站。
- 每座投送站容纳投送舱（T1 4 个，T2 8 个）。投送舱由组件工坊生产。

**FGR-EXP-014 投送**
- 选择一个**已探索、有着陆条件**（平地、不在敌方防空覆盖内、不在危害带中心）的落点，在投送距离内（**初值：T1 3,000 格**）。
- 每个投送舱载 1 台机器（连同它的货舱），或者 20 个单位的货物（例如施工材料）。
- 飞行速度 **初值 60 格/秒**，加 5 秒着陆；消耗燃油（**初值：每舱每 1,000 格 30 燃油**）；每次飞行后冷却 60 秒。
- **敌方防空**：铸造的对空高炮、白潮的护卫无人机会形成防空覆盖，覆盖区内不能着陆，地图上用红色区域标出。要空降进去，先得把防空打掉。

**FGR-EXP-015 回收**
- 在任何有着陆条件的地点呼叫回收：投送舱从投送站飞过去，把机器和货物一起带回来，按"远征卸货"规则卸到仓库或解析台（FG04）。
- 回收是正式的"撤离"方式：把满载的远征队或伤员快速带回。

**FGR-EXP-016 投送与静默夜**
- 静默夜期间不能发起投送或回收（没有信号）。已经在飞的投送舱按自动驾驶飞完，降落在原定地点。

### 3.3 前哨站

**FGR-EXP-017 前哨站**
- 离核心 300 格以外的建筑群，自动归为一个"前哨站"（玩家可以改名）。**不设第二个核心**。
- 常见用途：延伸信号覆盖（信号中继塔）、前线维修（维修台）、补给（仓库，可以接传送带）、防守（炮塔）、开采远处的富矿、第二个投送站。
- 前哨站可以有自己的发电，也可以用电塔接回家园电网（FGR-LOG-060）。

**FGR-EXP-018 远程施工与补给**
- 前哨站的施工虚影照常生成施工工作单（FG03）。材料可以由机器走过去运，也可以用传送带铺过去，或者用投送舱送"施工包"。
- 机器可以设为"前哨劳动"岗位，常驻某个前哨站（FG04 FGR-ECO-040）。

**FGR-EXP-019 前哨的防守**
- 前哨站会被突袭，靠近阵营领地的前哨更容易被盯上（FG06）。
- 前哨站被全部摧毁不会导致战役失败（只有归还核心被毁才失败），但损失的建筑要重建。

### 3.4 阵营领地

**FGR-EXP-020 领地**
- 四个阵营领地位于同一张地图的不同方向和距离上（FGR-GEN-021），用地理软门槛控制开放顺序（FGR-GEN-022）：

| 领地 | 阵营 | 幕 | 中心离核心 | 门槛 |
|---|---|---|---|---|
| 破碎都市 | 静默 | 第一幕 | 400～600 格 | 无 |
| 铸造前哨（外围 + 核心区） | 铸造 | 第一幕 | 700～1,000 格 | 核心区大门（沿用 Demo 核心门禁）；对空高炮阻止空投 |
| 沉淀湖 | 化工（澄净） | 第二幕 | 1,200～1,600 格 | 外圈酸沼带；防腐涂层由主线给出 |
| 热寂数据城 | 超频 | 第二幕 | 1,500～2,000 格 | 外圈高温辐射带；需要散热方案 |
| 白潮滩头 | 舰队（白潮） | 第三幕 | 900～1,400 格 | 揭示后出现（FGR-GEN-041） |

- 领地之外是无限的外延区，用于后期和后日谈探索（FGR-GEN-040）。

**FGR-EXP-021 持久化**
- 领地是世界的一部分，按区块差异保存（FGR-GEN-060）：已探索的迷雾、被摧毁的敌方建筑、已开启的遗迹点和终端、据点状态。

**FGR-EXP-022 领地控制、增援与收复**
- 每个领地有**控制度**（0～100），来自其中仍然活跃的据点。
- 首领被击败之前，阵营每 3 个游戏日（**初值**）增援一次，被摧毁的据点有可能重建。
- 首领被击败后，领地进入**平定**：不再增援，控制度随剩余据点被摧毁而下降。
- 控制度降到 20 以下（**初值**），领地变为**已收复**：敌方巡逻消失，土地可以建设；危害区和污染仍在，可以用净化塔逐步净化，净化后计入归还面积（FGR-ENV-042）。
- 已收复的领地里，精英残部每 7 个游戏日刷新一次，可以用来刷材料；首领不再刷新。
- 战略地图上显示每个领地的范围、控制度和状态（敌控、平定中、已收复）。

**FGR-EXP-030 领地内容**
- 领地里有：主线目标、支线目标、已知精英、终端、遗迹点、资源缓存、室内场地入口（FGR-GEN-042）。战略地图上标出，图例可以筛选。

### 3.5 返回、全灭与结算

**FGR-EXP-031 返回与全灭**
- **返回**：命令远征队走回家园或前哨站，或者呼叫投送舱回收（FGR-EXP-015）。
- **全灭**：远征队全部阵亡时，本次远征按全灭结算；货物和黑匣子留在原地（FGR-EXP-032）。信号若在其中一台机器里，弹回核心。

**FGR-EXP-032 地上的战利品与阵亡掉落**
- 机器阵亡时，它货舱里的东西和黑匣子掉在原地，其他机器可以捡起来。
- 没被带走的**普通战利品**留在地上，**1 个游戏日后被敌方回收并消失**（**初值**）。这保证了"带不回所有东西"的取舍依然有意义。
- **关键材料永远不会消失**，一直留到被捡回为止（防止主线被卡死）。
- 离开一片区域前，界面会列出地上还没捡的战利品。

**FGR-EXP-050 远征结算**
- 远征队回到家园或带仓库的前哨站时结算：带回的物品、三选一的选择记录、任务进度、生成的熔合线索（FG05）、暴露变化、远征耗时、机器经历更新。
- 货物按"远征卸货"规则送到仓库或解析台（FG04）。

## 4. 掉落

**FGR-LOOT-001 物品协议**
每件物品都有协议字段，决定它的去向：

| 协议 | 例子 | 去向 |
|---|---|---|
| 己方 | 自产的组件、固件 | 直接使用 |
| 中立 | 人类遗产、中立协议的固件和组件、材料、耗材 | **直接使用**：带回来就能装配，或直接进产线 |
| 敌方加密 | 敌方固件、敌方接口组件、未解析模块、数据核心 | **需要反破解**：送解析台（FG05）；敌方固件在破解前可以由核心"裸跑"（FGR-SIG-060） |

- 界面上用图标加文字标明协议，并在详情里写明"需要解析"或"可直接使用"。

**FGR-LOOT-010 掉落来源**

| 来源 | 内容 | 方式 |
|---|---|---|
| 杂兵 | 废料、金属矿、稀土矿，小概率常见固件 | 普通掉落 |
| 精英 | 组件、稀有固件、加密数据 | 三选一数据包 |
| 首领 | 该阵营的核心固件和关键材料（固定），另加一个三选一数据包 | 固定 + 三选一 |
| 据点 | 材料、少量组件；摧毁时可能掉数据核心 | 普通掉落 |
| 遗迹终端 | 蓝图、人类遗产、背景资料 | 固定 |
| 资源缓存 | 成批材料 | 固定 |
| 任务 | 关键材料 | 固定，不随机 |
| 事件 | 视事件而定（FG10） | 三选一或固定 |

**FGR-LOOT-020 三选一数据包**
- 精英死亡或事件完成时生成一个"待分拣数据包"。**不在战斗中弹出**，只在 HUD 上显示计数（"待分拣 ×3"）。
- 处理时机：远征队回到家园或带仓库的前哨站时，或者在战略暂停中随时处理。面板显示 3 个候选，每个写明类型、稀有度、协议、占用货舱空间；从未见过的标"新"。
- 选 1 个装进货舱。货舱放不下时，提示先丢弃别的东西或改选更小的候选。
- 没选的两个自动转化为少量技术数据（数字资源，不占货舱）。

**FGR-LOOT-021 候选池**
- 候选池 = 当前领地阵营池 + 通用池。
- 按稀有度抽取：普通 60%、精良 30%、稀有 9%、原型 1%（**初值**）。
- 同一个数据包内不重复。
- **保底**：连续 5 个数据包没有出现稀有及以上，下一个数据包必定有一个稀有位。

**FGR-LOOT-022 数据包不会丢**
- 数据包存在远征队身上，不占货舱；机器阵亡时，数据包转到同队其他机器上；全灭时留在原地，和关键材料一样永不消失。

**FGR-LOOT-030 货舱**
- 货舱容量来自底盘（搬运轮式最大）和货舱结构模块。
- 物品占用空间（**初值**）：

| 物品 | 占用 |
|---|---|
| 材料 | 每 10 个占 1 |
| 固件 | 1 |
| 组件 | 3 |
| 数据核心 | 2 |
| 未解析模块 | 3 |
| 人类遗产 | 2 |
| 黑匣子 | 1 |

- 货舱界面：全队总容量条，每台机器的明细。
- 可以丢弃物品；在战略暂停中，可以在机器之间转移物品。
- 自动拾取：按材料种类开关（例如"自动拾取稀土矿：开"）。

## 5. 任务

**FGR-QST-001 任务类型**
- **主线**：推进剧情，给出关键材料，引导玩家进入下一个领地。
- **支线**：领地任务，例如救援遗迹、摧毁监听节点、护送货物、夺回数据、清剿精英、调查异常、建立前哨。
- **家园指引**：可选的引导目标，例如"建造第一条传送带""撑过第一次静默夜"，给少量奖励；可以在设置里关闭。

**FGR-QST-002 任务来源**
- 任务来自核心备忘、监听站截获、终端和遗迹，**不做对话树**（沿用 GDD 的非目标）。

**FGR-QST-003 任务面板**
- 分"进行中 / 已完成 / 已失败"三栏。每个任务写明目标、位置、奖励预览、有无时限。
- 可以把最多 3 个任务固定到 HUD 的追踪栏；追踪中的任务在战略地图上有标记，可以一键让镜头飞过去。
- 支线任务可以放弃；主线任务不能放弃。

**FGR-QST-004 失败与重试**
- 大多数任务不会永久失败。有时限的任务到期前会提前警告，到期后标为失败，并说明原因。
- 主线任务失败时（例如护送目标被毁）可以重新开始，不会卡死剧情。

**FGR-QST-005 复用**
- 在现有目标追踪后端（`CampaignObjectiveTracker`）上扩展，保留其幂等判定。

**FGR-QST-020 关键材料清单**

| 关键材料 | 来源 | 用途 |
|---|---|---|
| 监听阵列核 | 寂听主脑（主线） | 超控阵列 T1；监听站 |
| 熔炉心 | 铸造主核心（主线） | 超控阵列 T2 |
| 防腐涂层蓝图 | 第二幕主线任务 | 安全穿过沉淀湖外圈的酸沼带 |
| 反应核 | 洗礼塔（主线） | 净化塔 T3 |
| 超算残核 | 余烬主机（主线） | 超控阵列 T3 |
| 巨构蓝图 | 第三幕主线 | 返航工程 |

## 6. 遗迹与人类遗产

**FGR-EXP-040 遗迹**
- 遗迹点分布在全世界，位置由生成器决定；手工设计的遗产每个世界各出现一次（FGR-GEN-033）。
- 人类遗产分四类：
  - 旧时代蓝图：独特的组件，例如人类制式重炮。
  - 预制固件：人类协议的固件，可以直接使用。
  - 纪念物：只有背景故事，放在核心保管库的展柜里展示。
  - 数据档案：背景资料加技术数据。
- 全游戏约 20 件（**初值**），图鉴有收集页。

## 7. 正常游戏补全清单

- 战略地图：领地范围、控制度、状态；己方前哨站、远征队、路线、预计到达时间；信号覆盖网络（断开处高亮）；敌方防空覆盖；未完成任务。
- 远征队可以改名、设颜色；按数字组快捷键选择（FG13）。
- 远征队走出覆盖范围前、进入危害带前、进入敌方领地时，各有提示。
- 三选一时可以把候选和自己已有的同类物品比较。
- 离开一片区域前，列出地上还没捡的战利品和它们消失的倒计时。
- 任务更新时发通知；追踪栏可以折叠。
- 货舱快满时预警。
- 前哨站总览面板：各前哨的建筑、供电、防御、补给、覆盖是否连通（FGU-47）。
- 投送站面板：投送舱数量、目标选择、燃油、飞行时间、防空警告（FGU-46）。
- 远征相关的快捷键都可以重绑。
- 图鉴有各领地、各遗迹、投送、前哨站的条目。
- 以上各项"第一次"的引导只埋钩子，内容在 FG15-UX-04 实现。

## 8. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 远征队走出信号覆盖 | 继续执行最后的命令；回到覆盖后控制恢复；不能接入其中的机器 |
| 投送落点在敌方防空覆盖内 | 拒绝，地图上显示防空范围 |
| 投送舱在飞行途中静默夜开始 | 按自动驾驶飞完，降落在原定地点 |
| 投送站在远征期间被突袭摧毁 | 在飞的投送舱改为降落在最近的另一座投送站；没有别的投送站时，降落在原定地点附近 |
| 三选一时货舱已满 | 提示先丢弃或改选更小的候选，不会强行塞进去，也不会丢失 |
| 远征队全灭，身上有关键材料和数据包 | 留在原地，永不消失，可以再派人取回 |
| 普通战利品留在地上超过 1 个游戏日 | 被敌方回收消失；消失前有倒计时提示 |
| 前哨站被全部摧毁 | 不导致战役失败；虚影保留，自动重建规则照常生效 |
| 领地已收复后，玩家在里面建设 | 正常建设；危害区和污染需要净化 |
| 主线护送任务失败 | 可以重新开始 |
| 在行军中、投送途中、领地内存档 | 读档后状态一致，不复制物品 |
| 镜头不在远征队那里时，远征队发生战斗 | 结果与镜头在时一致（FGR-BASE-021） |
