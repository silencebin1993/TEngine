# FG17 世界生成（单一无缝世界、种子、表面）

> 需求前缀：`FGR-GEN`；测试前缀：`FGT-GEN`。
> 里程碑：FG-M0（技术验证）、FG-M3（世界生成器与家园区）、FG-M8（阵营领地与室内场地）、FG-M9～M13（各阵营模板与手工锚点）、FG-M14（沙盒世界设置）、FG-M15（种子测试集）；多星球见里程碑文档的候选里程碑 FG-X1。
> 来源：用户推翻 D-20（要求程序动态生成、环境可以无限生成、可能做多星球、用唯一随机种子保证存读档），并于 2026-09-24 选定**单一无缝世界**：每个星球一张连续地图，家园与各阵营领地共享地形，镜头无缝。
> 架构：[FG14](FG14_Tech_Architecture_Migration.md) FGR-ARC-001、002、008、010、013～016。契约：[FG00](FG00_Completeness_Addendum.md)（B25 种子无关性）。

---

## 1. 玩家目的

- **每个新存档都是一个新世界**：地形、资源、废墟、敌方据点和阵营领地的方位都不一样。
- **世界是连续的**：从家园出发，可以一路开到敌人的领地；镜头可以一路跟过去，也可以一路缩放到整个世界。
- **"归还"是字面意思**：净化前线一格一格推向敌人，打下的领地可以净化、建设，与家园连成一片。
- **同一个种子生成同一个世界**：可以分享种子，存读档稳定。
- **剧情和首领的关键体验仍然是精心设计的**（手工锚点），随机性不会破坏高潮。

---

## 2. 结构

| 项 | 规则 |
|---|---|
| 星球 | 每个星球是一张**连续、无限**的地图（表面）。v1 只有地球 |
| 家园 | 归还核心在地图原点；核心周围是家园区，开局有保证（3.4） |
| 阵营领地 | 静默、铸造、澄净（化工）、超频四个领地，位于**同一张地图**的不同方向和距离上（3.3） |
| 白潮滩头 | 揭示之后，出现在一块预留区域（3.6） |
| 外延区 | 领地之外继续无限生成，四个阵营的零散前哨、更高的威胁和奖励（用于后日谈） |
| 室内场地 | 地下中继大厅（寂听主脑）、数据中心（余烬主机）从地表入口进入，是独立的小表面（3.7） |
| 镜头 | 在星球上**全程无缝**：可以从机器身边连续缩放到世界地图；只有进出室内场地时有过渡 |
| 多星球 | 架构上预留（3.2），内容为候选里程碑 FG-X1 |

## 3. 需求

### 3.1 种子

**FGR-GEN-001 世界种子**
- 新游戏时随机生成一个种子，也可以由玩家输入。
- 种子显示在新游戏设置、暂停菜单和存档卡片上，可以一键复制。

**FGR-GEN-002 确定性**
- （种子，生成器版本，世界设置）相同，生成的世界**逐格一致**。
- **与访问顺序无关**：每个区块只由种子、表面和区块坐标决定。领地位置、河流、矿带、据点分布、锚点位置等大结构，由一个按种子计算的粗粒度"区域规划层"决定（3.3），不依赖玩家先去了哪里。

**FGR-GEN-003 随机流分离**
- 世界生成的随机数，与玩法随机数（掉落、突袭、事件、天气）分开（FGR-ARC-010）。多打一场仗，不会改变还没生成的地形。

### 3.2 表面

**FGR-GEN-010 表面抽象**
- 表面有两种类型：**星球**（连续、无限的主地图）和**室内**（从入口进入的有限小地图）。
- 每个表面有自己的种子（由世界种子和表面编号派生）、独立的区块存储、独立的模拟。
- v1：地球（星球）；地下中继大厅、数据中心（室内）。

**FGR-GEN-011 多星球（预留）**
- 以后新增星球时，不能破坏存档格式；任何系统都不能假设"只有一个星球"。
- v1 不做多星球内容，见候选里程碑 FG-X1。

### 3.3 区域规划层与阵营领地

**FGR-GEN-020 区域规划层**
- 开局时按种子计算一张粗粒度的规划图，决定：各阵营领地的方向、中心、范围；危害带；白潮滩头的预留区；主要河流与矿带。
- 规划层只依赖种子和世界设置，计算量小，读档时重新计算，不需要存档。

**FGR-GEN-021 领地方位（初值）**

| 领地 | 幕 | 中心离核心 | 半径 | 外圈危害带 |
|---|---|---|---|---|
| 静默·破碎都市 | 第一幕 | 400～600 格 | 约 250 格 | 无（领地内部有电磁噪声区） |
| 铸造·铸造前哨（外围 + 核心区） | 第一幕 | 700～1,000 格 | 约 300 格 | 无（领地内部有熔渣热区） |
| 澄净·沉淀湖 | 第二幕 | 1,200～1,600 格 | 约 350 格 | 酸沼带，宽约 100 格 |
| 超频·热寂数据城 | 第二幕 | 1,500～2,000 格 | 约 350 格 | 高温辐射带，宽约 100 格 |
| 白潮滩头（预留区） | 第三幕 | 900～1,400 格 | 约 250 格 | 揭示后出现 |

- 四个领地按种子分配到不同方向，**彼此的方向夹角至少 60°**，领地之间不重叠。
- 领地与普通地形之间平滑过渡：越往领地中心，地貌越接近该阵营的风格，据点越密。
- 家园区（核心半径 200 格内）不会出现任何阵营领地。

**FGR-GEN-022 地理门槛（软门槛）**
- 不用看不见的墙，而用地理和危害控制开放顺序：
  - 铸造核心区：沿用 Demo 的核心门禁（锚点处的大门）。
  - 沉淀湖：外圈酸沼带；没有防腐涂层时能进去，但会持续受到重度腐蚀。
  - 热寂数据城：外圈高温辐射带；没有散热方案时热量上限大幅降低。
- 任务和情报会引导玩家按幕推进，但不硬性阻止玩家提前闯入。

**FGR-GEN-023 领地模板**
每个领地按模板生成：地貌风格和场景物件、危害区分布、敌方据点的类型和密度、巡逻路线、资源缓存、终端、遗迹点、支线任务地点。

**FGR-GEN-024 手工锚点**
- 手工设计的关键地点，按规则嵌入领地：
  - 首领场地：铸造主核心所在的核心区、洗礼塔的湖心平台（地表）；地下中继大厅、数据中心的入口（进入室内，3.7）。
  - 主线剧情地点、伏笔地点（例如铸造的对空阵地）。
  - Demo 手工地图的关键部分。
- 放置规则：在领地内的距离范围、保证从家园出发可达（层级寻路校验，FGR-ARC-015）、锚点之间不重叠、边缘与周围地形平滑过渡。

### 3.4 家园区

**FGR-GEN-030 地形与分层**
- 生成：地形（可建地、水源、油井、金属矿脉、稀土矿脉、废墟、悬崖）、污染（0～3 级，总体离核心越远越高，中间有局部浓淡）、资源点（成簇分布）、废墟群、遗迹点、零散的敌方侦察巢。

**FGR-GEN-031 起始区保证（关键）**
- 以归还核心为中心：
  - 半径 12 格内：污染 ≤ 1，没有悬崖。
  - 半径 24 格内：足够放下开局预置建筑的平地（FGR-ARC-001 开局布局表）；至少 1 处水源、1 处金属矿脉、1 片废墟群（废料储量不少于第一幕前两小时的需求）。
  - 半径 64 格内：没有敌方建筑；至少 1 处稀土矿脉。
  - 半径 128 格内：至少 1 处油井。
- 某项保证不满足时，只对这一项用派生子种子确定性地重新生成，不重生成整个世界。

**FGR-GEN-032 距离与威胁**
- 离核心越远：资源越丰富，污染越重，零散据点越强。
- 突袭导演按"离目标最近的活跃据点"决定突袭从哪里出发（FG06 FGR-DEF-023）。

**FGR-GEN-033 遗迹点**
- 遗迹点由生成器分布在全世界。
- 手工设计的人类遗产（约 20 件，FG08）**每个世界各出现一次**，按幕分配到对应的距离范围。剧情需要的遗产保证可以到达。

**FGR-GEN-034 敌方据点**
- 据点分布在各阵营领地里（主力），以及领地之间和外延区（零散）。
- 据点是突袭的出发地，也是领地"控制度"的来源（FG08 FGR-EXP-022）。
- 摧毁据点会降低这个方向的突袭频率，并掉落战利品。

### 3.5 外延区

**FGR-GEN-040 无限外延**
- 领地之外（离核心约 2,500 格以外）继续按需生成，四个阵营的零散前哨与更高的威胁和奖励，一直延伸下去。用于后期和后日谈的无限探索。
- 首领被击败后，更远处尚未探索的区块里，仍然可能生成该阵营的新前哨，让无限探索一直有目标。规则是确定性的。

### 3.6 白潮滩头

**FGR-GEN-041 预留与出现**
- 区域规划层在开局就预留一块区域（FGR-GEN-021），揭示之前它只是普通地形，没有任何提示。
- 揭示时，舰队在这里着陆：空投结构、焦土、屏蔽塔按规则生成在预留区里（FG11）。
- 预留区不会与其他领地、家园区重叠，保证可达。

### 3.7 室内场地

**FGR-GEN-042 室内**
- 地下中继大厅、数据中心是手工设计为主的室内表面，从领地里的地表入口进入。
- 进出入口时有过渡（**这是星球上唯一不无缝的地方**），室内与地表同时运行（FGR-ARC-002）。
- 进入室内视为进入首领战场地：触发进入首领战前的自动存档（沿用 `BossEngageEnter`）。

### 3.8 区块与按需生成

**FGR-GEN-050 区块**
- 表面划分为区块（**初值：32 × 32 格**）。进入"已探索范围 + 2 个区块的预生成边距"时才生成。
- 生成在工作线程完成（地形噪声等计算放在 AOT 内核，用 Burst），主线程只负责接入结果。单个区块的工作线程耗时 ≤ 5 毫秒（**初值**）。

**FGR-GEN-051 坐标**
- 为避免浮点精度问题，坐标存为"区块索引 + 区块内偏移"。实际可达范围写明上限（**初值：原点 ±1,000,000 格**）。

**FGR-GEN-052 活跃与休眠**
- 有己方建筑或单位、有正在行进的突袭或巡逻、或者正在被观察的区块，完整模拟。
- 纯地形区块不需要模拟。
- 离所有己方实体都很远（**初值：超过 300 格**）的敌方据点和巡逻处于**休眠**，被惊动（己方单位靠近、突袭导演调用、事件触发）时再按确定性规则唤醒。
- 以上规则不改变 FGR-BASE-021：有己方实体的区域，无论是否被观察都完整运行。

### 3.9 持久化与存档

**FGR-GEN-060 差异存档**
- 存档记录：种子、生成器版本、世界设置。
- 每个区块的状态分三种：未生成、已生成未修改、已修改。**只有被修改过的区块才保存差异**（例如废墟拆完、污染变化、建筑、地面物、据点被摧毁）。已生成但未修改的区块在读档时按种子重新生成。

**FGR-GEN-061 生成器版本**
- 任何会改变生成结果的改动，都必须提升生成器版本号。
- 读取旧存档时，尚未被修改的区块用**存档记录的那个生成器版本**来生成（保留旧版本的生成路径或数据快照）。
- 自动测试：对若干（种子，版本）组合保存样本区块的哈希值，作为回归基准。

**FGR-GEN-062 存档体积**
- 存档体积随**被修改的面积**增长，而不是随探索面积增长。目标见 FG15。

### 3.10 世界设置

**FGR-GEN-070 新游戏设置**
- 种子；资源丰度（低、标准、高）；敌方据点密度（低、标准、高）；污染强度（低、标准、高）；领地距离（近、标准、远：按比例缩放 FGR-GEN-021 的距离）；起始区（标准、宽松）。
- 剧情模式始终开启起始区保证；沙盒有更多选项（FG12）。

**FGR-GEN-071 种子分享**
- 把种子和世界设置打包成一段短码（例如 `BGR-XXXX-XXXX-XXXX`），可以复制和导入。

### 3.11 地图与镜头

**FGR-GEN-080 连续缩放的地图**
- 镜头可以从机器身边连续缩放到整个已探索的世界；缩得足够远时切换为"战略地图"表现（图标化、按类型筛选），不再逐个绘制实体。
- 战略地图上显示：已探索区域与迷雾、阵营领地的范围和控制度、己方建筑群与前哨、远征队、突袭路线、信号覆盖网络、玩家标记、任务、遗迹、资源。
- 点击任意位置或通知，镜头飞过去（过渡**初值：0.5 秒**）。

**FGR-GEN-081 小地图**
- 显示镜头附近的区域，支持同样的标记和筛选。

### 3.12 种子健康

**FGR-GEN-090 生成校验**
- 规划层和起始区、锚点布局生成后，立即运行校验：起始区保证、领地互不重叠且方向夹角达标、锚点可达、室内入口可达、白潮滩头预留区可达。
- 校验失败时，对失败项做确定性的局部重生成，并写日志。

**FGR-GEN-091 种子测试集**
- 固定一组测试种子（**初值：50 个**），每个里程碑出口都跑一遍全部校验；其中 3 个种子跑完整的旅程机器人。

## 4. 正常游戏补全清单

- 种子随处可见、可以复制；新游戏界面有"随机种子"按钮。
- 存档卡片显示种子和世界设置摘要。
- 战略地图支持玩家自定义标记和备注。
- "回到归还核心"（Home）和"跟随选中对象"（F）的快捷键在无缝大地图上尤其重要。
- 进入某个阵营领地、接近危害带时，HUD 给出提示，并显示该领地的名字。
- 镜头移动过快、区块还没生成好时，显示"生成中"的占位地貌，**绝不阻塞主线程**。
- 暂停菜单里可以查看当前世界的设置。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 某个种子的起始区保证或领地布局校验失败 | 对失败项确定性局部重生成；同一种子每次结果相同 |
| 玩家去到非常远的地方 | 坐标用区块索引，不出现精度抖动；超过上限时给出提示 |
| 镜头快速平移或从世界地图直接飞到远处 | 显示占位地貌，后台生成，主线程不卡顿 |
| 在区块边界上存读档 | 实体、传送带、流体跨区块时状态一致 |
| 读取生成器版本较旧的存档 | 未修改区块按旧版本生成；已修改区块按差异恢复 |
| 世界设置取极端值（资源低 + 据点高 + 污染高 + 领地近） | 起始区保证仍然成立，第一幕仍然可以推进 |
| 休眠据点附近突然出现己方单位 | 按确定性规则唤醒；唤醒前后的状态与"一直在模拟"时一致 |
| 锚点放置与悬崖、水域冲突 | 按规则挪位或平整地形，保证可达 |
| 两个存档用同一个种子 | 生成的世界完全相同 |

## 6. 存档

种子、生成器版本、世界设置、各表面的区块状态与差异、据点状态、玩家标记。区域规划层不存档，读档时按种子重算。

## 7. 性能（初值，统一见 FG15）

| 指标 | 目标 |
|---|---|

| 主线程接入一个区块 | ≤ 0.5 毫秒 |

| 存档体积 | 随修改面积增长；后期 ≤ 50 MB（与 FG15 一致） |

## 9. 人工体验审核

1. 从家园一路开到敌人领地时，有没有"这是一个连续的世界"的感觉？
2. 生成的世界看起来是"有人设计过的"，还是"随机拼凑的"？锚点和周围地形衔接得自然吗？
3. 通关后，玩家会不会想用新种子再开一局？
