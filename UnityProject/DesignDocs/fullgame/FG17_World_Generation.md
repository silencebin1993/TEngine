# FG17 世界生成（程序生成、种子、表面）

> 需求前缀：`FGR-GEN`；测试前缀：`FGT-GEN`。
> 里程碑：FG-M0（技术验证）、FG-M3（家园生成器）、FG-M8（远征区域生成器）、FG-M9～M13（各阵营模板与手工锚点）、FG-M14（沙盒世界设置）、FG-M15（种子测试集）；多星球见里程碑文档的候选里程碑 FG-X1。
> 来源：用户推翻 D-20（原决策"不做多家园、开放世界、无限程序生成"），要求：程序动态生成、环境可以无限生成、可能做多星球、用唯一随机种子保证存读档。
> 架构：[FG14](FG14_Tech_Architecture_Migration.md) FGR-ARC-001、002、008、010、013、014。契约：[FG00](FG00_Completeness_Addendum.md)（B25 种子无关性）。

---

## 1. 玩家目的

- **每个新存档都是一个新世界**：地形、资源、废墟、敌方据点都不一样，重玩有新鲜感。
- **世界没有边界**：可以一直往外探索、收复、扩张。
- **同一个种子生成同一个世界**：可以把种子分享给朋友；存读档稳定可靠。
- **剧情和首领的关键体验仍然是精心设计的**：随机性不会破坏高潮。

---

## 2. 结构决定

- **保留"家园 + 远征区"两层结构**。转场、"只有一道信号"的两难、远征时家园遇袭，这些核心机制都依赖两层结构。
- 两层**都按种子程序生成**：
  - 家园：一张无限的生成地图，开局附近有保证（第 3.4 节）。
  - 远征区：每个阵营的领地是一张按阵营模板生成的地图，关键地点用**手工锚点**嵌入（第 3.5 节）。
- Demo 的三张手工地图（归还谷地、破碎都市、铸造前哨）不再作为固定地图，它们的关键部分转为**手工锚点模板**。
- 多星球：架构上用"表面"抽象预留（第 3.2 节），内容暂不排期。

## 3. 需求

### 3.1 种子

**FGR-GEN-001 世界种子**
- 新游戏时随机生成一个种子，也可以由玩家输入。
- 种子显示在新游戏设置、暂停菜单和存档卡片上，可以一键复制。

**FGR-GEN-002 确定性**
- （种子，生成器版本，世界设置）相同，生成的世界**逐格一致**。
- **与访问顺序无关**：每个区块只由种子、表面和区块坐标决定。跨区块的大结构（河流、矿带、据点分布、锚点位置）由一个按种子计算的粗粒度"区域规划层"决定，不依赖玩家先去了哪里。

**FGR-GEN-003 随机流分离**
- 世界生成的随机数，与玩法随机数（掉落、突袭、事件、天气）分开（FGR-ARC-010）。玩法随机流的种子由世界种子派生，但互不影响：多打一场仗不会改变还没生成的地形。

### 3.2 表面

**FGR-GEN-010 表面抽象**
- 世界由若干"表面"组成。每个表面有：类型、自己的种子（由世界种子和表面编号派生）、独立的区块存储、独立的模拟（FGR-ARC-002）。
- v1 的表面：家园（地球·归还谷地）；静默、铸造、化工、超频四个阵营领地；登陆场。

**FGR-GEN-011 多星球（预留）**
- 以后新增"星球"类型的表面时，不能破坏存档格式。
- v1 不做多星球内容，见里程碑文档的候选里程碑 FG-X1。

### 3.3 区块与按需生成

**FGR-GEN-020 区块**
- 表面划分为区块（**初值：32 × 32 格**）。
- 进入"已探索范围 + 2 个区块的预生成边距"时才生成。
- 生成在工作线程完成（地形噪声等计算放在 AOT 内核，用 Burst），主线程只负责接入结果。单个区块的工作线程耗时 ≤ 5 毫秒（**初值**）。

**FGR-GEN-021 无限与坐标**
- 表面原则上没有边界。
- 为避免浮点精度问题，坐标存为"区块索引 + 区块内偏移"。实际可达范围写明上限（**初值：原点 ±1,000,000 格**）。

**FGR-GEN-022 模拟范围**
- 有己方建筑或单位、有进行中的突袭、或者正在被观察的区块，完整模拟。
- 纯地形区块不需要模拟。
- 未被发现的敌方据点处于休眠，直到被发现或被突袭导演调用。整个过程是确定性的。
- 以上规则不改变 FGR-BASE-021：有己方实体的区域，无论是否被观察都完整运行。

### 3.4 家园生成器

**FGR-GEN-030 地形与分层**
- 生成：地形（可建地、水源、油井、金属矿脉、稀土矿脉、废墟、悬崖）、污染（0～3 级，总体离起点越远越高，中间有局部浓淡）、资源点（成簇分布）、废墟群、遗迹点、敌方据点。

**FGR-GEN-031 起始区保证（关键）**
- 以归还核心为中心：
  - 半径 12 格内：污染 ≤ 1，没有悬崖。
  - 半径 24 格内：足够放下开局预置建筑的平地（FGR-ARC-001 的开局布局表）；至少 1 处水源、1 处金属矿脉、1 片废墟群（废料储量不少于第一幕前两小时的需求）。
  - 半径 64 格内：没有敌方建筑；至少 1 处稀土矿脉。
  - 半径 128 格内：至少 1 处油井（第二幕需要）。
- 某项保证不满足时，只对**这一项**用派生子种子确定性地重新生成，不重生成整个世界。

**FGR-GEN-032 距离分环**
- 按离核心的距离分环（**初值**：0～64 格安全，64～160 格中等，160 格以外危险）。
- 离得越远：资源越丰富，污染越重，敌方据点越强。
- 突袭导演用分环决定突袭从哪里来、有多强（FG06 FGR-DEF-023）。

**FGR-GEN-033 家园遗迹点**
- 遗迹点的位置由生成器决定。
- 手工设计的人类遗产（约 20 件，FG08）**每个世界各出现一次**，按幕分配到对应的距离环里。剧情需要的遗产保证可以到达。

**FGR-GEN-034 家园敌方据点**
- 在家园 160 格以外生成侦察巢和前哨。
- 突袭优先从所选阵营最近的活跃据点出发；没有合适据点时，从迷雾边界"远方来袭"作为兜底。
- 摧毁据点会降低该方向的突袭频率，并掉落战利品。

### 3.5 远征区域生成器

**FGR-GEN-040 阵营模板**
每个阵营领地按模板生成：
- 地貌风格和场景物件
- 危害区的分布（电磁噪声、熔渣热区、酸沼、高温辐射）
- 敌方据点的类型和密度
- 资源缓存、终端、遗迹点、撤离点、支线任务地点

**FGR-GEN-041 手工锚点**
- 手工设计的关键地点，按规则嵌入生成的地图：
  - 首领场地：寂听主脑的地下中继大厅、铸造主核心所在的核心区、洗礼塔的湖心平台、余烬主机的数据中心、登陆场的旗舰降落区。
  - 主线剧情地点、伏笔地点（例如铸造的对空阵地）。
  - Demo 手工地图的关键部分。
- 放置规则：离入口的距离范围、保证路径可达（放置后做寻路校验）、锚点之间不重叠、边缘与周围地形平滑过渡。

**FGR-GEN-042 入口与撤离点**
- 每个领地都有一个入口（远征队到达的位置），并至少有 2 个可以到达的撤离点。

**FGR-GEN-043 主区域与外延**
- 每个领地有一个包含所有锚点的"主区域"（**初值：半径 256 格**），其中的威胁和奖励按幕设计。
- 主区域之外继续按需生成，威胁和奖励随距离上升。这部分用于后期和后日谈的无限探索。

**FGR-GEN-044 动态据点**
- 首领被击败后，领地进入平定状态（FG08 FGR-EXP-022）。
- 更远处还没被探索的区块里，仍然可能生成新的敌方前哨，让无限探索一直有目标。生成规则是确定性的。

### 3.6 持久化与存档

**FGR-GEN-050 差异存档**
- 存档记录：种子、生成器版本、世界设置。
- 每个区块的状态分三种：未生成、已生成未修改、已修改。
- **只有被修改过的区块才保存差异**（例如废墟拆完、污染变化、建筑、地面物）。已生成但未修改的区块在读档时按种子重新生成。

**FGR-GEN-051 生成器版本**
- 任何会改变生成结果的改动，都必须提升生成器版本号。
- 读取旧存档时，尚未被修改的区块用**存档记录的那个生成器版本**来生成（保留旧版本的生成路径或数据快照）。
- 自动测试：对若干（种子，版本）组合保存样本区块的哈希值，作为回归基准。

**FGR-GEN-052 存档体积**
- 存档体积随**被修改的面积**增长，而不是随探索面积增长。目标见 FG15。

### 3.7 世界设置

**FGR-GEN-060 新游戏设置**
- 种子；资源丰度（低、标准、高）；敌方据点密度（低、标准、高）；污染强度（低、标准、高）；起始区（标准、宽松）。
- 剧情模式始终开启起始区保证；沙盒有更多选项（FG12）。

**FGR-GEN-061 种子分享**
- 把种子和世界设置打包成一段短码（例如 `BGR-XXXX-XXXX-XXXX`），可以复制和导入。

### 3.8 地图与探索界面

**FGR-GEN-070 世界地图**
- 按表面显示已探索的区块，未探索的部分覆盖迷雾。
- 可以缩放；标记玩家自定义的点、任务、遗迹、据点、资源；可以按类型筛选和搜索。
- 显示每个表面的探索面积。

**FGR-GEN-071 小地图**
- 显示当前表面，支持同样的标记和筛选。

### 3.9 种子健康

**FGR-GEN-080 生成校验**
- 生成起始区和锚点布局后，立即运行校验：可达性、起始区保证、锚点不重叠、撤离点可达。
- 校验失败时，对失败项做确定性的局部重生成，并写日志。

**FGR-GEN-081 种子测试集**
- 固定一组测试种子（**初值：50 个**），每个里程碑出口都跑一遍全部校验；其中 3 个种子跑完整的旅程机器人。

## 4. 正常游戏补全清单

- 种子随处可见、可以复制；新游戏界面有"随机种子"按钮。
- 存档卡片显示种子和世界设置摘要。
- 世界地图支持玩家自定义标记和备注。
- "回到归还核心"的快捷键（FG13 的 Home 键）在无限地图上尤其重要。
- 靠近危险距离环时，HUD 给出提示。
- 镜头移动过快、区块还没生成好时，显示"生成中"的占位地貌，**绝不阻塞主线程**。
- 暂停菜单里可以查看当前世界的设置。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 某个种子的起始区保证失败 | 对失败项确定性局部重生成；同一种子每次结果相同 |
| 玩家去到非常远的地方 | 坐标用区块索引，不出现精度抖动；超过上限时给出提示 |
| 镜头快速平移 | 显示占位地貌，后台生成，主线程不卡顿 |
| 在区块边界上存读档 | 实体、传送带、流体跨区块时状态一致 |
| 读取生成器版本较旧的存档 | 未修改区块按旧版本生成；已修改区块按差异恢复 |
| 世界设置取极端值（资源低 + 据点高 + 污染高） | 起始区保证仍然成立，第一幕仍然可以推进 |
| 锚点放置与悬崖、水域冲突 | 按规则挪位或平整地形，保证可达 |
| 两个存档用同一个种子 | 生成的世界完全相同 |

## 7. 性能（初值，统一见 FG15）

| 指标 | 目标 |
|---|---|
| 单个区块生成（工作线程） | ≤ 5 毫秒 |
| 主线程接入一个区块 | ≤ 0.5 毫秒 |
| 同时加载的区块（每个表面） | ≤ 400 个（其余卸载表现，保留模拟所需数据） |
| 存档体积 | 随修改面积增长；后期 ≤ 50 MB（与 FG15 一致） |

## 9. 人工体验审核

1. 生成的世界看起来是"有人设计过的"，还是"随机拼凑的"？
2. 手工锚点和周围的生成地形衔接得自然吗？
3. 玩家通关后，会不会想用新种子再开一局？
