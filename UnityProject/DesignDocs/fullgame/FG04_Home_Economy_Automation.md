## 1. 玩家目的

- **为什么要自动化**：你只有一道信号，远征时家园必须自己生产、自己防守。
- **产出的去处**：家园防御、机队补给、领土净化、终局工程。每样产出都有用处，不存在"为了数字好看而堆产量"。
- **偏经营玩家的爽感**：设计一套离开也能照常运转的家园；远征回来，看离家报告。

### 3.2 建筑的通用规则

**FGR-ECO-010 通用状态**
每座建筑都有以下状态，并且**不只靠颜色**区分：建造中、工作、待机（没选配方）、缺料、缺流体、缺电、输出堵塞、禁用、损坏、摧毁（留下虚影）、升级中。

**FGR-ECO-011 通用面板**
每座建筑的面板统一包含：
- 名称和编号（可以改名）
- 状态和原因（可以追溯根源，FGR-LOG-082）
- 配方选择
- 进度
- 输入和输出缓存
- 电力优先级
- 效率（最近 10 分钟的实际产量 ÷ 理论产量）
- 升级按钮、启用 / 禁用开关
- 最近 10 分钟的产出统计
- "?"帮助，链接到图鉴

**FGR-ECO-012 升级**
- 升级由研究解锁（FG05），原地升级，保留设置；按新旧等级材料差额收费，由机器施工。

**FGR-ECO-013 耐久与维修**
- 建筑有耐久。受损后效率不变，但耐久归零时摧毁。
- 维修由机器执行（维修工作单），消耗维修件。

**通用规则的补充**（FG4-ECO-05 落地时补齐，ADR-ECO-005；数值都是初值，FG16 调参）
- 状态是从建造状态、电网、生产、队列、耐久汇总出来的，不另存；“受损”= 照常工作但耐久没满，“摧毁”= 只剩虚影（设置保留，禁用的重建后仍禁用），面板“重建”或机器右键派机器重建：有修复造价按修复造价，否则按新建造价，开局预置、不能新建的装配站 / 解析台 / 维修台按建筑通用表里的重建造价；升过级的另加差额、保留等级。归还核心不会被摧毁（耐久最低显示 0）。
- 维修按缺的耐久比例收维修件（修满 = 表里的件数，至少 1 件），开单即从仓库预留，取消 / 目标被摧毁全额退回。受损不自动修、摧毁不自动重建（自动重建是 FG6-DEF-03 玩家开的规则）。
- 有等级的建筑：仓库 T1 300 / T2 600 / T3 1000 容量，信号塔 T1 300 / T2 500 格覆盖；升级先只收废料差额（多材料造价随 FG4-ECO-11），研发门槛随 FG5-RND-01。
  升级期间照常运转；断电不影响施工；升级中被摧毁则取消升级、已运到的差额全额退回。
- 批量修改的范围是“同类建筑”（全部启用 / 全部禁用 / 全部设为某一优先级），会改到别的建筑时先确认；禁用的仓库不提供容量（已存的不丢）。
- 家园仓库是共用的库存网络：每座仓库按等级与“只存哪些物品”给物品提供容量；输出口可以“保留 N 件”。
- 效率 = 最近 10 分钟完成的份数 ÷ 这段时间满速能做的份数（按 1 分钟一桶聚合，停工都拉低效率）；上下游按配方找，回收站与废液池不算谁的下游。

**能源三行的补充规则**（FG4-ECO-04 落地时补齐，ADR-ECO-004；数值都是初值，FG16 调参）
- 燃油发电机按电网需要出力：电网先用归还核心、发电机、太阳能的电，不够的部分和储能充电才由燃油发电机补，烧油量 = 满负荷每分钟 120 升 × 负荷；不缺电时不烧。
  燃油从燃油口的管线进来，机内存 30 秒满负荷的油；烧空停机（警告“燃油耗尽”，可定位），攒够 5 秒满负荷的油后自动重新发电。没接入电网时发不出电，也不烧油。
- 太阳能阵列乘光照系数（白天 1、夜晚 0、沙暴 × 0.4）；昼夜与天气由 FG7-ENV-01 / FG7-ENV-03 接入同一个接口，接入前按白天算。
- 储能站（储电 2,000 电·分钟，充放电最大 100）：只在电网有真盈余（没有停机的建筑）时充电；缺电时放电。电网面板里可以关掉充电、关掉放电，或让放电只给优先级 1～3 / 1～2 / 1 的建筑
  （先取只给高优先级的那部分，“给所有建筑”的留给后面低优先级的建筑）。存过电的电网放空时警告一次。
- 电网曲线把每一类发电（归还核心、发电机、燃油发电机、太阳能）分开画，颜色之外用形状标记区分。

### 3.4 超控阵列（扩展信号核槽位）

**FGR-ECO-020 分级**
- T1：信号核第 3 槽。需要：研究节点 + 关键材料"监听阵列核"（静默首领）。
- T2：第 4 槽。需要：研究节点 + "熔炉心"（铸造首领）。
- T3：第 5 槽。需要：研究节点 + "超算残核"（超频首领）。
- 持续耗电（**初值：T1 80，T2 120，T3 160**）；断电时，对应的槽位暂时失效，里面的固件保留但不生效，HUD 给出提示。

### 3.5 常驻规则

**FGR-ECO-030 规则类型**

| 规则 | 条件 | 动作 |
|---|---|---|
| 库存维持 | 仓库里物品 X 少于 N | 在指定工厂排产 X，直到补足 |
| 阈值补给 | 炮塔、陷阱的某种耗材少于 N | 派机器搬运补给（或提高对应管线的优先级） |
| 战时预案 | 突袭开始 | 维修工作单优先级改为 1；暂停指定的非必要生产 |
| 静默夜预案 | 静默夜开始前 N 秒 | 指定机器回到驻防点；储能站切换为只放电 |
| 机器维修 | 机器伤势超过 X% | 送去维修台 |
| 远征卸货 | 远征队返回 | 货物送到指定仓库或解析台（默认开启） |
| 自动重建 | 建筑被摧毁 | 按原样重建（FG06） |

**FGR-ECO-031 规则界面**
- 规则列表：启用开关、优先级、条件、动作、最近一次触发时间。
- 冲突检测：两条规则要求同一座工厂时，按优先级执行，并在规则上显示冲突警告。
- **可追溯**：每个由规则触发的动作，在对应实体上都显示"由规则 R3 触发"；规则面板有触发日志。
- 规则只执行定义好的动作，绝不做额外的"智能"行为（FGR-BASE-020）。

### 3.6 机器名册与岗位

**FGR-ECO-040 岗位**
- 岗位：劳动（施工、搬运、拆解、维修）、驻防（守点或巡逻，FG06）、前哨劳动（常驻某个前哨站，FG08）、远征预备、远征中、维修中、闲置。
- 岗位由玩家设定。劳动岗的机器按工作单优先级接活（沿用 ER3-WRK-02 的确定性分配）。闲置的机器不做任何事。

**FGR-ECO-041 名册**
- 列表：可以按岗位、底盘、状态、伤势、经历排序和筛选；支持批量修改岗位。
- **机器改名**：玩家可以给机器起名，名字出现在 HUD、通知、离家报告和结算中。
- 机器详情页：经历（沿用并扩展 `MachineExperience`）、当前装配、被接入次数和时长、击杀、受伤记录。

**FGR-ECO-042 劳动力提示**
- 家园顶栏显示劳动力（劳动岗机器数和忙碌比例）。
- 远征准备时提示"出发后家园劳动力 5 → 2，施工速度约下降 60%"。

### 3.7 统计与仪表盘

**FGR-ECO-050 生产统计**
- 每种物品的产量和消耗速率，可以切换时间窗口：1 分钟、10 分钟、1 小时、10 小时。
- 按建筑查看效率；**瓶颈查找**：列出最常缺的物品，以及缺它的建筑。
- 持续赤字（某物品消耗大于产出超过 10 分钟）发出警告。

**FGR-ECO-051 资源顶栏**
- 显示：玩家固定的物品、电力（各子网）、技术数据、研究点、暴露值。
- 玩家可以把任意物品固定到顶栏。

**FGR-ECO-052 产线规划助手**
- 选择目标（例如"每分钟 10 个精密零件"），自动列出需要的建筑数量、原料需求和电力需求。
- 只计算和显示，**不会自动建造**。

### 3.8 离家报告

**FGR-ECO-060 内容**
- 离家期间：各物品的净产量；前三个瓶颈；停电事件；突袭（FG06）；事件（FG10）；天气影响；机器的伤势和阵亡；完成的研究和解析。
- 远征回来时自动打开（可以在设置里关闭）；随时可以查看最近 3 份报告。

### 3.9 软锁与保底

**FGR-ECO-070 应急打印**
- 家园机器少于 2 台时，归还核心每个游戏日免费打印一台基础搬运轮式机。
- 废料为 0，并且没有能工作的回收站时，归还核心每分钟产出少量废料（**初值：1**），保证至少有一条恢复路径。
- 实现说明（FG4-ECO-10，ADR-ECO-010，待用户复核）：应急产废料一旦开始，产到够造一座回收站（回收站造价）或有回收站开始工作为止——只产到 1 件就停会让恢复路径永远攒不够；“家园机器”= 能施工的机器（只会充电的战斗履带不算），含远征中的机器；打印的是装配站能造的搬运机（搬运轮式）。

**FGR-ECO-071 每样东西都有去处**
- 任何固体都可以送进回收站分解为废料；任何流体都可以送进废液池销毁。副产品永远不会把产线卡死在"无处可去"。

**FGR-ECO-072 死锁检测**
- 检测到传送带闭环中物品长时间既不减少也不被消费时，发出警告。
- 检测到某座建筑机器无法到达，施工或维修永远无法完成时，发出警告。

### 3.10 告警

**FGR-ECO-080 告警补全**
- 把 `HomeValleyAlarms` 的六级严重度全部接上真实数据源（目前只有"仓满""工作受阻"两级有数据）。
- 新增告警：持续缺料、输出持续堵塞、电力不足、建筑受损、机器重伤或阵亡、突袭、静默夜、天气、事件、研究完成、解析完成。
- 告警遵守 FG00 B08：分级、聚合、可以定位、有历史记录。

## 4. 正常游戏补全清单

- 物品和配方都有图鉴条目，写明来源和用途（"这个东西从哪来、拿去干什么"）。
- 悬停物品图标显示：总库存、各仓库分布、当前净速率。
- 建筑面板可以直接跳到配方的上游建筑和下游建筑。
- 可以批量修改建筑的优先级、启用或禁用。
- 规则可以复制，也有常用预设。
- 离家报告里的每一条都可以点击定位。
- 新玩家第一次看到缺料、第一次看到副产品堵塞时，各有一次引导，教他用分流器、废液池或回收站。
- 仓库支持"只存某些物品"的设置。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 所有机器都在远征，家园没有劳动力 | 施工和维修暂停，并给出提示；产线本身继续运行 |
| 仓库全满 | 上游堵塞，发出告警，并提示扩建仓库或设置回收站 |
| 酸液没有去处 | 精炼塔输出堵塞；原因写明"副产品酸液无处可去"，并给出建议 |
| 两条规则争同一座工厂 | 按优先级执行，显示冲突警告 |
| 机器全灭 | 应急打印启动，并提示 |
| 停电期间 | 按优先级断电，储能站按设置放电 |
| 超控阵列断电 | 对应槽位失效，固件保留；来电后自动恢复 |
| 读档后 | 规则、岗位、生产进度、缓存全部一致 |
| 3x 速度下 | 产量与 1x 跑同样游戏时间一致 |
