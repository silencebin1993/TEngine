# FG07 时间、天气、静默夜与净化

> 需求前缀：`FGR-ENV`；测试前缀：`FGT-ENV`。里程碑：FG-M7。

## 1. 玩家目的

- 时间有节奏：白天建设，夜晚更危险，每隔几天有一次必须靠自动化撑过去的静默夜。
- 天气让家园有持续的维护压力，也给"防护"和"净化"带来意义。
- **归还面积**是经营玩家自己的进度条：一格一格把被污染的土地收复回来。

---

## 2. 与 Demo 的差距

Demo 没有游戏内时间、昼夜、天气、污染。可复用的只有 `StrategyClock`（倍速和暂停）和 `GameRoot` 的统一暂停桥接。

## 3. 需求

### 3.1 游戏时钟

**FGR-ENV-001 时间单位**
- 1 个游戏日 = 1x 下 20 分钟现实时间：白天 14 分钟，夜晚 6 分钟（**初值**）。
- 倍速档：暂停、0.5x、1x、2x、3x（在 `StrategyClock` 上增加 3x）。
- 所有时间相关系统都由统一游戏时钟驱动（FGR-ARC-009）。

**FGR-ENV-002 日历 HUD**
- 显示：第几日、当天时刻（例如"第 12 日 18:30"）、下一次静默夜倒计时、当前天气和预报图标。
- 点开是日历面板：未来几天的静默夜、天气预报（取决于监听站等级）、已知的突袭预报。

**FGR-ENV-003 昼夜**
- 光照随时间变化。夜晚太阳能阵列发电为 0。
- 夜晚画面变暗，但**所有 UI 信息不变**。设置里提供"夜间亮度下限"，保证可读性。

### 3.2 静默夜

**FGR-ENV-010 周期**
- 每 5 个游戏日一次，发生在夜间，持续 4 个游戏小时（1x 下约 3.3 分钟）。
- 预警：开始前 1.2 个游戏小时（1x 下约 60 秒）；日历上始终能看到倒计时。

**FGR-ENV-011 期间规则（逐项）**

| 项 | 静默夜期间 |
|---|---|
| 接入 | 不可用；信号在机器里的，开始时强制弹回核心 |
| 远程命令（编队命令、驻防调动） | 不可用 |
| 接入口 | 全部为空，所有机器和炮塔只跑本地常规固件 |
| 已有工作单、常驻规则 | **继续执行**（它们属于本地规则） |
| 新的施工规划 | 可以放虚影，但要等静默夜结束后才开工 |
| 修改规则、配方、优先级 | 不可用（界面上显示原因） |
| 镜头、查看面板、统计 | 可用 |
| 突袭 | 必定发生（FGR-DEF-020） |

**FGR-ENV-012 表现**
- 画面压暗，顶部横幅"信号中断"并显示剩余时间。
- 失去信号的机器显示安全模式图标。
- 音频：无线电杂音逐渐消失，转为寂静的环境声。

**FGR-ENV-013 远征中遇到静默夜**
- 远征队进入安全模式，继续执行最后的命令。
- 远征准备时，如果预计远征时间会跨过静默夜，给出提示。

**FGR-ENV-014 撑过去的奖励**
- 静默夜结束后，家园地图上随机出现几处"风暴残骸"（地面物）：技术数据缓存，偶尔有稀有物品。机器可以去捡回来。

**FGR-ENV-015 首次静默夜**
- 第一次静默夜前，给一次非阻塞的说明：会发生什么、要提前准备什么（储能、炮塔、静默夜预案规则）。

### 3.3 天气

**FGR-ENV-020 天气类型**

| 天气 | 效果 |
|---|---|
| 晴 | 无 |
| 酸雨 | 没有顶棚、不在净化区里的建筑、传送带、炮塔持续损失耐久（**初值：每游戏小时 1%**） |
| 沙暴 | 画面能见度下降；炮塔探测距离 -20%；露天传送带 -25%；太阳能 -60% |
| 寒潮 | 散热 +30%（对热量类构筑有利）；停止流动的管线会结冰（FGR-LOG-045） |

- 每种天气持续 0.5～1.5 个游戏日；出现频率随幕推进而提高（表见 FG16）。
- 天气与静默夜可以叠加。

**FGR-ENV-021 预报**
- 没有监听站 T2 时，天气开始前 0.5 个游戏日发出预警。
- 有监听站 T2 时，可以看到未来 3 个游戏日的预报。

### 3.4 顶棚

**FGR-ENV-030 顶棚**
- 4×4 一块，可以拖拽铺设。覆盖下的格子不受酸雨和沙暴影响。
- 建造视图下顶棚半透明，玩家可以看到并操作下面的东西；可以用快捷键隐藏顶棚。

### 3.5 污染与净化

**FGR-ENV-040 污染等级**
- 每格污染 0～3 级，由家园生成器按种子生成（FGR-GEN-030、031）：归还核心附近为 0～1 级，越往外越高，中间有局部浓淡。
- 影响：1 级格子上的建筑受天气损伤加倍；2 级及以上不能建造（净化塔和传送带除外，FGR-LOG-012）。
- 污染叠加层显示等级；悬停格子显示等级和影响。

**FGR-ENV-041 净化塔**
- 三个等级，净化半径 8、12、16 格。
- 从中心向外逐格降低污染，每格每 N 个游戏小时降 1 级（**初值：N = 2**）。
- 持续消耗冷却液和电力；供给中断时暂停净化，已净化的格子保持不变。

**FGR-ENV-042 归还面积**
- 世界是无限的（FG17），百分比没有分母，所以改用**已归还的面积**：0 级格子的总数。在顶栏和日历面板显示为"已归还 N 格"。
- 里程碑奖励（**初值**）：

| 归还面积 | 奖励 |
|---|---|
| 5,000 格 | 全局天气损伤 -25% |
| 20,000 格 | 揭示新的资源点（稀土富矿） |
| 50,000 格 | 信号覆盖 +10% |
| 100,000 格 | 成就，并在结局中增加一句专属文本 |

- 每个里程碑都触发一条核心备忘（FG11 叙事）。

**FGR-ENV-043 再污染**
- 化工阵营的突袭会让一片区域的污染升级（FG09）。被再污染的格子上的建筑不会立刻被摧毁，但会进入"受污染"状态并承受天气加倍损伤，直到重新净化。

### 3.6 家园扩张与迷雾

**FGR-ENV-050 迷雾**
- 地图未探索的部分被迷雾覆盖，不能建造。家园是无限地图，迷雾之外的区块按需生成（FGR-GEN-020）。
- 探索方式：信号塔覆盖范围自动探索；机器走到的地方被探索。

**FGR-ENV-051 家园遗迹点**
- 遗迹点由生成器按距离环分布（FGR-GEN-033），探索后可以派机器回收：背景资料、人类遗产、技术数据。让家园本身也有探索的乐趣。

### 3.7 区域环境危害

**FGR-ENV-060 危害框架**
- 每个远征区域有一种危害（具体数值见 FG09）：电磁噪声、熔渣热区、酸沼、高温辐射。
- 危害区在地图上有明确标记和图例；悬停说明效果和应对办法（例如"装散热鳍可以抵消"）。

---

## 4. 正常游戏补全清单

- 日历面板把静默夜、天气、已知突袭画在同一条时间轴上。
- 天气和静默夜到来前都有通知，并有对应的音乐和音效。
- 设置：夜间亮度下限、静默夜画面压暗强度、天气视觉效果强度（沙暴可能影响可读性）。
- 顶棚覆盖、污染、净化进度都有叠加层。
- 图鉴有"静默夜""各类天气""污染""净化""归还面积"条目。
- 静默夜结束时发一条总结通知：击退了什么、损失了什么、捡到了什么。

## 5. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 静默夜开始时玩家在机器里 | 预警后强制弹回核心，给出原因 |
| 静默夜期间放虚影 | 允许；结束后自动开工 |
| 静默夜期间尝试修改规则 | 拒绝，说明原因 |
| 酸雨期间建筑耐久归零 | 摧毁，留下虚影；自动重建规则照常生效 |
| 净化塔缺冷却液 | 暂停净化，给出原因；已净化的格子不变 |
| 化工再污染了一片有建筑的区域 | 建筑进入"受污染"状态，不会立刻被摧毁 |
| 3x 速度下跨过静默夜 | 行为与 1x 一致；预警时间按游戏时间计算 |
| 存档时处于静默夜中 | 读档后静默夜剩余时间、突袭状态完全一致 |
| 暂停时 | 所有计时同时停止 |

## 6. 存档

游戏时钟、静默夜计划、天气状态与预报（含随机种子）、污染格网、净化塔进度、归还面积里程碑、迷雾、遗迹点状态、风暴残骸。

---

## 7. 性能

- 污染格网按区域增量更新，不能每帧遍历整张地图。
- 天气造成的耐久损失按游戏分钟批量结算。
