# FG12 沙盒与后日谈

> 需求前缀：`FGR-SBX`；测试前缀：`FGT-SBX`。里程碑：FG-M14。
> 上游：[ProjectA_FullGame_Design.md](../ProjectA_FullGame_Design.md) 12.3。契约：[FG00](FG00_Completeness_Addendum.md)。
> 相关：[FG11 终局](FG11_Narrative_Endgame.md)、[FG06 突袭](FG06_Home_Defense_Raids.md)、[FG15 成就](FG15_Save_Settings_Perf_Release.md)。

---

## 1. 玩家目的

- 通关之后，**家园不必关掉**：继续扩建、继续优化、面对越来越强的清洗波次。
- 偏经营的玩家可以开一局**没有剧情压力**的自定义沙盒，专心建造。

---

## 2. 需求

### 2.1 后日谈（通关存档继续）

**FGR-SBX-001 继续游戏**
- 结局后选择"继续"，在同一个存档里接着玩。存档标记为"后日谈"。
- 轨道威胁指示保留，所有区域仍然可以远征。

**FGR-SBX-002 周期清洗**
- 每 7 个游戏日（**初值**）来一次清洗波次，等级逐次提高，没有上限；增长公式见 FG16。
- 沿用突袭的预警、结算和离家报告。
- 舰队残骸可以回收，得到人类预制固件和稀有材料。

**FGR-SBX-003 坚守统计**
- 记录：结局后坚守的天数、达到的最高清洗等级、单次清洗中的最佳防守数据。
- 这些数据显示在主菜单的存档卡片上。

**FGR-SBX-004 后日谈内容**
- 轨道坠落更频繁，而且更容易带来人类遗产。
- 开放最后一组人类遗产（只能在后日谈获得）。
- 专属成就（FG15）。

**FGR-SBX-005 失败**
- 核心被毁时，显示"坚守结束"总结页：坚守天数、最高等级、各项统计；之后可以读取自动存档继续。

### 2.2 自定义沙盒新档

**FGR-SBX-010 入口**
- 主菜单新增"沙盒模式"：从一张新地图开始，没有剧情。

**FGR-SBX-011 设置项**

| 设置 | 选项 |
|---|---|
| 突袭 | 关闭 / 低 / 标准 / 高 |
| 静默夜 | 开 / 关 |
| 天气 | 开 / 关 |
| 事件频率 | 关闭 / 少 / 标准 / 多 |
| 起始资源 | 标准 / 丰富 |
| 研发 | 正常 / 全部解锁 |
| 区域 | 按进度解锁 / 全部开放 |
| 敌方强度 | 低 / 标准 / 高 |
| 种子 | 输入或随机（FGR-GEN-001） |
| 资源丰度、敌方据点密度、污染强度 | 低 / 标准 / 高（FGR-GEN-070） |
| 领地距离 | 近 / 标准 / 远（FGR-GEN-070） |
| 起始区 | 标准 / 宽松 / 关闭保证（仅沙盒可关） |

- 关掉了剧情，关键材料改为在研发树里用研究点换取，保证超控阵列等系统仍然可以解锁。
- 存档卡片和暂停菜单上清楚标出"沙盒"及其设置；**沙盒存档不计入剧情类成就**，这一点在开局前说明。

**FGR-SBX-012 创造模式（可选，优先级 P2）**
- 资源无限、瞬间建造，用来规划布局；布局可以存进布局库，带回普通存档使用。

---

## 3. 正常游戏补全清单

- 后日谈开始时，简短说明接下来会发生什么。
- 清洗波次的历史记录可以查看。
- 沙盒的设置在开局后可以部分修改（突袭、静默夜、天气、事件频率），修改会记录在存档里。
- 主菜单的存档卡片区分：剧情中、后日谈、沙盒。

---

## 4. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 后日谈中核心被毁 | 显示坚守总结，可以读档 |
| 清洗等级非常高 | 突袭编成仍然不超过性能预算（FG15），通过精英化和单位强度体现难度，而不是无限堆数量 |
| 沙盒关闭突袭 | 不会有任何突袭；静默夜如果开启，照样断信号，但没有进攻 |
| 在沙盒里走到剧情节点的位置 | 没有剧情节点，不会触发演出 |

---

## 5. 存档

后日谈标记、清洗计时与等级、坚守统计、沙盒设置与修改记录。

## 6. 自动验收

| 测试 | 内容 |

| FGT-SBX-003 | 坚守总结与统计正确 |

| FGT-SBX-005 | 沙盒存档不触发剧情类成就 |
