## 1. 玩家目的

- 故事**不打断游戏**：靠日志、截获、环境和核心自己的备忘来讲。
- 前两幕埋下的伏笔，在信标点亮那一刻**全部接上**。
- 终战是对之前所有系统的**总考**：家园自动化、跨阵营构筑、信号接入。
- 结局让玩家记住**自己的机器**。

## 3. 叙事投放

**FGR-NAR-001 投放方式**

| 方式 | 说明 |
|---|---|
| 核心备忘 | 归还核心在剧情节点自动写下的日志，是玩家自己的"声音" |
| 数据终端 | 远征区里的文字日志 |
| 监听截获 | 监听站破译的通讯，以"无线电杂音 + 文字"呈现 |
| 遗迹纪念物 | 人类遗产的描述文字 |
| 环境叙事 | 关卡里的场景细节（炮口朝天的阵地、贴满天空扫描记录的墙） |
| 结局演出 | 游戏内镜头 + 文字 |

- 不做对话树（沿用 GDD 的非目标）。v1 不需要配音，配音是可选项（P2）。

**FGR-NAR-002 不打断游戏**
- 日志、截获、备忘都以通知形式出现，玩家有空时再读。
- 只有揭示和结局这两段演出会接管画面。两段都可以跳过（首次观看时，跳过需要确认），之后可以在资料库里重看。

**FGR-NAR-003 资料库**
- 图鉴里的"资料库"页收录所有已获得的文本，可以按幕和来源筛选，未读的有标记。
- "剧情回顾"按时间顺序列出已经发生的剧情节点。

**FGR-NAR-004 文风**
- 克制、冷静，带人情味的机器视角。
- 揭示之前，舰队的消息**温暖而鼓舞人心**；越接近揭示，越显得程式化。前后反差就是最大的情绪冲击。

### 3.1 剧情节点

**FGR-NAR-010 节点表**

| 节点 | 触发 | 方式 | 内容 |
|---|---|---|---|
| 苏醒 | 新游戏 | 演出（简短） | 核心启动；舰队简报："归还核心，欢迎回家。恢复电力，点亮信标。" |
| 天上的眼睛 | 第一次远征破碎都市 | 数据终端 | 静默日志："它们来了之后，天空就有了眼睛。" |
| 朝天的炮口 | 第一次进入铸造前哨 | 环境 + 核心备忘 | 备忘："它们的炮为什么都朝着天空？" |
| 第一个片段 | 击败寂听主脑 | 监听截获 | "……返航前……清点地表单元……" |
| 它在等什么 | 击败铸造主核心（对空形态） | 核心备忘 | 第一幕结束 |
| 净化即救赎 | 进入沉淀湖 | 监听截获 | 化工广播；与玩家的净化塔形成对照 |
| 信号幽灵 | 第二幕固定节点 | 事件（FG10） | 你的机器第一次被未知信号夺控 |
| 净化的意义 | 击败沉淀反应塔 | 核心备忘 | 核心反思"净化"一词 |
| 破译 | 击败超算残核 | 破译片段 | 第一次拼出"净化协议：返航前清除全部自治单元（含归还序列）"，但是残缺的，核心无法确认 |
| 巨构蓝图 | 第三幕开始 | 舰队消息 | 舰队发来巨构蓝图，语气热情 |
| 阶段消息 | 每个巨构阶段完工 | 舰队消息 | 语气越来越程式化 |
| 揭示 | 信标点亮 | 演出 | 见第 5 章 |
| 结局 | 击退先遣旗舰 | 演出 | 见第 7 章 |

- 核心备忘还会在归还率达到 25%、50%、75%、100% 时各写一条（FGR-ENV-042）。
- 核心的疑虑**不会强迫玩家做选择**，剧情照常推进。

## 4. 返航工程

**FGR-END-001 巨构阶段**
- 五个阶段：地基锚定 → 能源矩阵 → 信号天线阵 → 轨道校准 → 信标点火。
- 每个阶段是一片大型工地（**初值：12×12 格**），带输入端口，要用传送带和管线持续送入指定物资，并且持续供电一段时间。例如一个阶段需要：巨构构件 400、冷却液 2,000、持续供电 500 达 2 个游戏小时（**初值**）。
- 工地面板显示每种物资的进度，以及按当前供给速度预计的完成时间。

**FGR-END-002 防守工地**
- 每完成一个阶段，触发一次更高等级的突袭（FGR-DEF-020）。
- 工地受损时暂停推进，**已完成的进度不会倒退**。

## 5. 揭示

**FGR-END-010 揭示**
- 触发：玩家在信标点火后确认启动（沿用现有的二次确认面板）。
- 演出：镜头转向天空，舰队信号接入，文字："归还核心任务完成。净化协议启动。"之前所有伏笔在这里接上。
- 状态变化：HUD 出现"轨道威胁"指示；任务更新；音乐切换。
- 演出前后各自动存档一次。

## 6. 三段终战

**FGR-END-020 第一段：清洗波次（家园）**
- 2 个游戏日内来 3 波。无人舰群分批登陆；轨道打击周期性清空一片区域，落点提前 30 秒标出。
- 目标：守住家园。这一段是家园自动化的总考。
- 每一波开始前自动存档。

**FGR-END-021 第二段：登陆场（远征）**
- 登陆场区域开放。目标：摧毁 3 个轨道锚点和登陆信标，切断持续投送。
- 屏蔽塔会限制接入，要先拔掉。
- 这一段期间，家园只会遭受 1 级骚扰（由自动化防守），避免双线同时失败。

**FGR-END-022 第三段：最终 Boss·先遣旗舰**
- **阶段一·轨道轰炸**：旗舰悬在高空，无法攻击。它标记区域进行延时轰炸。场上有 4 座校准信标引导轰炸，每摧毁一座，轰炸就更不准；全部摧毁后，旗舰降下。
- **阶段二·登陆要塞**：旗舰降下地面要塞，有多个炮位和护盾节点。**每个护盾节点只怕一类固件**（电磁、流体、引信、限制器各一个）。这一阶段检验的是你跨阵营构筑的广度，是跨阵营编译（P3）的最终兑现。
- **阶段三·根权限压制**：旗舰动用人类根权限，每 20 秒夺取一台最靠近"压制中继"的你的机器（场上共 3 座中继）。被夺取的机器转而攻击你。
  - 你可以对被夺取的机器**反向接入**夺回来。这和信号幽灵（FG10）是同一个机制，玩家之前学会的技巧在这里得到回报。
  - 被夺取的机器被击倒后进入**瘫痪**，不会阵亡，阶段结束后恢复。
  - **永远不会夺取玩家当前所在的那台机器。**
  - 摧毁全部 3 座中继后，旗舰核心暴露，进入最后的爆发窗口。
- 这是**脚本化的首领机制**，只在这场战斗中出现，不属于常态 AI 行为。
- 每个阶段开始时自动存档；失败后从该阶段开始重试。

## 7. 结局

**FGR-END-030 结局演出**
- 先遣旗舰撤退，先遣舰队被击退。镜头转向天空：主舰队仍停在轨道上。
- 核心写下最后一条备忘：人类仍在沉睡，净化协议没有撤销，它选择继续守着这片土地，好让人类将来醒来时，还有东西可以归还。

**FGR-END-031 结算与纪念**
- 沿用并扩展 Demo 的机器故事：
  - 幸存机器列表：名字、编号、经历。
  - 纪念墙：所有阵亡机器（数据来自黑匣子陈列馆，FG05）。
  - 统计：归还率、游戏天数、发现的反应、熔合配方数、击退的突袭次数。
- 结语根据统计略有变化（只是文字差异，不是分支结局）。例如：归还率 100% 有专属的一句；提到最老的那台机器；提到被接入最多的那台机器。

**FGR-END-032 之后**
- 结算后让玩家选择：继续（进入后日谈沙盒，FG12）或返回主菜单。
- 解锁对应成就（FG15）。

## 8. 正常游戏补全清单

- 演出可以跳过，也可以在资料库重看。
- 文本显示速度、字幕大小可以设置。
- 阅读日志时游戏不会自动暂停，但可以手动暂停。
- 资料库有未读标记；新文本进来时发通知。
- 如果玩家迟迟不建信标，游戏**没有时间压力**，只用任务提示引导，不设倒计时。
- 终战各段都有独立的失败界面，写明失败原因和重试点。

## 9. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 揭示演出中退出游戏 | 读档后回到演出前的自动存档 |
| 清洗波次中核心被毁 | 从这一波开始前的自动存档重试 |
| 登陆场期间家园遭袭 | 只有 1 级骚扰，由自动化防守 |
| 根权限阶段玩家只有 1 台机器 | 不会夺取玩家所在的机器；中继照常可以摧毁 |
| 被夺取的机器被玩家击倒 | 瘫痪，阶段结束后恢复，不阵亡 |
| 巨构工地被摧毁 | 进度暂停，不倒退；重建后继续 |
| 玩家不建信标 | 游戏继续，没有倒计时 |

## 12. 人工体验审核

1. 揭示那一刻，玩家有没有"原来如此"的震动？伏笔回想起来是否合理？
2. 终战是否真的像"总考"：用上了家园、构筑、接入这三样？
3. 结局时，玩家记不记得自己某台机器的名字？
