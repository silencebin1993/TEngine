# FG13 UI/UX、引导与可访问性

> 需求前缀：`FGR-UX`；界面编号：`FGU-NN`；测试前缀：`FGT-UX`。里程碑：FG-M0（基础件）、各里程碑（各自的界面）、FG-M15（全集收口）。
> 契约：[FG00](FG00_Completeness_Addendum.md)（B01～B25 大多落在本文件）。架构：[FG14](FG14_Tech_Architecture_Migration.md) FGR-ARC-006、007、012。
> 技术规范：`.claude/rules/unity-ui-toolkit.md`、`Docs/UI/UI_PIPELINE.md`、tengine-dev skill 的 ui-toolkit 主题。

---

## 1. 玩家目的

- 任何功能，玩家都**找得到、看得懂、改得了、撤得回**。
- 40 小时后，常用操作依然**顺手、不重复**。
- 各种能力、习惯的玩家都能玩（可访问性）。

---

## 2. 与 Demo 的差距（2026-09-24 盘点）

- 新面板用 UI Toolkit，主菜单是 UGUI。
- 没有通用 toast 和确认框；tooltip 只在战斗浮层里；告警只有两级有真实数据源。
- 可重绑动作只有 6 个；没有本地化。
- 图鉴只覆盖细胞阶段内容；目标追踪没有独立面板。
- Demo 原有的 13 步教学已经降级为 ER9-TUTOR-01"可选教学覆盖层"。

## 4. 全局交互规则

**FGR-UX-001 取消与返回**
- 右键：取消当前的放置或选择模式。
- Esc：按层级逐层返回（关闭最上层面板 → 退出当前模式 → 打开暂停菜单）。

**FGR-UX-002 确认的尺度**
- 只有不可逆、代价大的操作才弹确认框（FG00 B04）。可逆操作不弹，靠撤销兜底。
- 确认框写清楚后果（"将丢失：未装载的战利品 ×7"）。

**FGR-UX-003 撤销**
- 规划类操作（建造、拆除、电路编辑、规则编辑）支持撤销和重做。

**FGR-UX-004 一致性**
- 术语以 `ProjectA_FullGame_Design.md` 第 5 章和 FG02 名表为准，全游戏统一。
- 颜色语义：红 = 危险，琥珀 = 警告，蓝 = 信息，绿 = 正常。**任何颜色都同时配有形状或图标**。
- 数字格式：超过 1 万用"万"（英文用 k / M）；速率统一写"/分钟"；时间写"第 N 日 HH:MM"。

**FGR-UX-005 屏幕分区（家园）**
- 顶栏：资源、电力、时间、暴露、归还面积。
- 右侧：通知。
- 右下：小地图。
- 底部：快捷栏。
- 左侧：当前选中对象的面板。
- 远征 HUD 和接入 HUD 沿用同样的分区，保持肌肉记忆。

## 6. 通知

**FGR-UX-020 分级与聚合**
- 三级：紧急（突袭、静默夜开始、核心受损、机器阵亡）、警告（缺电、仓满、持续缺料、天气）、信息（研究完成、解析完成、新任务）。
- 同类通知聚合（"3 座建筑缺电"），聚合后点击展开。
- 点击通知，镜头定位到相关实体。
- 通知中心保留历史，可以按等级和类型筛选。

**FGR-UX-021 自动暂停**
- 设置里可以按通知类型勾选"触发时自动暂停"（默认勾选：突袭到达、静默夜开始、首领阶段转换）。

**FGR-UX-022 声音**
- 每个等级有不同的提示音；同类提示音有冷却，避免连响。

## 7. 悬停提示

**FGR-UX-030 规则**
- 悬停约 0.4 秒后出现。按住 Alt 可以把提示固定住，用来阅读嵌套内容。
- 复合数值可以展开来源（伤害、产量、效率的构成）。
- 提示里附带相关的快捷键和图鉴链接。
- 所有交互元素都要有提示；禁止出现没有任何说明的图标。

## 8. 图鉴与资料库

**FGR-UX-050 标签页**
固件、组件、底盘、建筑、物品与流体、反应、状态标签、敌人、阵营、区域、事件、系统说明、人类遗产收集、资料库（剧情）。

**FGR-UX-051 规则**
- 机制类条目在首次接触时解锁；未解锁的显示剪影和获取提示。
- **持久化**：机制类条目跨存档共享（沿用 `CodexPersistence` 的方式）；资料库（剧情文本）按存档保存，避免在新存档里被剧透。
- 支持搜索；条目之间互相链接（固件 ↔ 反应 ↔ 敌人弱点）。
- 从任何悬停提示按一个键就能跳到对应条目。

## 10. 可访问性

**FGR-UX-060 最低集**
- UI 缩放 80%～150%；文字大小独立可调。
- 色盲模式（红绿、蓝黄、全色盲三种）；所有颜色信息都有形状或图标冗余。
- 高对比度选项。
- 字幕及字幕大小；关键音效有视觉指示（例如突袭来袭的方向指示）。
- 闪光减弱、震屏开关、慢放开关、镜头推动开关（统称"减少动态效果"）。
- 所有"按住"操作可以改为"切换"。
- 所有快捷键可以重绑；主要流程只用鼠标也能完成。
- 通知停留时长可调。
- 夜间亮度下限（FG07）。

## 11. 技术要求

**FGR-UX-070 实现**
- 新面板一律 UI Toolkit，使用 FG-M0 做好的基础件（FGR-ARC-007）。
- 大列表用虚拟化，不能每帧重建整个面板。
- UI 每帧开销与实体数量无关，只读汇总数据。
- 布局验收先跑无头布局探针，需要看真实画面时再用 Play 加 ScreenCapture 截图（UI Toolkit 用相机截图截不到）。
- 所有面板都要在 1280×720、1920×1080、2560×1440、3440×1440 四种分辨率下检查。

## 12. 负向与边界矩阵

| 场景 | 期望行为 |
|---|---|
| 英文文本比中文长 | 布局不溢出、不截断关键内容 |
| UI 缩放 150% + 1280×720 | 所有面板可用，必要时出现滚动条 |
| 1 秒内 50 条通知 | 聚合显示，不卡顿 |
| 重绑时发生冲突 | 提示冲突，并让玩家选择覆盖或取消 |
| 缺失文本键 | 显示明显的 `⟦key⟧` 标记，不显示空白 |
| 面板在数据加载中 | 显示加载态，不显示空白或旧数据 |

## 14. 人工体验审核

1. 第一次玩的人，能不能不看攻略就找到主要功能？
2. 30 小时后，哪些操作还是嫌麻烦？
3. 信息是否过载？HUD 是否太挤？
