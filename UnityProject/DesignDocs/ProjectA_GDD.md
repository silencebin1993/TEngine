## 0. 权威、假设与执行纪律

### 0.1 权威边界

1. 本文是 0.2 产品语义、玩家循环、内容范围与体验目标的最高权威。
2. `fullgame/FG00～FG17` 把本文展开为逐条需求（FGR-xxx）；**具体行为以详细设计为准**，但详细设计不得新增本文没有批准的产品系统。
3. [正式版里程碑](ProjectA_FullGame_Milestones.md) 只决定顺序；`production/design/full-game/` 的卡片与看板决定施工单元与状态。
4. [FG00 完整性附加契约](fullgame/FG00_Completeness_Addendum.md) 与 [00 契约](detailed/00_Implementation_Completeness_Contract.md) 是每个 Story 的完成下限；规格是下限，不是上限。
5. [正式版设计案](ProjectA_FullGame_Design.md) 是本文的展开背景与名表出处（叙事细节、名表全表、需求覆盖检查表）；两者冲突时以本文为准。
6. Demo 的 GDD 0.1（已归档）和 `production/design/earth-reclamation/` 下的 ERD 文档集**冻结**：只用于 Demo 回归测试、ERD / AC 编号追溯与代码考古，不作为 0.2 需求来源。
7. 旧生物机械 GDD、Cell Stage、债兽、生态债务、器官卡牌和旧 PCG 文档只作代码考古，不得作为任何需求来源。

### 0.2 制作假设

- 小型独立团队，PC 首发，离线单机；不做联网、服务器或多人同步。
- 一周目目标 40 小时以上，通关后进入沙盒（后日谈）。
- 优先复用 Demo 已实现的 Sim、控制权、编队、装配、ComposeEngine、输入、镜头、信号与数据管线（见 §16.2）。
- 世界按种子程序生成；同一个种子必须生成同一个世界，存档只记种子与改动（D-20、FG17）。
- Demo 存档不迁移到正式版（D-14）；手柄不承诺（D-15）；不做配音，用"无线电杂音 + 文字"呈现（D-21）。

### 0.3 产品承诺

> 玩家是归还核心发出的超控信号：经营一座会自己运转的机械家园，生产并照料有编号和经历的机器；带着核心固件接入其中任何一台，让它当场变形、打出你设计的连锁反应；把四个互不兼容阵营的技术夺来、破解、熔合进同一张蓝图，最终击退来"净化"地表的方舟舰队，守住这片土地。

新玩家应在 15 分钟内理解四件事：

1. 我是归还核心的信号，不是固定角色；我只携带固件，不携带实物；机器都是可替换但有经历的身体。
2. 家园里干活的机器，就是远征、防守和被我接入的机器。
3. 敌方技术必须带回、破解，才能量产；在那之前只有我的信号能"裸跑"它，并且要付暴露代价。
4. 我只有一道信号：我在远征时，家园要靠产线、炮塔和常驻规则自己运转。

## 1. 定位、受众与传播表达

### 1.1 一句话卖点

**把互不兼容的技术编进同一支机队，再亲手接入其中任何一台，引爆你设计的连锁反应。**

### 1.2 两种爽感，同一套底层系统

| 玩家偏好 | 爽感来源 | 用到的系统 |
|---|---|---|
| 偏远征 | 带着核心固件接入一台机器，看它当场变形，亲手引爆大反应 | 信号核、接入口、核心固件 |
| 偏经营 | 设计出不需要自己在场、就能自动打出连锁反应的家园阵地和产线；远征回来看离家报告 | 常规固件、炮塔、传送带、常驻规则 |

### 1.3 三个可视化传播瞬间

1. 玩家接入一台普通履带机，信号核里的核心固件插进接入口，散热鳍当场展开、枪管发红，下一发打出具名反应。
2. 远征途中家园警报响起，信号瞬间跳回家接入一座炮塔亲自防守，远征队交给 AI 继续执行最后的命令。
3. 离家报告：离家期间家园自动击退三波突袭，炮塔打出"燃爆 ×37"。

没有旁白时，观众也必须看懂"同一台机器""信号接入改变它""家园自己在打"。

### 1.4 目标玩家

- 喜欢规划产线和阵地、看自动化自己运转，但不想承受殖民者生理模拟的玩家。
- 喜欢小队战术与暂停下令，但不以高 APM 为乐的玩家。
- 喜欢模块构筑、组合反应、战利品改变后续打法的玩家。
- 喜欢在关键时刻亲自接入一台机器，而不是全程旁观数值结算的玩家。

### 1.5 明确非目标

- 不做传统 RTS 的抢矿、兵海和高 APM 多线压制。
- 传送带单车道、建筑端口直接对接，不做机械臂（D-02）；管线不做压力模拟，一个网络只有一种流体（D-03）；不做缺氧式气体温度模拟或环世界式社交关系。
- 不做随机卡牌局外肉鸽，不做第二套永久元进度；三选一属于局内掉落，不是元进度（保留 0.1 条款）。
- 不做机器人格对话树；机器叙事只来自编号、职责、损伤、经历和结局记录。
- 不做联网、多人、在线服务或赛季内容。
- 不做动画驱动的复杂近战或载具物理模拟。
- 多星球（含多家园）只作为候选里程碑 FG-X1，v1 不排期（§18）。

## 2. 设计支柱与取舍规则

| 支柱 | 含义 | 取舍规则 |
|---|---|---|
| **P1 真实机器个体** | 家园里干活的机器，就是远征、防守和被你接入的机器；每台都有编号和经历，阵亡不复活 | 禁止另造"英雄身体"；禁止无理由重置伤势与身份 |
| **P2 信号接入** | 玩家是归还核心的超控信号，只携带固件；接入一台机器，就是把核心固件插进它的电路，让它当场变成另一种东西 | 接入必须改变行为，不能只加数值；禁止给玩家隐藏伤害倍率 |
| **P3 跨阵营编译** | 四阵营技术互不兼容；夺来、破解、熔合之后编进同一张蓝图 | 新内容优先加"读法"和"熔合"，不优先加新固件 |
| **P4 自己运转的家园** | 你只有一道信号，不能同时出现在两个地方；远征时，家园必须自己生产、自己防守 | 每个经营功能都要回答：它有没有增加下一次远征或防守可用的反应选择，或者让反应更容易被看见？答不上来就不做 |
| **P5 守住归还** | 所有系统最终服务于击退清洗舰队、守住这片土地 | 不强化终局的功能，优先级靠后 |

跨支柱的硬规则：
- **可恢复**（沿用 0.1 P4）：断电、堵塞、机器损毁、远征失败、断链都是可恢复的软失败；玩家必须看得懂原因、影响和恢复办法；除归还核心被毁外不允许无提示软锁。
- **不做玩家没要求的事**：机器、炮塔、规则只执行玩家显式设定的命令和规则；每个自动动作在 UI 上可追溯来源（FGR-BASE-020）。
- **观察不改变结果**：家园和任何活跃区块在不被观察时，结果必须与观察时一致（FGR-BASE-021、D-06）。

## 3. 核心循环

### 3.1 10～30 秒操作循环

1. 观察一个明确问题：缺电、缺料、产线堵塞、敌人接近、机体受损、反应窗口出现、突袭预警。
2. 采取一个动作：放置或改线、改优先级、排生产、下编队命令、暂停规划、接入一台机器、发动核心固件。
3. 获得即时反馈：路线、进度、资源预留、失败原因、机身形变、反应名、伤势或警报变化。
4. 继续、修正、撤销或取消；任何失败输入都必须给出稳定原因，不能静默。

### 3.2 30～90 分钟远征与经营循环

1. 在家园检查产线、电力、库存、炮塔阵地、机器状态、静默夜倒计时与突袭预警。
2. 编成远征队，选目的地，看派遣检查单（信号覆盖、货舱、静默夜、家园劳动力、敌方反制）。
3. 沿地形行军或用投送舱投送；指挥小队移动、守备、攻击、撤退。
4. 接入是**常态玩法**：随时接入远征队或家园中任意一台在信号覆盖内的机器，插入核心固件，打出只有信号在场时才有的反应；离开时机器回到本地配置。
5. 拿到精英、首领、终端、任务的掉落；决定现在裸跑敌方固件，还是带回家破解。
6. 家园遇袭时决定：信号跳回家亲自防守，还是相信阵地。
7. 回到家园或前哨站结算：卸货、处理待分拣数据包（三选一）、破解、熔合、研究、改蓝图、改产线。

### 3.3 40 小时战役循环

| 幕 | 时长（提案） | 内容 | 新开放系统 |
|---|---|---|---|
| 第一幕 | 约 8 小时 | 相当于 Demo：归还谷地、破碎都市、铸造前哨；寂听主脑、铸造主核心 | 信号接入、接入口、基础传送带、突袭与炮塔、静默夜 |
| 第二幕 | 约 15 小时 | 澄净（内部代号化工）和超频阵营；家园工业化；掘进蠕虫、信号幽灵 | 管线、分拣、熔合配方、超控阵列升级、净化塔、恶劣天气 |
| 第三幕 | 约 10 小时 | 返航工程、信标、揭示、终战 | 巨构物流、最终防御 |
| 后日谈 | 不限 | 沙盒、清洗波次 | — |

一周目主线约 33 小时，加上支线、遗迹和自由经营，达到 40 小时以上。

### 3.4 资源流

| 资源 | 来源 | 消耗 | 归零后果 |
|---|---|---|---|
| 电力 | 发电机、储能站；电塔覆盖成子网（D-05） | 建筑、生产、炮塔、超控阵列、信号 | 该子网消费者按优先级停机；已有状态不凭空丢失 |
| 废料 / 合金 / 零件 | 回收站、提取钻、精炼炉、零件工坊；战利品 | 建造、生产、维修、改造 | 无法开新事务；已预留事务按规则完成或退款 |
| 流体（冷却液、燃油等） | 流体泵、储罐 | 散热、流体类固件、炮塔补给 | 相关消费者降级或停机，并显示缺流体 |
| 技术数据 / 研究点 | 解析台、仿真实验室、没选中的三选一候选 | 研发树、熔合实验 | 不影响已解锁内容 |
| 关键材料 | 指定任务、首领固定掉落（不随机） | 超控阵列升级、区域通行、净化塔升级 | 不会因全灭而永久丢失（D-13） |
| 信号覆盖与带宽 | 归还核心、信号塔、信号中继 | 远程命令、接入距离、远征连通 | 超出覆盖的机器只执行最后的命令；超额请求被拒绝并显示原因 |
| 信号暴露 | 见 §4.6 | 不是货币；驱动突袭与敌方反制 | 达阈值触发有预兆的事件；可主动降低 |
| 归还面积 | 净化塔、收复领地 | 不是货币；终局与统计指标 | 世界无限后取代 0.1 的"归还率"百分比 |

## 4. 玩家与信号

### 4.1 玩家是什么

- 玩家是归还核心发出的**超控授权信号**，不是任何一台机器（延续 0.1"玩家身份是归还核心，机器是可替换的身体"）。
- **不能携带任何实物**。战利品、零件、材料一律由机器搬运。
- 同一时刻只能待在一台机器里；只有一道信号（§4.5）。
- 机器平时运行自治安全协议；只有核心有权让它们越过安全线。

### 4.2 信号核

- 信号核带固件槽，**初始 2 槽，最多 5 槽**；扩槽靠"超控阵列"逐级升级，每级需要一份指定任务给出的关键材料。
- 槽里可以放任意固件；**核心固件只能由信号携带**：只能放在信号核里，不能装进机器或炮塔。AI 驾驶的机器永远只运行本地常规固件。
- 超控阵列持续耗电，断电时多出的槽暂时失效。

### 4.3 接入

1. 在上帝视角选择信号覆盖内一台存活、友军、未处于不可控状态的机器，发起接入；0.35 秒镜头过渡，明确显示机器编号。
2. 机器有**接入口**时，信号核里的固件插进接入口，电路当场重新编译，机身发生可见形变（§5.5）。
3. 没有接入口时，玩家照样可以操作（移动、瞄准、主动作），只是不插入固件。
4. 离开时，固件随信号带走，机器重编译回本地配置；**热量和冷却状态留在机体上**，不随信号转移。
5. 原身体立即恢复其 AI 教义或未完成的合法编队命令；接入不改变机器所有权、装配、伤势和当前世界状态。
6. 受控机器死亡时按确定性规则回弹到覆盖内友军；无候选则回到战略视角并说明原因。
7. 接入是常态玩法，不消耗一次性资源，**不计入信号暴露**。

### 4.4 断链与安全模式

- 超出覆盖、被敌方干扰掐断、赶上静默夜，信号都会被强制弹回核心。
- 失去信号的机器回落到**安全模式**，只运行本地常规固件。
- 失联不是死亡：进入重连宽限期；宽限期结束仍不可解析才转为无控制目标（沿用 0.1）。

### 4.5 裸跑敌方固件与只有一道信号

- 核心可以**直接运行尚未破解的敌方固件**：只有信号能携带，不能装进机器或炮塔；每次发动确定性地增加暴露，热量上涨也比同类快。送解析台破解后才能量产。
- 远征途中家园遇袭：玩家可以把信号瞬间跳回家接入炮塔亲自防守，远征队交给 AI。要再跳回远征队，远征队必须在与核心连通的覆盖网络里（沿途信号中继塔或随队信号中继模块）。

### 4.6 信号暴露

- 暴露来源：高功率生产、核心固件发动、裸跑敌方固件、使用异派技术、摧毁敌方节点。
- 接入本身和操作时长不计入暴露：接入是本版核心玩法，不应该被惩罚。
- 关闭信号塔主动广播、摧毁监听节点可以降低暴露。
- 暴露到阈值触发家园突袭，并影响敌方在下一次远征中的反制编制；事件必须提前预警，不以墙上时间自动升级。

### 4.7 状态机

| 状态 | 允许输入 | 进入 | 退出 |
|---|---|---|---|
| 世界战略 | 选择、建造与规划、队列、工作单、常驻规则、编队、派遣、暂停、倍速 | 开局、退出接入 | 接入机器、打开模态 UI |
| 接入 | 移动、瞄准、主动作、功能动作、交互、核心固件发动、切换目标 | 合法接入请求完成 | 主动退出、目标死亡、断链、静默夜 |
| 模态 UI | 当前面板专属输入 | 蓝图、工厂、研究、熔合、设置、暂停菜单 | 确认、取消或关闭 |
| 过渡 | 无玩法输入 | 镜头飞跃、接入切换、信号跳转 | 成功进入目标状态或安全回退 |

单一无缝世界下不再有"家园战略 / 远征战略"两种战略态与出发退出家园的区域切换（C-13）。模态 UI 优先级最高；过渡期间冻结冲突输入；战略暂停允许选择和排队命令，但禁止接入态下的移动和攻击。

## 5. 机器分层、蓝图与固件

### 5.1 分层

**口诀：机器决定"用什么打"，你决定"打出去之后发生什么"。**

| 层 | 内容 | 归属 |
|---|---|---|
| 底盘 | 搬运轮式 / 战斗履带 / 维修悬浮；新增**固定底盘**（炮塔） | 机器 |
| 能源核（0 号格） | 电路板固定源点 | 机器 |
| 作战组件（8 号格） | 决定载体类型：射弹、格斗、无人机、力场、布区 | 机器 |
| 结构模块 | 重甲 / 散热鳍 / 货舱 / 信号中继 | 机器 |
| 3×3 基元电路板 | 通用节点 / 减振节点 / 高导节点，**新增接入口** | 机器 |
| 固件 | 常规固件装在机器上；核心固件只在信号核里 | 机器 / 信号 |
| 资源轴 | 电池与热量、废料、拆解回收 | — |

各层玩家可见名与旧内部 ID 的对照见 [TERM-MIGRATION.md](../../../production/design/earth-reclamation/TERM-MIGRATION.md) §6（0.2 名表）。

### 5.2 接入口

- 在家园编电路时，可以把 3×3 中任意一个空格标为接入口；**一台机器只有一个接入口**。
- AI 驾驶时接入口按空槽处理：照样传信号，但没有芯片效果。
- 玩家接入时，信号核里的固件按槽顺序插入接入口参与路径编译；放不下的固件不生效。
- 两难：电路配满交给 AI，稳定但平庸；留一个接入口，你在的时候它是怪物，你不在的时候它有缺口。

### 5.3 固件

- 四类物理包装：引信与弹芯、限制器与击发逻辑、流体改道、电磁场控。**固件不凭空造出硬件，只改变机器已有的硬件怎么用**；所有改变都有物理代价，落在电池和热量双轴上。
- **核心固件判定**：越过安全限制，或需要核心的实时算力。6 条核心固件全部属于"限制器与击发逻辑"。
- 名表共 44 条（旧 42 + 新建 2），以 [TERM-MIGRATION.md](../../../production/design/earth-reclamation/TERM-MIGRATION.md) §6.2 为准；读法、代价与数值见 FG02。
- 固件芯片成为物品，取消 Demo 的 8 格有限仓（D-08）；固件刻录台把已破解的固件批量刻成常规固件芯片。
- **熔合**：两条固件 → 一条混合固件，同时具备两者的读法；配方靠实验发现；熔合只有一层，混合固件不能再熔合（D-09）。熔合取代 0.1 合成台的数值配方。
- 具名反应先用行为探针核实触发配对，再命名、开放（FGR-FW-040～042）；每个阵营至少带来 2 条新的具名反应，大部分需要跨阵营组合。

### 5.4 蓝图、版本与旧机改造

- 一张蓝图包含：底盘、作战组件、结构模块、3×3 基元电路板（含可选接入口）与四邻有向导线、常规固件、工作优先级模板、战斗教义，以及版本号、显示名、成本、能耗、带宽、热量、阵营标签和编译签名。
- 编辑器在保存前生成编译预览、成本、代价、反应名和冲突原因；相同输入与内容版本必须得到相同编译签名；非法组合拒绝保存并显示原因；合法基元组合即使没有具名反应也走通用正交结算。
- 保存生成新版本，不原地改写已生产个体；旧机器回装配站付差额改造，保留 LogicId、编号、经历、伤痕和统计；被引用的版本只能归档，不能物理删除。
- 战场表现只读取正式编译结果，不得为 VFX 再算一套伤害、角度或目标。

### 5.5 机身形变

- 接入那一刻的形变是本作最重要的爽点，必须在上帝视角的镜头距离下也清楚可见。
- 表现层只读取正式编译结果。美术预算按类别做：引信与弹芯类只做弹体特效变体；其余三类每个作战组件各做 3 套机身状态（形变、喷口、线圈）。

### 5.6 机器个体

每台机器保存稳定 LogicId、显示编号、蓝图与版本、耐久、伤势、当前任务、经历、阵营、所在位置、装配签名和控制恢复标识。经历形成日志、离家报告与结局记录，不做对话树。阵亡永久，黑匣子可以带回。

## 6. 家园经营

### 6.1 为什么要自动化

**你只有一道信号。** 远征的时候，家园必须自己生产、自己防守。持续产出有四个去处：家园防御（炮塔、屏障、维修、弹芯耗材）；机队补给（维修件、冷却液、替换机体、新蓝图量产）；领土归还（净化塔逐格收复土地）；终局工程（返航信标与巨构，分阶段吞下大量产出）。

### 6.2 建造与建筑

- **格网自由建造，可以旋转**；Demo 的固定锚点建筑变成开局预置（D-01）。
- 拆除全额返还（D-04）；放置、拆除、编辑、排队都能撤销或取消（FG00 B03）。
- 电力改为电塔覆盖，可以分成多个子网（D-05）。
- 家园矿脉无限；废墟有储量，拆完变成可建空地（D-12）。
- **每座建筑都要有持续工作或额外功能**，不存在"造完只为解锁、之后放着不动"的建筑。建筑全表（核心、能源、信号、采集、加工、制造、研发、情报、维修、防御、领土、存储、终局 13 类）以 [正式版设计案](ProjectA_FullGame_Design.md) 6.2 为准，取代 0.1 的 8 座建筑封闭清单；规格见 FG03、FG04。

### 6.3 物流：全面传送带

- **传送带**：直带、转角、分拣、合流、升级带速；**管线**：流体输送、泵、储罐。
- 规划方式：上帝视角放置与规划，支持框选复制和粘贴布局。
- 施工方式：放置后生成建造工作单，由机器施工。**机器仍然是劳动力和主角**；吞吐量交给传送带。
- **常驻规则**：维持库存、低于阈值自动补货、战时优先级。
- 解锁节奏：第一幕第一次远征之后开放基础传送带；第二幕开放管线、分拣和高速带；第三幕开放巨构物流。
- 传送带和管线的逐物品模拟只在 AOT 内核（§16.1）。

### 6.4 工作与生产

- 工作单：搬运、建造、维修、拆解、充电；玩家设置工作类别优先级 1～4 或禁用；机器按优先级、距离、任务年龄确定性选择；不可达、缺料、目标消失和建筑停机都进入可见的等待、失败或重新分配状态（沿用 0.1）。
- 生产事务：排队只预留，开工才扣款；取消未开工订单全额释放，取消已开工订单退回未消耗部分；出口堵塞时产物留在原地，不重复生成（沿用 0.1）。

### 6.5 研发与情报

- 研究点由仿真实验室持续产出，解锁研发树；部分节点还需要关键材料；研发树按阵营分支。
- 解析台是反破解队列：敌方固件、组件、数据核心 → 蓝图和技术数据；空闲时从残骸慢慢提取技术数据。
- 仿真实验室兼作试车场，并分析远征回放给出熔合线索；监听站持续破译突袭预警、敌方反制、首领弱点与舰队信号片段。

### 6.6 离家报告

远征回来或随时打开：离家期间的产量、击退的突袭波次、炮塔触发了哪些反应和多少次、损失；附带自动化成就。这是偏经营玩家"大功告成、不用亲自插手"的主要回报。

## 7. 家园压力

### 7.1 突袭与塔防

- 触发：信号暴露阈值、剧情节点、静默夜。来源：从真实存在的敌方据点出发，沿地形行进；也可能袭击前哨站。
- 预警：保证最短预警时间；建了监听站，预警更早，还能看到敌方编成。
- 编成来自你最近刺激得最狠的阵营；目标优先级：信号塔、超控阵列、发电机，然后是归还核心。
- **炮塔就是固定底盘的机器**，同样有作战组件、3×3 电路、常规固件和可选接入口，不另造一套塔防规则；玩家可以接入炮塔亲自防守。
- 路线被完全堵死时敌人会攻墙，不允许完美迷宫（D-11）。
- 突袭时可以开倍速观战。

### 7.2 时间与静默夜

- 1 个游戏日 = 1x 下 20 分钟（D-18）；所有计时系统由统一游戏时钟驱动，暂停时同样暂停，0.5x～3x 倍速一致。
- 静默夜按游戏内时间周期到来（初值：每 5 个游戏日一次，持续约 3 分钟），提前 60 秒预警。期间所有信号中断：不能接入，不能下达远程命令；机器和炮塔只运行本地常规固件；敌方趁机大规模进攻。远征队同样进入安全模式。撑过去有奖励。

### 7.3 恶劣环境

- 家园天气按游戏内时间循环：酸雨（腐蚀建筑）、沙暴（降低视野与传送带效率）、寒潮（散热加快、管线可能冻结）。
- 区域专属危害见 §10；净化塔范围内天气危害降低。

## 8. 世界与远征

### 8.1 单一无缝世界

- 每个星球是一张按种子生成、按区块无限延伸的连续地图（v1 只有地球）；家园在原点，四个阵营领地在不同方向、不同距离，地形共享，镜头无缝（FG17）。取代 0.1 的三张固定地图与"出发时退出家园"的区域切换。
- Demo 三张手工地图的关键部分转为**手工锚点模板**：首领场地、剧情地点、伏笔地点按规则嵌入生成的世界。内容不得依赖固定坐标，必须在种子测试集的任意种子下成立（FG00 B25）。
- 开放顺序靠地理软门槛（危害带、大门、防空），不设看不见的墙。
- 整个世界同时运行：家园与远征、所有活跃区块（己方实体、行进中的突袭与巡逻、正在被观察）同时模拟；观察不改变结果（D-06）。

| 地点 | 阵营 | 幕 | 离核心 |
|---|---|---|---|
| 归还谷地（家园区） | — | 全程 | 0～200 格 |
| 破碎都市 | 静默 | 第一幕 | 400～600 格 |
| 铸造前哨（外围 + 核心区） | 铸造 | 第一幕 | 700～1,000 格 |
| 沉淀湖 | 澄净 | 第二幕 | 1,200～1,600 格 |
| 热寂数据城 | 超频 | 第二幕 | 1,500～2,000 格 |
| 白潮滩头 | 方舟舰队（白潮） | 第三幕 | 900～1,400 格 |
| 外延区 | 各阵营零散前哨 | 后期 | 2,500 格以外 |

### 8.2 远征流程

1. **派遣**：编成远征队、选目的地、看派遣检查单。派遣不退出家园。
2. **行军或投送**：前期沿地形行军；第一幕末解锁投送站，可以把机器投送到已探索、没有防空的落点。"离家"的代价来自距离、单信号和中继覆盖（D-07）。
3. **领地内**：主线、支线、精英、终端、遗迹、据点。走出信号覆盖的远征队只执行最后的命令。
4. **前哨站**：可以在远处建中继、维修、仓库、炮塔，把前线推过去。
5. **返回**：走回家园或前哨站，或呼叫投送舱回收；回到带仓库的地点时结算。阵亡机器不复活，黑匣子可以带回。
6. **收复**：击败首领、拔掉据点后，领地变为已收复，可以净化和建设，与家园连成一片。

没带走的普通战利品 1 个游戏日后被敌方回收；关键材料和数据包永不消失，全灭也不会永久丢失关键材料（D-13）。

### 8.3 编队命令

封闭命令：移动、攻击、守备、撤退（沿用 0.1）。命令只控制移动意图，非接入单位按自身装配和教义战斗；玩家当前接入的机器不接受编队命令；战略暂停中命令按下达顺序排队，恢复后执行。

## 9. 掉落与反破解

| 来源 | 掉落 | 方式 |
|---|---|---|
| 杂兵 | 废料、材料、常见固件 | 普通掉落，由机器捡进货舱 |
| 精英 | 组件、稀有固件、加密数据 | 三选一 |
| 阵营首领 | 该阵营的核心固件和关键材料（固定），另加一次三选一 | 固定 + 三选一 |
| 遗迹终端 | 蓝图、人类遗产 | 固定 |
| 指定任务 | 卡进度的关键材料 | 固定，不随机 |
| 事件 | 视事件而定 | 三选一或固定 |

- 三选一生成"待分拣数据包"，**不在战斗中弹出**；回到家园、带仓库的前哨站或战略暂停中处理；没选中的两个自动转化为少量技术数据；候选池 = 区域阵营池 + 通用池，按稀有度抽取，设保底。
- 货舱容量有限，每件物品占用不同空间，装车本身也是取舍。
- 两种去向：**直接可用**（人类遗产、中立协议的固件和组件、耗材、材料）；**需要反破解**（敌方加密固件、敌方接口组件、数据核心）。破解前可以由核心裸跑（§4.5）。

## 10. 敌方阵营与反制

| 阵营 | 前身 / 真相 | 技术类别 | 区域危害 | 首领 | 首领固定掉落 |
|---|---|---|---|---|---|
| 静默 | 通信与监控网络；在躲轨道扫描 | 电磁场控 | 电磁噪声：信号覆盖缩短 | 寂听主脑 | 核心固件：标记跳转、集群协议 |

| 澄净（内部代号化工） | 环境修复系统；执行自己的"净化" | 流体改道 | 酸沼：持续腐蚀 | 洗礼塔 | 核心固件：反应增幅 |

## 11. 惊喜与惊吓事件

不按固定日程出现，每个都要有预警和回报：掘进蠕虫（提取钻震动值越阈值）、静默夜、信号幽灵（第二幕起一台机器被未知信号短暂夺控）、轨道坠落、诱饵终端、流浪商队。详细规则见 FG10。

- 被事件夺控的己方机器被击倒后进入瘫痪，不阵亡（D-10）：被事件夺控不是玩家的失误。

## 12. 叙事与终局：舰队反转

- **背景**：地球生态崩溃后，人类冷冻睡眠，乘方舟舰队离开；舰队派出归还核心（玩家）恢复电力、建立据点、点亮返航信标。舰队没告诉核心的是：返航前会执行"净化协议"，清除地表所有可能偏离设定的自治机器，**归还核心自己也在清除名单上**。
- **伏笔**：静默日志"天上的眼睛"、铸造的高仰角对空阵地、澄净广播"净化即救赎"、超频首领残骸里的破译片段、信号幽灵、监听站解出的舰队信号片段。
- **揭示**：返航信标与巨构最终阶段完工，信标点亮；舰队应答"归还核心任务完成，净化协议启动"。执行清洗的是方舟舰队的自动舰群"白潮"，由先遣旗舰"归乡号"率领。
- **三段终战**：清洗波次攻打家园（塔防总考）→ 进攻白潮滩头（摧毁轨道锚点和登陆信标）→ 最终首领先遣旗舰"归乡号"（轨道轰炸、登陆要塞、根权限压制；根权限夺取是只在这一场出现的脚本化首领机制，不属于常态 AI 行为，且不能夺取玩家所在的机器）。
- **结局（击退结局）**：先遣舰队被击退，主舰队仍在轨道上，人类仍在沉睡；归还核心继续守着这片土地。结算沿用 Demo 的机器故事：幸存机器、阵亡记录、每台机器的经历。
- **后日谈沙盒**：家园继续运转；主舰队周期性派出升级的清洗波次；沙盒关闭剧情时，关键材料改为用研究点换取（D-19）。

## 13. 胜负、失败与难度

### 13.1 胜利

击退先遣旗舰"归乡号"，进入击退结局与后日谈沙盒。取代 0.1"摧毁铸造主核心 + 启动导航信标"的 Demo 胜利条件；返航信标变为第三幕的终局工程与揭示触发点。

### 13.2 战役失败

归还核心被毁触发失败界面；可以读取最近自动存档或返回主菜单；不得停留在不可操作世界。

### 13.3 软失败

断电、缺料、产线堵塞、仓满、远征全灭、断链、控制目标丢失、关键模块未带回均可恢复；每种都提供原因、当前影响和至少一个恢复动作。机器阵亡永久，黑匣子可以带回。

### 13.4 难度

突袭强度（从面向纯经营玩家的"建造者"到"严酷"）、静默夜频率；只影响压力，不影响剧情和解锁。

## 14. UI、引导与可访问性

- **教学最后做**：各 Story 只埋引导钩子事件，引导内容统一在 FG15-UX-04 实现；关闭教学的玩家必须能走完相同战役并得到相同结果；提示不得代操作（沿用 0.1 后置教学原则）。家园指引任务可以在设置里关闭（D-22）。
- 新面板用 UI Toolkit；玩家可见文本一律走文本键（FG00 B16）。
- 图鉴的机制条目跨存档共享；剧情资料库按存档保存（D-17）。
- 可访问性下限：所有快捷键可重绑；镜头移动、缩放、边缘滚动可调或关闭；暂停与 0.5x～3x 倍速，模态 UI 不受速度影响；颜色之外同时使用图标、轮廓和文字；屏幕震动、闪光、慢放、镜头推动可关；关键警报有字幕与视觉提示；UI 缩放至少 80%～140%；按住类操作可改为切换（FG00 B15）。
- 通知分紧急 / 警告 / 信息三级并聚合，点击能定位，有历史记录（FG00 B08）。

## 15. 美术、声音与题材红线

- 视觉目标：工业废土、模块化硬表面、清晰轮廓、中等细节、俯视可读。玩家为冷白装甲与青蓝核心光；四阵营与白潮各有可区分的轮廓语言（白潮洁白、流线、成群，与地面阵营的粗粝风格对比）。
- **题材红线**：玩家可见内容不得出现旧生物题材词（细胞、器官、基因、吞噬、代谢、谱系、萌生、债兽、孢子、菌丝），也不得出现 0.2 名表的内部代号与退役旧名；完整禁用词与正式名以 [TERM-MIGRATION.md](../../../production/design/earth-reclamation/TERM-MIGRATION.md) §2.3、§6 为准，自动审计（题材审计词表）与之逐词一致。旧内部 ID 和类名可以暂留，但必须经机械包装。
- 功能声音：接入成功或拒绝、断链、低电、仓满、生产完成、突袭预警、静默夜预警、反应触发、首领阶段转换等；重要声音均有非声音等价反馈；同类音效有数量上限。

## 16. 技术、存档与性能约束

### 16.1 硬约束

- Unity 6000.3.17f1，Built-in RP；不用 Entities/ECS，只用 Burst + Jobs + Collections + Mathematics。
- 逐物品、逐单位、逐弹体的 O(N) 逻辑只在 AOT 内核 `Main/Sim/`；传送带和管线的逐物品模拟、层级寻路、炮塔弹道都在内核；弹道唯一真相在内核，炮塔也走 `JobProjectile`。
- 热更层每帧 O(1) / O(卡牌)，只读汇总结果；热更接触内核只经 SimBridge；表现层只读取编译结果，不写模拟真相。
- 统一游戏时钟驱动所有计时系统（生产、研究、解析、突袭、天气、静默夜）。
- 新数值入 Luban 表，新文本走文本键，新面板用 UI Toolkit。

### 16.2 可复用的现有系统

`AiHandoffSystem` / `ControlHandoffState`（接入与交还）、`EmissionContext`（玩家与 AI 同一套规则）、`CameraDirector`、`PathCompiler`（加入接入口格子）、`OverloadSuppressionMirror`（热量按机体归属）、`MechanicalReactionCatalog`、信号塔与暴露账本、工作单、生产队列、解析台、`BagInventory` / `TransferService`、Luban 表（`tools/cell_tables/`）。详见 [正式版设计案](ProjectA_FullGame_Design.md) 15.2 与 FG14。

### 16.3 存档与性能

- 存档 v2：磁盘使用跨进程稳定 LogicId，不保存 SimEntityId；世界存种子与改动；写盘先写临时文件再原子替换；坏档拒绝加载到安全状态并保留备份；在任意时刻存读档不复制、不丢失实体和物品（FG15、FG00 B10）。
- 性能预算、种子测试集与发布候选标准见 FG15、FG16、FG17；每个里程碑的性能场景相对上一个里程碑退化不超过 10%。

## 17. 0.2 完成定义

正式版只有同时满足以下条件才可称为完成（FG-M15 出口）：

1. 每个里程碑出口满足 [正式版里程碑](ProjectA_FullGame_Milestones.md) 第 3 节：Story 全部 Completed 并附 FG00 第 6 节输出；旅程机器人从主菜单走完出口旅程；反向旅程覆盖资源不足、目标死亡、断链、暂停与倍速、存读档、路径失败；性能不退化；本里程碑缺口全部关闭；需要试玩的里程碑通过 FG16 标准。
2. 玩家从主菜单新建战役（可指定种子），在同一个无缝世界里完成三幕主线与三段终战，得到击退结局并进入后日谈沙盒。
3. 所有界面、反馈、题材资产与禁用词审计通过；不允许玩家看见开发占位；任何 P0 / P1 问题为零；任何测试种子都不失败。
4. 人工体验审核只剩乐趣与品味判断（FG00 第 9 节）。
