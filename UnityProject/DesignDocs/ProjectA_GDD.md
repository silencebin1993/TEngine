## 1. 产品定义

### 1.1 一句话体验

玩家是人类从避难星球发射回地球的**地球归还核心**：在废墟中建立机械聚落，让机器自动工作与生产，需要时亲自驾驶任意一台机器出征，夺取敌方技术、摧毁敌方主核心，直到地球重新适合人类返航。

### 1.2 类型与比重

| 体验层 | 目标比重 | 核心乐趣 |
|---|---:|---|
| 机械聚落经营 | 45% | 改建废墟、规划电力 / 信号 / 仓储、看机器自动干活、优化生产线 |
| 编队远征与战役决策 | 35% | 选择战区、带什么蓝图、何时出征、如何拆敌方网络 |
| 任意机器直控 | 20% | 关键突破、精确拆解、抢残骸、救场 |

这不是「RTS 外面套肉鸽」，也不是「纯动作割草」。  
三层共用同一世界：家里的工厂生产出的机器，就是远征时能直控的身体。

### 1.3 与传统 RTS 的硬边界

**不做：**

- 开局抢矿、铺农民、几分钟内兵海压制；
- 无限扩张占地图；
- 高 APM 多线微操作为主乐趣；
- 敌方每分钟无脑冲家逼你快节奏。

**做：**

- 可暂停、可慢慢改建自己的小世界；
- 机器有编号、工作记录、损伤史，值得关心；
- 出征是主动选择，不是永久催促；
- 生产重点是**蓝图质量与兼容组合**，不是数量。

### 1.4 目标玩家

- 喜欢在自己的小世界里改建、观察、优化；
- 喜欢模块构筑与跨阵营技术拼装；
- 喜欢关键时刻亲自驾驶一台机器救场；
- 不要求星际争霸式手速，但愿意做战略取舍。

### 1.5 商业与范围

- 单机买断；
- 首发：一个完整「归还地球」战役，可重复游玩；
- 允许暂停、0.5× / 1× / 2×；
- 无强制倒计时、无缩圈、无「再不行动就刷末日」的隐藏橡皮筋。

### 1.6 独特性承诺（必须同时成立）

1. **家与战场一体**：聚落里造的机器，就是远征与直控的身体。  
2. **跨阵营编译**：只有归还核心能把互不兼容的阵营技术编进同一台机器。  
3. **任意接管**：不是固定主角；你随时进入任意己方机器。  
4. **清场回家**：终局是清除异己网络并打开返航走廊，不是「养出天敌再杀掉」。

任何功能若不能强化至少一项，不进首发。

## 2. 世界观与因果链

### 2.1 你是谁

你是**地球归还核心**（Earth Reclamation Core）。

你不是一台战斗机器人，也不是人类驾驶员。  
你是一套可展开的指挥 / 生产 / 技术解析协议，被装进一枚降落舱送回地球。

### 2.2 你从哪来

人类曾把高强度战争交给多方 AI 机器军团。战争失控后，地球被多个机器阵营分割，地表与轨道不再适合人类居住。人类撤离到另一颗避难行星建立殖民地。

避难星只能短期维持：

- 生态与工业资源不足；
- 人口无法长期增长；
- 关键制造与基因库仍在地球；
- 殖民地系统逐渐衰退。

人类必须回地球，但地球仍被自主战争机器占据。

### 2.3 你要干什么

**表层任务：**  
在地球建立归还网络，摧毁所有非己方机器阵营的主核心，清理轨道与着陆走廊，让人类返航。

**玩家日常目标：**

1. 把坠毁点改造成可运转的机械聚落；  
2. 生产并迭代机器；  
3. 远征敌区，回收模块与蓝图；  
4. 解析敌方科技，编出更强机器；  
5. 逐个清除四大阵营主核心；  
6. 启动地球归还程序。

### 2.4 敌人是谁

地球上仍有四个自主机器阵营。它们的**最高任务统一为**：

> **清除所有非己方机器，独占地球。**

它们不是「各守一种设施的管理员」，而是互相开战的战争网络。  
玩家的出现被它们识别为第五个外来核心，因此同样必须被清除。

### 2.5 为什么人类不能远程关机

- 各阵营协议互不兼容，且部署了死手协议；  
- 统一远程关闭会被识别为入侵并摧毁关键基础设施；  
- 大量系统已离网，必须物理接近；  
- 人类不敢把完整超级战争 AI 整建制送回地球。

因此只发射一枚**能力受限、可本地扩张**的归还核心。

### 2.6 为什么开局弱

弱的不是「智力低」，而是：

- 没有工厂；  
- 没有能源；  
- 没有地图；  
- 大规模生产 / 自我复制 / 轨道武器权限被人类故意锁死；  
- 大部分战争记忆被删除（防失控）。

你必须靠拆解与本地生产把权限一点点编回来。

### 2.7 终局意义

清除异己后，地球重新成为人类可降落的家园。  
胜利画面：返航舰队进入轨道，玩家的聚落灯火成为着陆导航点。

（**已锁定**：返航成功后保留少量无法确认身份的机器信号，作续作钩子；不进首发主线任务，但结算/尾声可暗示。）

## 3. 玩家主体：三层结构

### 3.1 归还核心（身份层）

实体表现：聚落中央的核心舱 + 通讯塔 + 指挥穹顶。

职责：

- 保存蓝图库；  
- 解析敌方科技；  
- 发出直控请求；  
- 管理信号带宽；  
- 执行人类返航协议。

核心被彻底摧毁且无备份节点 = 整局失败。

### 3.2 机械聚落（家园层）

玩家可长期改建的「小世界」：

- 生产车间；  
- 能源阵列；  
- 维修平台；  
- 资源仓库；  
- 机器停泊区；  
- 信号塔；  
- 防御炮台；  
- 后期返航设施。

这里是放松与经营空间：可以暂停、规划电力、改房间布局、看机器自动工作。

### 3.3 机器单位（身体层）

地图上的真实实体。玩家可：

- 分配工作（采集、搬运、维修、建造、守卫、侦察）；  
- 编队出征；  
- 随时直控其中任意一台。

直控时镜头跟随该机器；其他机器继续执行任务。  
机器损毁 ≠ 核心死亡；控制权可回弹到其他友军或回核心。

**禁止再把玩家设计成「一台不断换外挂的主角战车」。**

## 4. 核心循环

### 4.1 每分钟循环

1. 观察聚落：电力、仓储、生产线、机器故障；  
2. 暂停并调整：建造、改线路、改蓝图、改工作分配；  
3. 让机器自动工作；  
4. 决定是否出征某个邻近废墟 / 敌区；  
5. 选择携带的机器与蓝图；  
6. 远征中切换直控处理关键局部；  
7. 带回残骸、模块、数据；  
8. 解析科技，升级工厂与蓝图；  
9. 扩大聚落或准备下一次清除行动。

### 4.2 战役节奏（非倒计时）

| 幕 | 玩家主动承诺 | 内容 |
|---|---|---|
| 第一幕：扎根 | 建立稳定供电与第一座工厂 | 家园区清理、基础机器、第一批远征 |
| 第二幕：夺技 | 摧毁任意一个阵营区域主节点 | 开始跨阵营编译、建立前哨 |
| 第三幕：清场 | 摧毁四大阵营主核心 | 大规模远征、改造敌方工厂 |
| 终局：归还 | 启动返航走廊 | 清理轨道接口、打开着陆区、人类返航 |

压力来自：资源枯竭、敌方区域活动、出征风险，**不是墙上时钟**。

## 5. 对象模型与术语

| 对象 | 是什么 | 怎么来 | 有什么用 |
|---|---|---|---|
| 归还核心 | 玩家身份与指挥中枢 | 开局降落 | 蓝图、直控、解析、终局协议 |
| 聚落 | 可扩建家园 | 改建废墟 | 生产、仓储、维修、防御 |
| 工厂 / 装配站 | 生产与蓝图编译设施 | 建造或占领 | 生产机器、改蓝图 |
| 蓝图 | 某类机器的装配配方 | 解析 / 设计 | 决定新生机器能力 |
| 机器个体 | 场上真实单位 | 工厂生产 | 工作、战斗、被直控 |
| 作战组件 | 原「攻击器官」 | 回收 / 研究 | 武器与主动动作 |
| 结构模块 | 原「结构器官」 | 回收 / 研究 | 装甲、散热、载荷、被动 |
| 固件协议 | 原「基因」 | 解析敌方数据 | 修饰组件行为与组合反应 |
| 模块反应 | 原「代谢 / 命名反应」 | ComposeEngine | 跨组件 / 跨阵营组合效果 |
| 拆解回收 | 原「吞噬」 | 战场残骸 | 材料与可解析模块 |
| 信号带宽 | 指挥资源 | 核心 / 信号塔 | 同时稳定控制的机器数与直控距离 |
| 阵营主核心 | 敌方根网络 | 地图上的最终目标 | 摧毁后该阵营崩解 |

### 5.1 关系约束

- 一个工厂可维护多条蓝图；  
- 一条蓝图可生产多个个体；  
- 一个个体任一时刻只表达一个蓝图版本 + 有限现场改装；  
- 编队可混编不同蓝图的机器；  
- 直控锁定个体，不锁定蓝图；  
- 跨阵营组合发生在蓝图编译层，不是魔法全图换装。

## 6. 聚落经营（模拟经营层）

### 6.1 设计目标

玩家应感到「这是我的机械小世界」，而不是「我必须在 8 分钟内打爆对面」。

参考乐趣（不是抄玩法）：

- **缺氧**：电力与线路连锁故障（v1 不做气体/温度）；  
- **环世界**：角色（机器）有故事、事件、损伤与工作优先级；  
- **泰拉瑞亚**：探索废墟、带回材料、扩建家园。

### 6.2 家园系统清单（首发）

| 系统 | 玩家做什么 | 失败时发生什么 |
|---|---|---|
| 电力 | 建发电机、铺线路、平衡负载 | 生产线停转、直控延迟、防御掉线 |
| 信号 | 建信号塔、维持带宽 | 无法远程下令 / 直控距离缩短 |
| 仓储 | 规划仓库与搬运路径 | 生产堵塞、出征带不走战利品 |
| 维修 | 分配维修机、备件 | 机器带伤工作直至报废 |
| 生产 | 排队蓝图、分配车间 | 出征缺兵、关键蓝图编不出 |
| 防御 | 炮台、警戒机、封锁口 | 敌方侦察队袭扰（低频、有预兆） |
| 改建 | 拆墙、铺路、改房间 | 无「做错就死」；只影响效率 |

### 6.3 机器工作 AI

每台重要机器有：

- 机体编号；  
- 蓝图版本；  
- 工作优先级；  
- 损伤与故障记录；  
- 常用任务；  
- 行为倾向（谨慎 / 高效 / 鲁莽等，由固件影响）。

玩家可设优先级，不必逐帧微操。  
故事来自故障、堵塞、远征损伤与「老机器」经历，而不是给机器写人类台词。

### 6.4 敌方袭扰规则（防 RTS 化）

- 敌方不会无预警无限冲家；  
- 袭扰有侦察信号、时间窗、可拦截路径；  
- 玩家可选择加固、出征反打、或暂时断电隐蔽；  
- 家园被毁一部分 = 软失败，不是瞬间 GG（除非核心被毁且无备份）。

## 7. 生产、蓝图与模块

### 7.1 生产不是兵海

默认规模：

- 家园常驻重要机器：约 8～20 台；  
- 单次远征携带：约 3～8 台；  
- 临时打印有次数 / 材料上限。

### 7.2 蓝图编辑

玩家在工厂界面编辑蓝图：

- 1 个底盘；  
- 1 个主作战组件；  
- 0～1 个功能组件；  
- 0～1 个结构模块；  
- 2～4 个有序固件协议；  
- 1 套工作 / 战斗教义。

提交后：

- **新生机器**用新版；  
- **旧机器**必须回厂改造，支付材料与时间；  
- 不会瞬间全图换装。

### 7.3 模块装在哪

| 对象 | 可安装内容 |
|---|---|
| 机器蓝图 | 作战组件、结构模块、固件协议 |
| 工厂 | 生产速度、能耗、解锁重型、拆解效率、跨阵营兼容槽 |
| 归还核心 | 带宽、直控冷却、解析速度、备份节点、返航协议进度 |

### 7.4 获取途径

- 拆解战场残骸；  
- 占领 / 改造敌方工厂；  
- 解析数据包；  
- 稀有完整模块（高风险完整回收）。

拾到实物 ≠ 解锁蓝图；需解析归档。

## 8. 战斗基元与跨阵营组合

### 8.1 基元保留

底层仍使用现有战斗基元语义（穿透、分裂、追踪、反弹、拖尾、区域、链接、召唤、干扰等）。  
展示层改为机械语言。

ComposeEngine 的 Packet 链与命名反应继续作为「模块反应」真相源。

### 8.2 四阵营技术树

| 阵营 | 视觉 / 结构语言 | 战斗特长 | 可回收方向 |
|---|---|---|---|
| 铸造 | 厚重、铆接、履带、炮塔 | 正面火力、装甲、冲击 | 重炮、装甲、攻城底盘 |
| 日冕 | 细长、散热鳍、镜面板、悬浮 | 激光、热能、远程精准 | 高能电池、过热武器 |
| 蜂巢 | 多模块拼接、小机体群 | 复制、维修、数量压迫 | 无人机舱、自修复、分裂 |
| 静默 | 低矮、吸波黑、天线密 | 干扰、伪装、短暂接管 | 电子战、标记、假目标 |

### 8.3 跨阵营组合（归还核心特权）

示例（首发需可验证，不必一次做满）：

| 组合 | 结果直觉 |
|---|---|
| 铸造底盘 + 日冕热能 | 熔穿重炮：慢、痛、过热 |
| 日冕激光 + 静默标记 | 光束沿标记网络跳转 |
| 蜂巢复制 + 铸造装甲 | 装甲工蜂群 |
| 蜂巢复制 + 静默干扰 | 伪装无人机，被识破则整组暴露 |
| 铸造冲击 + 静默干扰 | 电磁冲击波，短控 + 破甲 |

组合必须：

- 在蓝图预览中可见；  
- 有代价（能耗、过热、暴露、带宽）；  
- 有至少两种对策（对敌人用时也成立）。

### 8.4 为什么敌人会「针对你」

不是魔法学习玩家菜单，而是：

1. 你的控制信号与独特编译特征可被侦测；  
2. 战场残骸暴露你使用的模块类型；  
3. 阵营在自己的技术树上部署克制编制（例如你常用热能 → 铸造派出耐热装甲编制）。

这是**编制反制**，不是「复制你的整套构筑变成债兽」。

---

## 9. 直控

### 9.1 规则

- 信号覆盖内可请求接管任意友方机器；  
- 同时只有一个直控焦点（可后续扩展双通道，首发不做）；  
- 退出后该机器恢复 AI 教义；  
- 死亡时控制权回弹其他友军或回核心（沿用现有 `ControlledUnitId` / `ControlChangeReason` 契约）。

### 9.2 直控价值

AI 可靠完成：移动、普通攻击、按教义工作 / 护送 / 撤退。  
玩家优势：精确瞄准、险招、完整拆解、卡角度、临时牺牲路径。

### 9.3 与经营的关系

直控不是逃避经营的万能主角模式：  
单体不能同时修电厂、搬完仓库、守住所有口子并清完敌区。

## 10. 地图与空间

### 10.1 结构

不做无限开放世界。使用「可深入改建的区域网」：

1. **归还谷地（家园）**：最安全，主聚落；  
2. **破碎都市**：民用废墟、通讯与轻型模块；  
3. **铸造荒原**：重工业与重装敌人；  
4. **蜂巢地下**：复制设施与狭窄通道；  
5. **日冕高地 / 轨道电梯**：能源与终局返航接口；  
6. **静默盲区**：电子战与数据中心。

### 10.2 改建

玩家可把敌区前哨改造成自己的：

- 充电站；  
- 临时工厂；  
- 信号中继；  
- 仓储；  
- 防御点。

这强化「小世界被一点点变成我的」的感觉。

---

## 11. 胜负

### 11.1 胜利

同时完成：

1. 四大阵营主核心均被摧毁或强制离线；  
2. 返航走廊（轨道 + 着陆区 + 导航信标）可用；  
3. 玩家主动启动地球归还程序；  
4. 人类舰队成功进入预定轨道。

### 11.2 整局失败

- 归还核心被毁且无备份节点；  
- 或所有生产与解析能力永久丧失且无法重建（极端软锁，应尽量用设计避免）。

### 11.3 软失败

- 单机损毁、前哨失守、蓝图污染、电力崩溃、远征全灭 —— 均可重建，但有代价。

## 12. UI 信息层级

### 12.1 聚落视角常驻

- 电力 / 信号 / 仓储摘要；  
- 生产线队列；  
- 警报（故障、入侵、堵塞）；  
- 当前战役目标。

### 12.2 远征 / 战略视角常驻

- 选中编队与教义；  
- 带宽占用；  
- 远征携带清单；  
- 敌方编制提示。

### 12.3 直控视角常驻

- 当前机器编号与蓝图版本；  
- 组件状态、过热 / 能耗；  
- 可切换友军列表；  
- 撤离路径。

### 12.4 蓝图编辑器必须回答

1. 这是什么组件 / 固件；  
2. 从哪来；  
3. 装到哪台蓝图、影响新生还是回厂改造；  
4. 输出与成本；  
5. 冲突、过热、暴露与阵营标签。

## 13. 美术与声音方向

### 13.1 关键词

**工业废土、硬表面、模块化战车 / 无人机、锈蚀与冷白核心光、阵营轮廓可辨、无生物组织。**

### 13.2 阵营识别（不能只靠染色）

- 铸造：铸铁灰、铆钉、厚炮塔；  
- 日冕：灼热橙 / 镜面、散热片；  
- 蜂巢：工业黄、多节肢拼接；  
- 静默：吸波黑、天线林；  
- 玩家：冷白装甲 + 青蓝核心光。

### 13.3 相对生物题材的制作判断

纯机械更利于：

- 模块复用；  
- 硬表面流程；  
- 损伤与拆解表现；  
- 现有混元 / 绑定管线。

风险：同质灰坦克 —— 用轮廓与运动方式强制区分阵营。

**已锁定**：旧生物美术资产全部停用；新内容只硬表面机械。

## 15. 最终设计结论

本作应做成：

> **在毁灭地球上经营一座机械聚落，用跨阵营编译制造独特机器，必要时亲自驾驶它们清除所有异己战争网络，把家园还给人类。**

它借用模拟经营的「家与改建」，借用小队战术的「出征与直控」，借用现有组合引擎的「模块化学反应」，但不再依赖细胞幻想与债兽终局。

若家园经营本身不好玩，加更多武器没有意义；  
若跨阵营编译与直控接管成立，每多一个模块与区域都会成倍扩展可能性。
