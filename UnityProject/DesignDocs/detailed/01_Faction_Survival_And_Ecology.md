## 1. 产品结论

双方不是“玩家有经济、敌人按导演刷出”。它们争夺同一世界中的物质、供能、空间和信息，并共用采集、搬运、供养、修复、繁殖、守护、样本和信号能力。差异来自阵营目标、权限、器官、教义和风险偏好。

这套规则回答四个根本问题：

1. 个体为什么移动、战斗、撤退或回巢；
2. 编队和护群为什么需要食源、运输与守护；
3. 玩家为什么不能无限造兵，敌人为什么不能无成本刷兵；
4. 断粮、伏击、诱离和争夺领地为什么能成为战斗以外的有效方案。

## 2. 目标层级

### FS-REQ-001 个体目标

每个活体个体至少有：完整度、本地代谢储备、载荷、所属阵营/谱系、当前任务、威胁记忆和信号状态。

默认优先级从高到低：

1. 不可违抗的剧情/门禁状态；
2. 立即致死风险的脱离、闪避或求援；
3. 玩家显式命令或 Alpha 群体命令；
4. 搬运物所有权、护送对象和正在执行的不可瞬间取消动作；
5. 教义/谱系职责；
6. 补充本地储备、修复、回巢；
7. 自主觅食、巡逻、采样或待机。

“立即致死风险”只能短暂覆盖命令，且必须给出中断原因；教义可调整撤退阈值。玩家单位不能因为轻微饥饿擅自放弃关键搬运，敌人也不能因为看见玩家就永久忘掉食源和巢。

### FS-REQ-002 编队/护群目标

编队或护群维护共同任务、集合锚点、资源余量、成员职责和撤退条件。它不复制个体状态；只对成员目标做协调。

- 玩家编队优先执行玩家命令与教义；
- 普通敌群优先维持巢区、运输与谱系职责；
- Alpha 护群优先维持核心个体、食源线、信号链和暴露窗口；
- 群体失去信号时降级为成员本地策略，不应全部站桩。

### FS-REQ-003 谱系目标

谱系需要保留至少一个可繁殖节点、足够生物质/代谢流和可复现的遗传信息。谱系会为繁殖、修复、适应和领地做资源取舍，而不是只计算当前战斗 DPS。

### FS-REQ-004 阵营最终目标

- 玩家文明：维持文明种子与谱系，完成三个锚点外部应答，吸收债兽并破壳发射。
- 敌方生态：维持星舰局部稳态，回收异常信息，隔离或吸收会改写组织的玩家文明。

普通 AI 只需要知道可执行的局部目标；阵营导演把最终目标分解为巢、食源、样本、领地和猎杀任务。

## 3. 共享资源

### FS-REQ-010 生物质

可库存的物质。来源为食源采集、尸体/器官回收、环境组织和首领储备；去向为孕育、修复、改造、铺管、筑巢、育化和补员。

每一份生物质只能处于一个状态：`World / Reserved / Carried / Stored / Consumed / Lost`。状态转换必须有事务 ID，取消或失败按来源规则退款，不能同时被两方消费。

### FS-REQ-011 代谢流与本地储备

- 代谢流：网络或食源每秒可提供的供能能力，不是可无限堆叠货币；
- 本地储备：身体实际携带的短期能量，离开供能范围后消耗；
- 高耗器官、搬运重物、修复和高速移动增加消耗；待机和低耗教义降低消耗。

低储备按可读阶段降级：先禁止高耗可选动作，再降低再生/补员，最后降低机动；不得在无预警时直接死亡。完全耗尽后仍保留最低求生移动，使单位能尝试回到食源，除非伤势本身使其失能。

### FS-REQ-012 信息资源

器官、样本和记忆记录是可搬运信息实体：

- 玩家把它们带回分析囊变成蓝图；
- 敌人把它们带回育化巢变成适应证据；
- 实体被抢夺、摧毁、污染或读档恢复时必须保持唯一所有权；
- UI 显示来源、携带者、目的地、预计结果和拦截机会。

### FS-REQ-013 信号

信号传播群体目标、样本警报、食源状态和意识传递请求。信号有来源、覆盖、延迟、干扰和优先级；不能等同于全图全知。

玩家和敌人使用同一传播/干扰规则，但加密权限不同。玩家不能用敌方中继直接下令，敌人也不能读取玩家菜单，只能观察已广播内容和世界痕迹。

### FS-REQ-014 空间资产

食源、巢位、萌生腔、导管接口、锚点、掩体和迁徙通道都是可占用的空间资产。占领不是瞬间改颜色：必须满足清场/共生、连接、投入资源和维持条件。

## 4. 食源模型

### FS-REQ-020 定义

食源是将世界中的物质或环境能量转换为生物质/代谢流的对象。每个食源至少声明：

- 类型与世界位置；
- 所有权/争夺状态；
- 当前库存、产率和恢复规则；
- 可接入的搬运或导管接口；
- 暴露的破坏部位；
- 对不同谱系的效率；
- 可生成的气味、热、信号或遗迹痕迹；
- 耗尽、污染、断开和读档行为。

### FS-REQ-021 食源类型

开放集合，首个固定场景至少覆盖：

| 类型 | 产出 | 主要风险 | 可形成的玩法 |
|---|---|---|---|
| 营养囊 | 稳定代谢流 | 接口易被切断 | 占领、铺管、护卫 |
| 腐解床 | 尸体转生物质 | 暴露高、敌我争抢 | 战后回收、诱敌、污染 |
| 可猎食生物群 | 移动生物质 | 会逃离或迁徙 | 追猎、驱赶、保护 |
| 导管虹吸口 | 高流量能量 | 会伤害原网络 | 破坏、偷取、反制 |
| 高能遗迹 | 一次性高价值 | 触发环境或警报 | 冒险、伏击、替代路线 |

新增类型必须通过同一接口表达，不按阵营复制实现。

### FS-REQ-022 食源状态

`Dormant → Discovered → Claimed/Contested → Connected/Harvested → Depleted/Polluted/Destroyed`

争夺、采集和耗尽由资源事务推进；暂停时不推进。食源易主时，在途资源仍属于原事务，不能瞬间翻转库存。

## 5. 共享能力组件

### FS-REQ-030 能力清单

以下是第一版封闭清单；后续可追加，但不能为同一含义另造阵营专用版本：

| 能力 | 输入 | 输出/状态 | 失败原因 |
|---|---|---|---|
| 感知 | 位置、感官、信号、遮挡 | 已知目标与置信度 | 超距、遮挡、干扰 |
| 移动/寻路 | 目标、体型、通行规则 | 路径与移动意图 | 不可达、卡死、目标失效 |
| 攻击 | 装配、发射上下文、目标规则 | 弹体/范围/状态 | 资源、冷却、失能、非法目标 |
| 采集 | 食源接口、容量、时间 | 资源事务进入 Carried | 耗尽、被占、容量不足 |
| 搬运 | 实体/资源、目的地 | 所有权和载荷变化 | 载体死亡、目标满、路径失败 |
| 进食/供养 | 储备缺口、供给对象 | 代谢储备增加 | 食物不足、距离、敌对权限 |
| 存储 | 携带物、仓/巢 | Stored/归档队列 | 断网、仓毁、容量不足 |
| 修复 | 伤势、物质、供能 | 完整度/器官状态恢复 | 交战、资源不足、接点被毁 |
| 繁殖/孕育 | 模板、物质、空间 | 新生个体 | 资源、空间、节点失联 |
| 守护/护送 | 保护目标、威胁 | 阵位、拦截、撤离 | 目标失效、信号断开 |
| 撤退 | 安全目的地、威胁 | 脱离并重组 | 路径失败、无安全点 |
| 采样/解析 | 证据、处理节点 | 蓝图或适应进度 | 样本丢失、节点摧毁 |
| 信号 | 消息、优先级、网络 | 接收者命令/知识 | 带宽、干扰、无覆盖 |

### FS-REQ-031 阵营策略注入

共享能力不得包含“如果是玩家/敌人就走另一套算法”的复制分支。阵营差异通过：

- 目标评分器；
- 命令权限；
- 资源所有权与交换关系；
- 教义阈值；
- 器官与基因装配；
- 反馈皮肤。

特殊首领可组合或编排这些能力，但仍遵守事务、空间和结算规则。

## 6. 玩家阵营的生存操作

### FS-REQ-040 编队续航

战略视角显示编队本地储备百分比、按当前命令预计续航、最近可用补给和撤退路径。默认不要求逐个单位喂食；编队会按教义自动从联网节点补充。

### FS-REQ-041 离网远征

远征前可预留携带资源。断网后仍能执行已知命令，但新远程命令、意识传递、改造和归档受限。储备不足时按教义请求撤退；玩家可明确覆盖并承担风险。

### FS-REQ-042 生存不是额外胜利条

玩家的最终目标仍是破壳发射。食源和供能用于制造路线、构筑与风险，不增加“每隔几秒点一次吃饭”的独立小游戏。

## 7. 敌方生态行为

### FS-REQ-050 可解释任务来源

每个敌方群体的任务来自巢、食源、样本、领地、Alpha 或即时威胁之一。调试界面能显示：任务来源、目标、优先级、预计完成条件和上一次切换原因。

### FS-REQ-051 三谱系权重

- 甲壳工蚁：护巢/运输权重高，正面拦截强，追击距离短；
- 浮囊鳐：巡猎/高能节点/信号中继权重高，响应快，储备较低；
- 菌毯拾荒者：尸体/样本/腐解床权重高，持续占区强，撤退慢。

适应只能调整权重或赋予能力，不能抹掉谱系职责。

### FS-REQ-052 无免费刷新

敌人出生必须对应巢容量、生物质和育化过程。导演可以安排资源和任务，不能直接绕过账本生成已适应单位。剧情必需的保底生成也要记录来源为“星舰储备”，在地图或结算中可追溯。

## 8. 边界情况

### FS-REQ-060 载体死亡

携带物落地或按明确破坏规则损失；预留事务解除；护送/供养目标收到失败原因；样本不会瞬间传送到巢。

### FS-REQ-061 节点摧毁或断网

停止新事务，已在途事务按位置继续或落地；本地储备不消失；重新连接后不得重复到账。

### FS-REQ-062 争夺与死锁

双方同时占用一个接口时进入 Contested，按单位占据与控制规则结算。资源不足导致双方都无法推进时，地图必须有替代食源、回收或低耗撤离路径。

### FS-REQ-063 暂停与倍速

暂停冻结需求增长、采集、运输、进食、孕育和 AI 决策，但允许查看预测和排队命令。倍速只缩放模拟时间，不改变每次事务产出。

### FS-REQ-064 存读档

保存资源事务 ID、状态、数量、载体、来源、目的地、剩余时间和随机选择。读档重复执行提交/退款视为致命回归。

## 9. UI 与反馈

### FS-REQ-070 战略层

必须可见：食源产率/库存、所有权、运输线、编队续航、巢/萌生队列、资源中断原因和 Alpha 供养关系。可以分层显示，但不能藏在调试日志。

### FS-REQ-071 个体层

选中或直控时显示：本地储备、当前消耗、器官耗能、载荷、补给来源、低储备降级阶段和撤退建议。

### FS-REQ-072 因果反馈

任何资源导致的行为变化都显示“原因 → 状态 → 后果 → 可恢复方法”，例如：

> 食源被切断 → Alpha 储备低于 40% → 快速再生关闭 → 可在下一次觅食迁徙时伏击。

## 10. 自动验收

### FS-TEST-001 资源守恒

固定总量经过采集、搬运、储存、消费、死亡掉落、取消和读档后，总和等于初值减明确损耗；重复提交为零。

### FS-TEST-002 敌我共用能力

同一食源分别由玩家搬运者和敌方搬运者使用，除权限/目的地/教义外走同一状态转换与失败原因。

### FS-TEST-003 离网续航

编队断网后本地储备按实际动作消耗；低储备逐级禁用高耗动作并请求撤退；重新补给恢复，无瞬死或无限行动。

### FS-TEST-004 可解释敌方目标

食源、巢、样本和玩家威胁分别出现时，三谱系按权重选择不同任务；移除刺激后能给出明确切换原因。

### FS-TEST-005 中断恢复

搬运者死亡、节点断开、目标满、暂停、读档各跑一次；没有复制、丢失所有权或软锁。

### FS-TEST-006 正式入口旅程

机器人从正常开局完成：发现食源 → 下达采集/搬运 → 接入网络 → 孕育单位 → 离网远征 → 低储备撤回。全程检查 UI 状态与资源账，不直接调用资源容器作弊。

## 11. 分阶段落地，不构成永久禁区

- M4 前/当前：先定义编队任务、职责和命令接口，禁止把不存在的搬运用“移动态”冒充验收。
- M5：实现共享资源容器、食源、玩家网络、敌方巢与真实搬运/供养。
- M6：在同一实体和事务上接样本搬运与适应。
- M7：Alpha 护群复用上述能力；不得再做一套 Boss 专用假食源。
- M8+：扩大单位、食源和地图规模，以压力测试和玩家可读性决定，不在本规格预设永久上限。
