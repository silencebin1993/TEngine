# 文明织造 First Playable 开发规格

> 修订日期：2026-08-04。本次修订落实四项设计决定并补齐可执行层：
> ① FP 目标时长 25-30 分钟；② 生物质=货币 / 进化点=门票；
> ③ 细胞阶段加入一次 3 选 1 微选择；④ 构筑槽位 2 个 / 模块 6 个。
> 新增章节：§5 公式、§7 调参表、§8 边界情况、§9 失败与重开、§12 依赖与技术对接。

## 1. 目标

First Playable 的目标不是展示完整八阶段，而是验证项目最核心的承诺：

`细胞阶段微选择 -> 器官/组织阶段结构差异 -> 生物阶段可感知的生存或战斗优势`

这是一条**三段**继承链，缺任何一段都不构成验证。

目标时长：25 到 30 分钟。

阶段时长分配：
- 细胞阶段：9 到 14 分钟（由玩家自己决定何时进化，见 §4.1）
- 器官/组织阶段：3 到 5 分钟
- 生物阶段：10 到 12 分钟

不覆盖：
- 远古竞争阶段
- 文明崛起阶段
- 大明势力登场
- 废土重建阶段
- 星海扩张阶段
- 宇宙终局阶段

## 2. First Playable 产品承诺

玩家从一个弱小细胞开始，通过吞噬、规避和两级递进选择（细胞微选择 -> 2 个器官模块），
让生命体形成明确路线，并在生物阶段看到这些早期选择带来的能力差异。

这一版本必须让玩家明白三件事：
- 早期选择不是临时加成，而会进入下一阶段。
- 三条路线的体验确实不同。
- 阶段切换不是换小游戏，而是同一生命链条的升级。

## 3. 核心循环

短循环：
`移动 -> 吞噬目标 -> 避开威胁 -> 同时获得生物质与进化点`

中循环：
`进化点达门槛 -> 自行决定何时进化 -> 用生物质购买 2 个模块 -> 生物阶段兑现`

First Playable 完整流程：
`细胞求生 -> 细胞微选择 -> 决定进化时机 -> 购买器官模块 -> 生物阶段验证 -> 结算本局路线`

### 3.1 资源职责（关键）

两种资源职责严格分离，不重叠：

| 资源 | 职责 | Source | Sink |
|---|---|---|---|
| `进化点` | **门票**。达 100 解锁进化按钮，不消耗 | 吞噬食物 | 无（纯阈值） |
| `生物质` | **货币**。器官阶段购买模块 | 吞噬食物 | 器官模块购买 |
| `生命值` | 生存资源 | 吞噬回复（部分路线） | 受击 |

`生物质` 的 sink 就是模块购买，因此不再是死资源。`进化点` 不作货币，因此不与
槽位数构成双重约束——槽位限数量（2 个），生物质限品质（买得起哪两个）。

生物阶段不再产出或消耗生物质与进化点，两者在结算界面只作为本局记录展示。

## 4. 三阶段范围

### 4.1 细胞阶段

目标：验证移动、吞噬、规避、资源获取，并做出第一次路线倾向选择。

玩家操作：
- 控制单个细胞移动（3D 平面，WASD，带惯性）。
- 吞噬体积小于自己的目标。
- 避开体积大于自己的威胁与危险区域。
- 在 4:30 时做一次 3 选 1 微选择。
- 进化点达 100 后，自行决定何时按「进化」按钮。

核心资源：`生命值`、`生物质`、`进化点`

**进化时机由玩家掌控（本阶段的核心决策）：**

进化点达 100 时 HUD 出现「进化」按钮，但不强制跳转。玩家可以选择：
- **立刻进化**：约 9 分钟，生物质约 260，只买得起便宜模块组合。
- **继续留场**：生物质持续累积，能买更好的模块组合，但威胁数量每 4:30 翻倍递增。

第 3 波（13:30）结束时若仍未进化，强制进入器官阶段（防止无限刷）。

这就是本阶段 9-14 分钟时长的填充方式：**一个风险/收益决策**，而不是拉长刷取。

胜利条件：进化点 ≥ 100 且玩家主动进化，或到达 13:30 且进化点 ≥ 100。

失败条件：生命值归零；或 13:30 时进化点 < 100。

必须实现：
- 玩家细胞移动（惯性漂移）。
- 两类可吞噬食物（A 型 / B 型）。
- 威胁单位（体积大于玩家）。
- 体积对比吞噬判定（见 §5.1）。
- 吞噬后玩家体积增长与移速衰减（见 §5.2）。
- 生命值、生物质、进化点变化。
- 4:30 的 3 选 1 微选择 UI。
- 波次刷新（每 4:30 一波，共 3 波）。
- 「进化」按钮与阶段结算。

#### 细胞阶段 3 选 1 微选择

在 4:30 触发，暂停玩法，3 选 1，选完记 1 点路线倾向到 `RunData`：

| 选项 | 效果 | 路线倾向 |
|---|---|---|
| `贪食囊` | 吞噬获得生物质 +25% | 吞噬扩张型 |
| `趋光纤毛` | 移速 +20% | 功能特化型 |
| `代谢泡` | 每次吞噬回复 3 生命值 | 科技统治型 |

`代谢泡` 之所以是"回血"而不是"加速拿进化点"：科技统治型的模块最贵（见 §7.3），
需要玩家留场更久攒生物质，因此它要提供的是**续航**能力，与该路线"偏后期"的
定位一致。加速拿进化点反而会缩短留场时间、买不起本路线模块，是反向的。

**微选择效果只作用于细胞阶段，不带入生物阶段。** 它对后续阶段的影响走另一条
更有意义的因果链：微选择决定细胞阶段的生物质累积效率与存活能力 → 决定玩家能
留场多久、攒到多少生物质 → 决定器官阶段买得起哪两个模块 → 决定生物阶段的能力。

这样设计有两个好处：生物阶段的属性只由 2 个模块决定，验收指标（§14）可以干净地
计算与复现；同时微选择的影响是经济性的而非单纯加数值，玩家更能体会到"早期选择
改变了后面的可能性"，而不只是"早期选择给了我一点属性"。

微选择另外恒定贡献 1 点路线倾向（§5.3），并在器官阶段用于高亮匹配模块。

### 4.2 器官/组织阶段

目标：验证构筑选择与路线分化。

本阶段是一个**选择菜单**，不是可玩关卡，预期 3 到 5 分钟。（GDD 10.1.2 已同步修正）

玩家操作：
- 在 6 个模块中购买最多 2 个（生物质不足则买不起）。
- 确认后进入生物阶段。

核心资源：`生物质`（货币）、`构筑槽位`（2 个）

构筑规则：
- 槽位上限 2 个。
- 每个模块归属一条原型路线，每路线 2 个模块。
- **2 槽位 + 每路线 2 模块 = 纯路线构筑可达**，这是本次修订的关键：满槽构筑不会
  被迫掺入第二条路线，路线差异才能被干净地验证。
- 模块结果在生物阶段转化为属性或能力。

首版 6 个构筑模块（数值见 §7.3）：

详细设计意图、后续候选卡池与机制联动说明，见 `First_Playable_Card_Pool.md`。本规格文档仅保留
First Playable 首轮开发所需的最小可执行版本。

| 模块 | 路线 | 效果概要 |
|---|---|---|
| `吞噬口器` | 吞噬扩张型 | 近战伤害↑，击杀回血 |
| `厚壁细胞层` | 吞噬扩张型 | 最大生命值↑，移速↓ |
| `感知纤毛` | 功能特化型 | 移速↑，敌人察觉范围↓ |
| `协同神经束` | 功能特化型 | 冲刺无敌帧↑，体力消耗↓ |
| `原始放电囊` | 科技统治型 | 解锁远程放电攻击 |
| `能量导流组织` | 科技统治型 | 体力上限↑，体力回复↑ |

胜利条件：完成购买并进入生物阶段（允许只买 1 个或 0 个）。

失败条件：本阶段不设硬失败。

必须实现：
- 构筑选择界面，展示 6 个模块及其生物质价格。
- 当前生物质余额与 2 个槽位显示。
- 买不起的模块置灰。
- 支持取消选择并退款。
- 与细胞微选择路线倾向匹配的模块高亮（引导，非强制）。
- 构筑结果写入 `RunData` 并传入生物阶段。

### 4.3 生物阶段

目标：验证前两级选择在实战中可感知。

玩家操作：
- 控制小型生物移动、冲刺。
- 应对 2 种普通敌人与环境威胁。
- 使用构筑带来的能力（近战 / 冲刺 / 放电）。
- 击败精英敌人「顶级掠食者」。

核心资源：`生命值`、`体力`

**`适应度` 已从首版移除。** 它此前只有名字没有规则，且不为 FP 的验证目标服务。
该概念保留到远古竞争阶段再引入。

体力规则（此前完全缺失，现补齐）：
- 上限 100，冲刺消耗 30，停止消耗后延迟 1 秒开始回复，回复 12/秒。
- 冲刺提供 0.3 秒无敌帧，是**所有路线**的通用生存手段（保证三路线都能风筝）。

流程（10 到 12 分钟）：
1. 0:00-4:00 生态区探索，击杀普通敌人，熟悉新形态操作。
2. 4:00-8:00 敌人持续刷新，压力递增。
3. 8:00 起 精英战。**进入精英战前生命值全满**（排除前段耗血的随机性，
   让精英战成为对构筑本身的干净测试）。

胜利条件：击败精英敌人「顶级掠食者」。

失败条件：生命值归零。

必须实现：
- 生物形态玩家单位 + 冲刺与体力系统。
- 2 种普通敌人（草食虫巡逻 / 掠食虫追踪）。
- 1 个精英敌人（顶级掠食者，带冲撞技能）。
- 构筑模块转化为实际属性与能力。
- 至少 1 个路线专属能力（放电）实装。
- 胜利 / 失败结算界面。

## 5. 公式

### 5.1 吞噬判定

设玩家体积 `Vp`，目标体积 `Vt`，阈值 `k = 1.15`：

```
Vp >= Vt * k   -> 玩家可吞噬目标
Vt >= Vp * k   -> 目标可吞噬玩家（玩家受伤）
其余（0.87 < Vp/Vt < 1.15） -> 双方均不可吞噬，仅碰撞弹开
```

中间地带的存在是有意的：避免体积接近时反复误判，也给玩家一个"打不过也吃不掉"
的可读状态。

### 5.2 体积增长与移速衰减

```
吞噬后：Vp = min(Vp + Vt * 0.30, V_max)      // V_max = 3.0
当前移速：Speed = BaseSpeed * (1 - (Vp - 1.0) * 0.18)
                 下限 Speed >= BaseSpeed * 0.55
```

变大 = 能吃更多但更慢。这构成细胞阶段的内在权衡，防止"一路吃大"成为无脑主导策略。

### 5.3 路线判定

```
细胞微选择      -> 对应路线 +1 点
每个器官模块    -> 对应路线 +1 点
总分上限        3 点（1 微选择 + 2 模块）

主导路线 = 得分最高者
平票时         -> 器官模块所属路线优先（权重更高）
三路各 1 点     -> 判定为「混合型」，结算界面如实显示
```

### 5.4 伤害与回复

```
近战伤害 = BaseMelee * (1 + 吞噬口器加成)
放电伤害 = 25（固定，不受近战加成影响）
击杀回血 = 吞噬口器持有时，击杀普通敌人回复 8 生命值
接触伤害 = 敌人 ContactDamage，同一敌人对玩家有 0.8 秒伤害间隔
```

## 6. 三条原型路线的最小差异

### 6.1 吞噬扩张型
体验关键词：更大、更硬、更能吃。
- 细胞阶段：`贪食囊` 让生物质累积快 25%（进化点不受影响，门槛仍是 100）。
  同一进化点下手头更富裕，因此本路线纯构筑在刚达门槛时就买得齐。
- 器官阶段：`吞噬口器` + `厚壁细胞层`，总价最低（见 §7.3），最早可达的纯路线。
- 生物阶段：最大生命值 190，近战伤害 24，击杀回血；移速最低 4.6。正面硬吃。

### 6.2 功能特化型
体验关键词：更灵活、更依赖组合、更吃操作。
- 细胞阶段：`趋光纤毛` 提升规避能力。
- 器官阶段：`感知纤毛` + `协同神经束`，中等总价。
- 生物阶段：移速 6.4，敌人察觉范围 -35%，冲刺无敌帧 0.45 秒、体力消耗仅 21。
  生命值停留在基础 140（无生命值模块），三条路线中容错最低，失误惩罚最重。
  精英战对本路线是纯操作检验：靠 0.45 秒无敌帧与廉价冲刺躲掉冲撞，才能赢。

### 6.3 科技统治型
体验关键词：更远、更准、更偏后期。
- 细胞阶段：`代谢泡` 提供续航，支撑留场攒生物质。
- 器官阶段：`原始放电囊` + `能量导流组织`，总价最高，需要打到第 3 波才买得起。
- 生物阶段：解锁 3.5 米放电攻击，体力上限 140。近身容错低，靠距离解决问题。

## 8. 边界情况

| 情况 | 处理 |
|---|---|
| 生物质不足，买不起任何模块 | 不可能发生：达 100 进化点时必有约 260 生物质，而最便宜模块 120。若因调参破坏此前提，则赠予最便宜模块保底。 |
| 玩家只买 1 个模块就确认 | 允许。结算如实显示 1 个模块，路线倾向按 §5.3 计算。 |
| 玩家买 0 个模块直接确认 | 允许，但需二次确认弹窗提示"将以基础形态进入生物阶段"。 |
| 玩家不做细胞微选择就挂机 | 微选择弹窗暂停玩法，不选不继续。无超时跳过。 |
| 玩家体积达上限后继续吞噬 | 体积不再增长，但仍正常获得生物质与进化点。 |
| 玩家体积小于所有食物 | 不可能：A 型食物体积 0.5 < 玩家初始 1.0。 |
| 三路各 1 点的混合构筑 | 判定为「混合型」，结算界面如实显示，不强行归类。 |
| 13:30 到达但进化点 < 100 | 本局失败（见 §9）。 |
| 精英战中体力耗尽 | 正常，等待回复。冲刺是通用手段但非无限。 |
| 同一敌人连续接触玩家 | 0.8 秒伤害间隔，防止贴身瞬间掉光血。 |

## 9. 失败与重开规则

| 阶段 | 失败条件 | 重开粒度 | RunData |
|---|---|---|---|
| 细胞阶段 | 生命值归零；或 13:30 进化点 < 100 | **重开整局**，回到细胞阶段 0:00 | 全部清空 |
| 器官阶段 | 无硬失败 | — | — |
| 生物阶段 | 生命值归零 | **可选**：重试生物阶段（保留构筑）／ 重开整局 | 重试保留，重开清空 |

生物阶段失败允许保留构筑重试，理由是：FP 的目的是验证构筑效果，若每次失败都要
重刷 9-14 分钟细胞阶段，调参与验证节奏会被拖死。这是 FP 专属的开发期便利，
不代表正式版的 roguelite 规则。

## 12. 依赖与技术对接

对接点（须遵守项目 CLAUDE.md 编码红线）：

| 项 | 约定 |
|---|---|
| 入口 | `GameApp.StartGameLogic()`，替换当前的 `ShowUIAsync<BattleMainUI>()` |
| 跨阶段数据 | `FirstPlayableRunData` 由 `FirstPlayableGameMode` 持有的静态单例，阶段切换不重建 |
| UI | 一律走 `GameModule.UI.ShowUIAsync<T>()`，不直接 Instantiate |
| 资源 | `LoadGameObjectAsync` 加载，必须与 `UnloadAsset` 配对释放 |

| 代码位置 | `Assets/GameScripts/HotFix/GameLogic/FirstPlayable/`（全热更） |
| 场景 | 首版全部在 `main.unity` 内，白模用引擎原始几何体，流程稳定后再拆场景 |

FP 不依赖 Luban 导表、不依赖 HybridCLR 出包、不依赖 YooAsset 正式分包
（Editor 模拟模式即可），因此可以立即开工。

## 13. 明确不做

First Playable 不做以下内容：
- 文明 RTS 完整系统、大明王朝势力、废土阶段、星海阶段、宇宙终局。
- 完整科技树、完整存档系统（25-30 分钟单局无需中途存档）、多结局。
- 支线事件、复杂外交、开放世界地图、大量敌种、正式美术资源。
- `适应度` 资源（推迟到远古竞争阶段）。

## 14. 验收标准

流程类：
- 玩家可从细胞阶段依次进入器官/组织阶段、生物阶段，无需手动切场景。
- 细胞阶段具备吞噬、受伤、资源获取、失败四项行为。
- 细胞阶段在 4:30 触发 3 选 1 微选择，选择结果写入 `RunData`。
- 进化点达 100 后出现「进化」按钮，且不强制跳转。
- 器官阶段提供 6 个可购买模块，槽位上限 2，买不起的置灰。
- 失败后可按 §9 规则重开。

可测的路线差异（替换原先不可测的"明显体现差异"）：
- 吞噬扩张型纯构筑的最大生命值 ≥ 185，且 ≥ 另两条路线的 1.35 倍。
  （基线：190 / 140 = 1.36）
- 功能特化型纯构筑的移速 ≥ 6.3，且 ≥ 吞噬扩张型的 1.35 倍。
  （基线：6.4 / 4.6 = 1.39）
- 科技统治型纯构筑能在 3 米外造成伤害；另两条路线在 3 米外伤害为 0。
- 三条纯路线**均可击败**精英敌人；任一条无法击败，则调整精英生命值后重测。
- 最快路线与最慢路线击败精英的耗时差异 ≥ 30%（证明路线不是换皮）。
  （基线预期：吞噬型约 7 秒接触时间最快，科技型约 16 秒最慢）

时长：
- 完整一局落在 25 到 30 分钟区间（不是"以内"——过短同样不达标）。
- 最快路线（吞噬扩张型立刻进化）不短于 22 分钟。

## 15. 最高风险

设计风险：三阶段仍然像三个小游戏，而不是一条生命成长链。
- 缓解：细胞微选择 + 器官模块构成显式的两级继承链，结算界面明确展示路线来源。

制作风险：过早把生物阶段做成完整动作游戏，导致范围膨胀。
- 缓解：生物阶段只有近战 / 冲刺 / 放电三个动作，敌人只有 3 种。

内容风险：构筑模块数量增加太快，导致路线差异无法验证。
- 缓解：锁定 6 模块 / 2 槽位，新增模块一律推迟到 Vertical Slice。

平衡风险：精英敌人强度让某条路线打不过。
- 缓解：精英生命值 250 是首版主要杠杆，§14 已把"三路线均可击败"列为验收硬条件。
