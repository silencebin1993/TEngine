# 《文明织造》美术选型文案（细胞阶段优先）

> 版本：v0.1（选型草案，待你勾选定稿）  
> 日期：2026-08-05  
> 依据：`Cell_Stage_Spec.md`、`GDD_Starter_Pack.md` §13、`Game_Framework_Design.md`（Built-in RP + GPU 实例化万敌）  
> 目的：在玩法与现有肉鸽差异不大时，锁定**能一眼辨认、后期可扩到星海、且一人/小团队做得出**的表现方案

---

## 0. 一句话结论（推荐）

**细胞阶段采用「显微镜下的风格化 3D / 2.5D」：半透明湿润、低面数有机体、功能可读的固定槽位拼装；不做孢子式自由拖拽造物，也不做像素主视觉。**

差异感不靠「又一个霓虹竞技场肉鸽」，而靠三条视觉承诺：

1. **尺度母题可继承**：细胞膜 → 皮肤/甲壳 → 城墙 → 舰壳 → 星云膜，同一套造形语法跨阶段。  
2. **构筑一眼可见**：六条路线有独立剪影与材质语义，截图即可猜 build。  
3. **规模即演出**：万敌时靠体积分层、发光层级、生态染色表达「从猎物到霸主」，而非单体高精动画。

下方各节给出选项与推荐；文末有勾选表，你定稿后此文档升为 v1.0 美术基线。

## 1. 选型必须服从的硬约束

| 约束 | 对美术的含义 |
|------|----------------|
| 单局约 60 分钟、敌人峰值数千～上万 | 大量单位必须走 **GPU 实例化**；单体不能依赖复杂骨骼/布料/独立材质球爆炸 |
| Built-in RP，无 Entities Graphics | 渲染方案要简单：实例化网格 / 广告牌 / 简单自定义 shader，忌 URP 专属炫技管线 |
| 玩法核心是吞噬 + 局内突变构筑 | 视觉必须服务「体积可读、吞噬反馈、选卡后外形真变」 |
| 六条路线混搭 | 外形要能叠加，不能每种路线一套不可组合的全身模型 |
| 全项目还有器官→生物→文明→废土→星海 | **细胞阶段定的造形语言要能「换皮扩尺度」**，不能定死「只适合微生物像素」 |
| 独立开发产能 | 每条路线全套独立动画/特效 = 死；优先模块复用与参数换色 |

Spec 已点名的可读性风险（§16）：万敌时玩家必须始终最高对比度；敌人要按体积/颜色/轮廓分层。

## 2. 在「玩法不新」时，眼前一亮靠什么

肉鸽市场里，**机制组合本身很难单靠文案出圈**。细胞阶段能打出的差异，建议压在这四层（按性价比排序）：

| 层级 | 做什么 | 不做 |
|------|--------|------|
| A. 第一眼气质 | 湿润微观、半透明、生物发光、流体环境；避免 VS/Brotato 霓虹竞技场默认脸 | 灰暗写实医学片、纯黑底霓虹弹幕 |
| B. 构筑可视化 | 选卡 → 身体立刻长出可读部件；结算页「路线剪影」可分享 | 只改数字、外形几乎不变 |
| C. 时期换脸 | 6 个生态时期换背景染色、粒子、敌人轮廓语言（同场景换生态） | 每时期重做一整张地图美术 |
| D. 终局尺度感 | 霸主战玩家体量与光晕碾压全场 | 依赖长过场 CG |

**结论**：差异来自「显微镜进化剧」气质 + 构筑外形反馈，不是来自更复杂的操作或更写实的模型。

## 3. 画风总选型（2D / 3D / 像素 / Poly / 写实）

### 选项对照

| 方案 | 气质 | 万敌友好 | 跨阶段扩展 | 产能 | 眼前一亮潜力 |
|------|------|----------|------------|------|----------------|
| **A. 像素 2D** | 独立感强、易联想到同类肉鸽 | ★★★★ | ★★ 星海/文明难共用语言 | ★★★★ | ★★ 同质化重 |
| **B. 手绘 2D 精灵** | 精致、亲和 | ★★★ | ★★★ | ★★ 张数爆炸 | ★★★ |
| **C. 低面风格化 3D（推荐）** | 有机、半透明、可打光 | ★★★★ | ★★★★★ | ★★★ | ★★★★ |
| **D. 高模写实 / 半写实** | 「科学感」 | ★★ | ★★★ | ★ | ★★ 脏、贵、难读 |
| **E. 纯 Flat 矢量 / 剪纸** | 极简、辨识高 | ★★★★★ | ★★★ | ★★★★ | ★★★ 易显玩具感 |
| **F. 混合：3D 单位 + 2D UI/背景层** | 灵活 | ★★★★ | ★★★★ | ★★★ | ★★★★ |

### 推荐：**C 为主，F 为辅**

- **单位与玩家**：低面有机 3D（或「假 3D」预烘剖面 mesh），半透明 shader + 边缘光 + 内核高亮。  
- **环境**：简单体积网格 + 程序化流体/颗粒背景（不必做开放世界地形）。  
- **UI / 卡面**：2D 插画或 flat 图标，与 3D 战场分离，避免卡面也跟万敌同精度。  
- **明确不做**：主视觉像素；写实显微镜摄影风；每敌人独立高模。

**参考气质（不是玩法抄袭）**：  
《孢子》细胞关的「半透明可爱」×《Holyday City / 部分 Noita 式》的可读剪影 × 科学插画里的「染色切片」——而不是 Vampire Survivors 的弹幕霓虹。

## 4. 造物方式：孢子拖拽 vs 土豆兄弟槽位

这是细胞阶段最关键的表现选型。

### 方案对比

| | **方案 S：孢子式自由拖拽部件** | **方案 P：固定槽位变体（土豆兄弟式）** | **方案 M：槽位模块 + 强剪影演化（推荐）** |
|--|-------------------------------|----------------------------------------|-------------------------------------------|
| 玩家感受 | 「我亲手捏了一个生物」 | 「我选了 build，外形跟着变」 | 「我在进化出独特物种，但操作仍是选卡」 |
| 与当前玩法 | 玩法是 3 选 1 卡，拖拽是第二套 UX，易割裂 | 完美贴合选卡 | 选卡即装配；无第二套造物 UI |
| 万敌 / 实例化 | 自由组合 → 网格组合爆炸，批处理困难 | 槽位少、变体可控，批友好 | 槽位有限（3–5）+ 部件表驱动，仍可按 Archetype 分批 |
| 产能 | 极高（编辑器、碰撞、平衡、UI） | 低 | 中低 |
| 跨阶段 | 器官/生物阶段可再开造物；细胞阶段过早做全套会烧光预算 | 后期难做出「物种独特感」 | 细胞定槽位语义，器官阶段可升级为更自由拼装 |
| 眼前一亮 | 高（若做透） | 中（易淹没在同类） | 中高：靠「一局结束外形完全不像开局」的分享图 |

### 推荐：**方案 M（默认）**；方案 S 降级为「远期器官/生物阶段再议」

**方案 M 的具体规则建议：**

1. **槽位固定、部件表驱动**（不是自由拖到任意位置）  
   - 建议槽：`核/体`（必选基底）· `膜/外壳` · `口器/捕食` · `运动器` · `附属/孢子位` · `领域/菌毯锚`（后两者可随路线解锁显示）  
2. **选卡 = 改槽位部件或叠材质参数**，不弹造物台。  
3. **混搭规则**：同槽高稀有度覆盖；跨路线用「着色层 + 小饰件」叠加，避免 6 路线 × N 部件排列爆炸。  
4. **终局剪影**：结算生成一张「物种剪影 + 路线色带」，用于分享与图鉴——这是低成本「孢子感」替代品。  
5. **明确不做（细胞阶段）**：自由旋转/缩放部件、部件物理关节、造物沙盒关。

若你强烈想要「孢子感」，建议只开 **轻量版 S'**：进化节点里偶尔出现「二选一外形突变」（仍非拖拽），而非常驻编辑器。

## 5. 六条路线的视觉语义（不论选哪种造物，都应锁定）

目标：截图 1 秒能猜主导路线；混搭时仍能读出「主色 + 副饰」。

| 路线 | 剪影关键词 | 材质/光 | 战场痕迹 |
|------|------------|---------|----------|
| 吞噬扩张 Devour | 大、圆、张口、不规则外缘 | 厚膜、暗沉、吃光时的拉伸变形 | 尸体残渣、吞咽涟漪 |
| 机动猎食 Agile | 梭形、尖、细长鞭毛 | 高对比边缘、残影拖尾 | 穿体残线、标记印记 |
| 电化统治 Electric | 刺突、丝状触须 | 青白高光、脉冲描边 | 导电网络线、连锁弧 |
| 孢子繁殖 Spore | 多泡、分体、小点环绕 | 雾状半透明、孢子尘 | 附属体云、感染斑 |
| 菌毯筑巢 Nest | 扁平、锚点、地毯状延伸 | 糙面、菌丝纹理 | 地面染色领地 |
| 异化污染 Corrupt | 不对称、破口、棘 | 病态色偏、噪点闪烁 | 污染雾、灾变闪白 |

**混搭规则建议**：主路线决定「体型骨架 + 主色」；副路线只加「1 个槽位部件 + 1 种粒子」。

### 6.1 摄像机与空间

| 选项 | 说明 | 推荐 |

勾选： [ ] 轻微透视顶视  [ ] 纯顶视  [ ] 其他______

### 6.2 玩家可识别性（万敌刚需）

| 选项 | 推荐 |
|------|------|
| **玩家恒定：高亮描边 + 内核脉冲 + 体积阴影圈** | ★ |
| 仅靠颜色区分 | 不够 |
| 屏幕中心准星强制锁定 | 可作辅助，不作唯一手段 |

勾选： [ ] 描边+内核+阴影圈  [ ] 其他______

### 6.3 吞噬反馈（核心动词必须好看）

| 层级 | 建议 |
|------|------|
| 小目标 | 吸附拉伸 → 吸入 → 体积微胀 + 营养数字 |
| 同级 | 撕咬翻滚短演出（≤0.4s） |
| 精英 | 专属吞噬 pose + 镜头微震 + 进化能爆发 |

不做：每次吞噬都播长动画。

勾选： [ ] 接受分级反馈  [ ] 要更夸张（接受节奏变慢）

### 6.4 进化选卡时的外形变化时机

| 选项 | 推荐 |
|------|------|
| **选中确认瞬间播放「突变」0.6–1.0s，战场暂停** | ★ |
| 仅 UI 闪一下，回战场才变 | 反馈弱 |
| 自由浏览时实时预览外形 | 好，但要做预览管线 |

勾选： [ ] 确认时突变演出  [ ] 还要卡面悬停预览  [ ] 最小化

### 6.5 环境与时期换装

| 选项 | 推荐 |
|------|------|
| **同一培养皿场景，6 时期换：水色、粒子、敌人调色板、远处剪影密度** | ★ |
| 每时期独立场景美术 | 产能炸弹 |

勾选： [ ] 单场景换生态参数  [ ] 多场景

### 6.6 UI 视觉

沿用 GDD：「模块化进化 UI」。细胞阶段具体建议：

- 信息密度中等，**卡面 3 秒可读**（Spec §12.2）  
- 材质语言：半透明面板 + 有机边框（像细胞膜切片），不要科幻蓝玻璃 HUD 默认套  
- 进化界面：卡左侧小 3D/剪影预览「装上后长什么样」

勾选： [ ] 有机切片 UI  [ ] 更硬核科幻面板  [ ] 极简扁平

### 6.7 VFX 预算哲学

| 原则 | 含义 |
|------|------|
| 特效服务机制可读 | 电弧、菌毯、污染雾必须「读得懂」，不是好看烟雾 |
| 同屏特效分级 | 玩家/精英全特效；小怪共享简易粒子或顶点色闪 |
| 禁止全屏过曝 | 灾变期用色偏与边缘暗角，少用白闪连打 |

勾选： [ ] 接受分级 VFX  [ ] 小怪也要华丽（接受性能与制作加压）

### 6.8 动画复杂度

与 GDD §13.7 一致：**前中期可读，后期规模感**。

- 玩家：少量骨骼或顶点动画（呼吸、鞭毛、口器开合）  
- 小怪：顶点抖动 / 广告牌帧动画即可  
- 首领：可上独立动画状态机（唯一例外）

勾选： [ ] 接受  [ ] 全体要骨骼（不推荐）

### 6.9 「孢子感」替代清单（低成本高回报）

若放弃自由拖拽，仍建议做这些，避免「又一个圆形吃豆」：

1. 开局极简圆泡 → 60 分钟后严重异形（强制美术里程碑）  
2. 图鉴「我的物种」剪影墙  
3. 时期切换一句环境旁白 + 水色突变（Spec 文案已有）  
4. 附属体/菌毯让战场「被你染色」  
5. 结算短镜头：从你的细胞缓缓拉远，暗示未来尺度跃迁（预埋星海母题）

## 7. 与后续阶段的衔接约定（现在定，避免返工）

细胞阶段美术一旦定稿，建议锁死这些「跨阶段不变量」：

| 不变量 | 细胞表现 | 未来可映射 |
|--------|----------|------------|
| 半透明膜 + 内核 | 细胞膜 / 核 | 护盾 / 反应堆 / 星舰核心 |
| 功能部件外挂 | 口器、鞭毛、孢子囊 | 武器、引擎、无人机舱 |
| 路线主色 | 六色体系 | 文明涂装 / 舰级标识 |
| 领地染色 | 菌毯 | 领土、势力范围、星区控制 |

**反例**：细胞阶段若锁定「16-bit 像素顶视」，到文明/星海几乎必然整套重做——与 GDD「制作风险：跨度大于产能」直接冲突。

勾选： [ ] 接受跨阶段造形语法  [ ] 细胞阶段允许与后期脱钩（接受返工）

## 8. 产能与管线建议（落地用）

### 8.1 最小可卖相资产包（细胞阶段 P0）

1. 玩家基底 1 套 + 每路线核心部件 2–3 个（共约 15–20 个模块）  
2. 敌人：按「体积档 × 行为原型」做，而不是按每个 EnemyId 做模（30 敌人共享约 8–12 个外形原型 + 换色/饰件）  
3. 首领 1 个三阶段换装  
4. 环境：1 培养皿场景 + 6 套时期参数  
5. UI：HUD + 选卡 + 结算物种剪影  
6. VFX：吞噬 / 升级突变 / 六路线各 1 个签名特效  

### 8.2 技术对齐

- 部件与敌人外观最终应能映射到 `ArchetypeId` 分批实例化（见框架 `SimRenderer`）  
- 材质尽量：**共用 shader + 材质属性块（MPB）/ 实例 buffer**，禁止每单位独立材质实例  
- 资源落点遵守 `Art_Repo_And_HotUpdate.md`：源文件 `GameRes/Art/`，运行时 `GameRes/Raw/`  

### 8.3 验证标准（选型验收，不是画完才验收）

做白模阶段就要过这三关：

1. **10 米外剪影测试**：六路线玩家外形能否区分  
2. **1000 单位同屏**：玩家是否仍一眼可找  
3. **选卡前后截图对比**：陌生人能否看出「变强了/变怪了」

## 9. 风险与明确不做（细胞阶段）

| 不做 | 原因 |
|------|------|
| 孢子式自由拖拽造物台 | UX 与选卡肉鸽叠床架屋；组合爆炸；实例化不友好 |
| 写实解剖/医学可视化 | 脏、难读、与「一小时爽游」气质冲突 |
| 像素作为主视觉 | 跨阶段扩展差；肉鸽同质化 |
| 每张卡独立全身模型 | 135 卡 × 产能不可承受 |
| 全单位高精度骨骼 | 与万敌预算冲突 |
| 每生态时期全新场景 | 制作风险已在 GDD 标红 |
