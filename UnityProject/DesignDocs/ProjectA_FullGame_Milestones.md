## 0. 与 Demo 的关系

- 本文件是**版本迭代**：Demo 封版之后的下一个大版本。它**不影响**当前 Demo 的任何进度：Demo 的 GDD、ERD、`STORY-BOARD.md`、`DIGEST.md` 队列都不动。
- 里程碑只决定**顺序**；每个功能**完整应该做成什么样**，以卡片点名的 `fullgame/FGxx` 详细设计为准。

## 4. 各里程碑

### FG-M0 技术基线

**目标**：先把四个架构难点验证清楚，给后面所有里程碑铺路。

**必须完成**
- 家园与远征同时运行，焦点切换，后台结果一致（FGR-ARC-002）。
- 统一游戏时钟的底座：此后所有计时系统都由它驱动（FGR-ARC-009）。昼夜、3x 档和日历留到 FG-M7。
- 传送带内核原型达到规模（FGR-ARC-004）。
- 战斗逐单位逻辑接入内核，达到规模（FGR-ARC-003）。
- 格网建造原型；Demo 的锚点建筑迁移为开局预置（FGR-ARC-001）。
- 数据驱动和文本键管线跑通（FGR-ARC-005、006）。
- UI 基础件 12 类（FGR-ARC-007）；输入按上下文划分（FGR-ARC-012）。
- 存档 v2 骨架；Demo 存档给出明确提示（FGR-ARC-008）。
- 旅程机器人框架扩展到 FG；搭好性能场景（FGR-ARC-011）。
- 把正式版设计合并进 GDD v4，Demo GDD 作为 v3.1 历史保留。

**出口旅程 FGJ-M0**：从主菜单开新档 → 在格网上放置、旋转、拆除几座建筑 → 出发远征，同时让家园继续运行 → 远征中切回家园看一眼 → 回到远征区 → 返回家园；两边的状态与不观察时的对照完全一致。

**Story**：FG0-DOC-01、FG0-ARCH-01、FG0-ARCH-02、FG0-ARCH-03、FG0-ARCH-04、FG0-DATA-01、FG0-UX-01、FG0-SAVE-01、FG0-QA-01。

**风险**：战斗内核接入的代价可能很高。如果技术验证证明做不到，必须把正式版的规模目标一起下调，并请用户拍板（FGR-ARC-003）。

### FG-M1 信号接入

**目标**：兑现一号卖点。

**必须完成**
- 信号核槽位与装卸；核心固件只能在信号核里（FGR-SIG-010～012）。
- 接入口与双态编译预览（FGR-SIG-020～023）。
- 接入、重编译、离开；冷却跟着信号、热量留在机体（FGR-SIG-030～034）。
- 断链与安全模式（FGR-SIG-040、041）。
- 跨区域跳转（FGR-SIG-050～052）。
- 裸跑与暴露改写（FGR-SIG-060～071）。
- 机身形变首批：Demo 已有的作战组件（FGR-FW-020～022）。
- 接入 HUD、机器经历、首次引导（FGR-SIG-080～082）。

**出口旅程 FGJ-M1**：在家园编辑电路标出接入口，看双态预览 → 给信号核装上"过载" → 远征铸造前哨外围 → 接入重炮机，看到形变，打出熔穿过载 → 切到另一台机器，确认冷却没有重置 → 被干扰机断链，进入安全模式 → 跳回家园 → 再跳回远征区 → 撤离。

**Story**：FG1-SIG-01～07、FG1-VFX-01、FG1-HUD-01、FG1-E2E-01。

**试玩**：要。通过标准见 FGR-BAL-061。

**必须完成**

**出口旅程 FGJ-M3**：搭建"矿脉 → 精炼炉 → 零件工坊 → 仓库"的产线 → 人为制造一次堵塞，用诊断找到根源并修好 → 把整条产线存进布局库，在另一处放一份 → 撤销 → 升级传送带 → 存读档 → 远征一次，回来确认产量与后台一致。

**Story**：FG3-LOG-01～09、FG3-E2E-01。

**出口旅程 FGJ-M10**：完成防腐涂层主线 → 进入沉淀湖 → 利用化工自己的油迹打出爆燃 → 击败沉淀反应塔 → 回家应对一次化工突袭，重新净化被污染的区域。

**Story**：FG10-FAC-01、FG10-REG-01、FG10-BOSS-01、FG10-REACT-01、FG10-RAID-01、FG10-E2E-01。
