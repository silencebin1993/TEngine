## 0. 正名（人确认口径）

| 容易误读 | 正确理解 |
|----------|----------|
| 「化学引擎」= 火水汽酸碱 | **已废弃作权威名**；对外与派工只用 **组合引擎 / ComposeEngine** |
| 核心爽感 = 查「谁和谁反应」表 | **默认任意变化词都能一起生效并混合出结果**；表只写例外与少数具名涌现 |
| 产物 = 新元素 tag | 一份完整 **出口意图**（伤害/治疗/形态/运动/空间/残留…） |

**一句话**：**组合引擎（ComposeEngine）** = 组合变化引擎。  
「ChemEngine / 化学引擎」仅为历史别名，001 改名已完成，实现与文档不得再当主称呼。

库能力已覆盖：变大 / 散射 / 旋转绕圈 / 爆炸 / 位移执行器 / 双倍 / tag。  
偏航主因曾是：**叙事只谈代谢化学** + **战场桥只吃 `HitEvent.Damage`** + **误用白名单配方当「反应」定义**。

## 1. 组合模型（永久 · 人锁定）

### 1.1 默认：全能组合（一切都能「反应」）

| 类型 | 默认行为 | 「反应」含义 |
|------|----------|--------------|
| 形态 / 数量 / 运动 / 空间 / 时序 / 出口 | **全部正交写入同一 Packet/HitEvent** | 一起改变同一发意图（以撒式叠乘） |
| Substance / Status 标签 | **全部进入混合向量，必算出正规形结果** | 任意多 tag 混合都有确定语义（魔法工艺式搓合） |
| Contract / Meta | **全部累进 RuleVector → 软帽** | 全局规则一起改结算 |

**没有注册行 ≠ 不反应。** 没注册时仍然组合；只是走默认代数，而不是「NoOp 各算各的当没发生」。

### 1.2 例外：不能组合（黑名单 / 冲突代数 · 少数）

只有显式登记的才阻止或改写默认：

- **互斥**：两契约抢同一模式 → 冲突代数收成 NF（已有 Reflect 等）  
- **湮灭/抵消**：如 Slow↔Haste、Grounded 取消 Charged、Fire↔Ice 配置择一  
- **Reject-to-Safe**：非法装配不崩，收成安全空结果  

**主路径 = 白名单「能反应」已作废；例外表 = 黑名单「不能/特殊」。**

### 1.3 Substance：属性代数（任意混合必有结果）

每个 Substance tag 贡献一组有界标量（可扩维，不许改旧维语义）：

| 维 | 例 |
|----|-----|
| Heat / Cold | Fire+, Ice+, Plasma++ |
| Wet | Water+, Wet+, Oil 可改燃点 |
| Charge | Shock+, EMP+, Grounded 压 Charge |
| Corrosion | Acid+, Ichor+, Nanite+ |
| Phase | Light+, Dark+, Void 吞其他维 |
| Bio | Poison+, Blood+, Life± |
| Mass / Force | Earth+, Gravity+, Knock 读此 |
| Tempo | Slow−, Haste+, Delay |
| Entropy | Curse+, Radiation+, Void+ |

**混合算法（引擎职责，做法 C）**：累加各维 → 软帽/夹紧 → 由维阈值推出出口附着与派生 tag（例：Heat↑ 且 Wet↑ → 派生 Steam 语义并消减对立维）。  
具名反应（火+湿→汽）= **可选覆盖/强调**，不是「没写就不反应」。

### 1.4 验收（仍禁止笛卡尔 KPI）

- 性质：任意合法随机 tag 袋 + 修饰 → 有界、可复现、不 NaN  
- 抽样：多轴同装；黑名单例外各 1  
- **不**把「配方表行数」或「全 pair 覆盖率」当 Done 条件

## 4. 属性维与例外表（默认全能 · 例外少数）

> **G1～G10 = 混合向量的维/阶段皮标签**，不是「只有组内才能反应」。  
> 任意 tag 只要贡献了维，和其他任意 tag **自动一起混合**。  
> 「具名涌现」= 可选覆盖示例，**不是**准入白名单。

### 4.1 维索引（与 §1.3 对齐）

| 代号 | 维 | 阶段侧重 |
|------|----|----------|
| G1 | Heat/Cold | * |
| G2 | Charge | * / M EMP |
| G3 | Phase | * / U Void |
| G4 | Corrosion | * / M Nanite |

### 4.2 默认派生规则（引擎代数 · 示意，可调参）

| 条件（混合后） | 默认结果意图 |
|----------------|--------------|
| Heat↑ ∧ Wet↑ | Steam 语义；削对立维；可改 Shape/场 |
| Heat↑ ∧ Oil↑ | Burn 强化 + 易留 BurningGround |
| Cold↑ ∧ Wet↑ | Frozen / 霜残留 |

| Bio毒↑ ∧ Blood↑ | 剧毒蔓延倾向 |
| Phase Light↑ ∧ Dark↑ | 湮灭爆发或转 Entropy（配置） |
| Void↑ | 吞并其他 Substance 维转入 Entropy/伤 |
| Slow 与 Haste 同时 | **例外**：互相抵消 |
| 任意修饰轴同装 | 始终正交生效（Count/Scale/Orbit…） |

### 4.3 例外 / 黑名单（显式「不能或特殊」· 保持短）

| 例外 | 行为 |
|------|------|
| Slow ↔ Haste | 抵消 |
| Grounded → 压 Charge | 取消过载 |
| 互斥 ReflectMode 等 | 冲突代数 NF |
| 配置项 Fire↔Ice | 湮灭为 Steam 或 Brittle（Config 二选一） |
| 缺 Actuator | Reject-to-Safe，无事件 |

### 4.4 具名涌现（可选覆盖，非主路径）

火+湿→汽、油+火→燃地、酸+油→粘酸等 **短列表**，仅当要盖过默认代数手感时使用。  
新增内容默认义务：**给 tag 填维权重**，而不是再加一对一配方。
