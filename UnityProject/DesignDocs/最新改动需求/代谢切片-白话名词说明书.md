# 《代谢切片》白话说明书 — 每个词是什么意思

> 给：**人**先看懂。  
> 程序/美术总案里的黑话，这里全部换成「你在游戏里看见什么、点什么」。  
> 看完再去看《冻结总案》会对得上号。

---

## 先用生活比喻理解整款游戏

把你的细胞想成一座 **小工厂**：

| 游戏里 | 就像 |
|--------|------|
| **培养切片** | 工厂车间平面图（一格一格的地） |
| **槽位** | 车间里的一个工位（地板种类不同） |
| **器官** | 放在工位上的机器（也能挂在传送带管子上） |
| **代谢管（箭头）** | 你画的传送带方向：东西只能按箭头走 |
| **代谢包 Packet** | 传送带上正在运的一箱货 |
| **喷射器/纤毛** | 工厂大门：货从这里变成打出去的攻击 |
| **基因** | 全厂规章制度（所有大门出去的货都要遵守） |
| **储备囊** | 仓库（位子有限，满了必须扔） |
| **战场地形** | 外面马路的路况（湿地、油地…） |
| **残留** | 打完留在地上的痕迹（还会继续起反应） |
| **消化泡** | 厨房：打死怪拿到的生肉，要煮一会才变成可用零件 |

你每局在干的事：**往工厂里装机器 → 画传送带 → 出门打仗 → 战利品塞仓库 → 满了就扔或合成。**

## 第一章：你天天会摸到的界面名词

### 培养切片 / 细胞蓝图
- **是什么：** 战斗用的「身体改装面板」，一张方格纸。  
- **不是什么：** 不是背包，不是法杖技能栏。  
- **你干什么：** 把器官放格里，画箭头。

### 槽位（格子）
- **是什么：** 切片上的一格空地，可以放东西，也可以空着。  
- **空放：** 格子里可以不放机器；传送带仍可从空格经过。  
- **槽位地形 / SlotType：** 这格地板自带属性。  
  - 例：酸沼地板 = 货箱经过时会被「沾酸、变热」。  
  - 地板效果 **永远在**，跟你有没有放机器无关。

### 四邻 / 方格
- **是什么：** 只用上下左右相邻，不用斜角，也不做 3D。  
- **为什么：** 好懂、好画箭头。

### 有向代谢管 / 箭头 / 有向边
- **是什么：** 你从 A 格画到 B 格的箭头：「能量只许 A→B」。  
- **无向是什么（弱）：** 个别地板会「熏」旁边一格（比如酸味），那不是主传送带。  
- **记住：** 真正打输出的能量，只认你画的箭头。

### 细胞器 / 器官
- **是什么：** 放进格子里、或挂在代谢箭头上的零件卡，战斗时改「传送带上的货」或「这一条管子」。  
- **例子：**  
  - 线粒体 = 发电（装格子）  
  - 散射 = 一箱变多发（装格子）  
  - 刺突 = 只能装膜缘地板的外壳器官  
  - 绝缘管 = 挂在箭头上的管器官，让热少传一点  
- **对外不要再说「膜器」「管壁」品类**——都叫器官，差别只是能装哪。

### 基因
- **是什么：** 全身体质卡，最多装几条（方案里是 3 条）。  
- **例子：**「双倍」= 所有可放大的效果×2；「燃律」= 打出去容易带火。  
- **和器官差别：** 器官管「这条路/这根管上的货」；基因管「所有出门的货的总规则」。

### 储备囊（背包）
- **是什么：** 战利品仓库，格子数有限（先 8 个）。  
- **满了怎么办：** 必须选：扔掉旧的 / 扔掉新的 / 先合成腾位置。  
- **重要：** 放在仓库里的零件 **不会** 帮你打仗，装进切片才算。

### 装卸
- **装上：** 仓库 → 切片格子。  
- **卸下：** 切片 → 仓库（仓库满了就卸不下来）。

### 合成 / 升级
- **是什么：** 在营地菜单里，用仓库里的和/或身上卸下来的材料，拼成更强的或拆成材料。  
- **不是：** 不是战斗里临时搓法术。

### 消化泡 / 试剂
- **是什么：** 打死怪先拿到「生的碎片」，要在消化泡里煮一段时间。  
- **煮好了：** 变成真正能装的器官，进仓库。  
- **煮砸了：** 浪费、中毒、或弄脏脚下地面。

## 第二章：程序爱说的词 = 其实就这些

### 基元
- **人话：** 一种「会参与规则的零件类型」。  
- 地板、器官、基因、地上的水渍、反应公式……都算基元的一种。  
- **不是：** 不是说每一个都是卡牌。

### 做法 C
- **人话：** 每个零件只干自己那件事（发电就发电，加倍就加倍），**不要**写「如果旁边是聚焦就发动必杀」。  
- 组合效果是「货被改了很多次」自然出现的。

### 方案 A（禁止）
- **人话：** 每个零件都去点名别的零件写特殊互动 → 以后加东西会爆炸，所以禁止。

### Packet（代谢包）— 叫它「货箱」
传送带上的一箱货，上面写着数字和贴纸，例如：

| 字段（黑话） | 人话 |
|--------------|------|
| Energy | 这箱有多少能量 |
| Heat | 有多烫（太烫会出事） |
| Shape | 打出去长什么样（子弹/激光…） |
| Scale | 体积多大（打出去罩多大/多胖，进机制） |
| Count | 打算裂成几发（打几次，进机制） |
| Spin / Orbit | 转不转、绕不绕圈（改怎么飞，进机制） |
| Tags | 贴纸：火、湿、酸… |
| Mult | 临时倍率（双倍会动它） |

### HitEvent — 叫它「出门单」
货箱到达喷射器后，变成一张「打出去的订单」：伤害多少、带不带火、会不会落地留痕、撞到爆不爆。

### RuleVector — 叫它「全厂规章表」
所有基因把规则写进同一张表（双倍、带火、禁止远程…），出门前统一按这张表改订单。

### Tag（标签）— 叫它「贴纸」
贴在货箱、地面、敌人身上的小标记。  
**化学反应** = 看贴纸凑没凑齐：例如「火 + 湿 → 蒸汽」。

### 催化 / 反应表
- **人话：** 一张配方表：「当这些贴纸同时存在时，变成那样」。  
- 表可以一直加新行 = 内容变多；零件不用互相改代码。

### 正交叠乘
- **人话：** 两个效果各干各的，乘在一起。  
- 例：基础散射 2 发 × 双倍 = 4 发；变大也吃双倍。  
- **不需要** 做一张「双倍散射」专用卡。

### 软帽
- **人话：** 叠太多同类规则时，自动打折，防止无限变强到坏掉。  
- 你仍可无限叠，但越叠越「不划算」。

### 正规形
- **人话：** 不管你怎么乱叠基因，系统先整理成一张标准规章表再算，避免互相打架算不清。

### 源 / 汇
- **源：** 发电的格子（线粒体等）。可以有好几个。  
- **汇：** 出门的格子（喷射器等）。可以有好几个。  
- **多条链：** 左边发电养左炮，右边发电养右刺，同时存在。

### 图 / SimGraph
- **人话：** 你的格子 + 箭头，合起来就是一张「路线图」。  
- 程序按路线图运货箱，不是让你玩寻路游戏。

### 管道结算顺序
- **人话：** 货出厂后，按规定步骤盖章：先看能不能远程 → 再延迟 → 再贴元素 → … → 最后和地面贴纸反应。  
- 顺序写死，是为了每次结果一样、好测试。

### ComposeEngine（组合引擎）
- **人话：** 专门负责「运货、改货、出门、贴贴纸反应」的计算器。  
- 不负责画图、不负责摇杆操作；Unity 只负责显示和操作，把结果拿去播动画。

### ArtId
- **人话：** 美术文件的身份证号，例如 `org/mito` = 线粒体那张图。  
- 程序按这个名字找图，不按中文名找。

### DLL / 零 Unity 引用
- **人话：** 规则做成独立工具箱，可以打成库文件；里面不写 Unity 专用代码，以后换引擎也能用。

## 第三章：复玩三轴（人话）

### 轴 A：环境残留 + 地形
- 地上本来就有湿地/油地（地形）。  
- 你打一枪可能留下油渍、酸滴（残留），下一枪或敌人踩上去会再起反应。  
- **好玩在：** 每层地图地面不一样，走位和射击顺序有意义。

### 轴 B：背包逼弃 + 合成
- 东西太多装不下，逼你扔或合成。  
- **好玩在：** 每局留什么都是痛苦又有趣的选择。

### 轴 C：捕食消化
- 打怪不直接给成品，先给生肉，要煮。  
- **好玩在：** 贪吃会撑死/煮爆；耐心煮有好零件。

### 不可逆蜕变（以后再做）
- 某些强化会永久改掉零件，不能变回原样。  
- **好玩在：** 进化分叉，一去不回。

## 第四章：冻结总案里那些「种类」对照

| 总案里的名字 | 你就记 |
|--------------|--------|
| SlotType | 地板种类 |
| Organelle | **器官**（含原膜器、原管壁；装格子或挂箭头） |
| Gene | 全身基因规则 |
| Terrain | 战场地板 |
| Residue | 地上临时痕迹 |
| Status | 敌人/自己身上的状态（燃烧、湿透） |
| Reaction | 贴纸配方表的一行 |
| Reagent | 消化用的生肉碎片 |
| CardMeta | 卡牌封面信息（名字、稀有度、用哪张图） |

**已废除：** MembranePart、EdgeMod（并进器官）。玩家改装只认 **器官 + 基因**。

## 第五章：一个完整小例子（串起来）

1. 你在切片放：**线粒体 →（箭头）→ 散射 →（箭头）→ 喷射器**，空着一格地板是酸沼，箭头从酸沼穿过。  
2. 基因装了：**双倍**。  
3. 开战：线粒体发电 → 货箱路过酸沼沾上酸 → 散射把「发数」变成 2 → 双倍变成 4 → 喷射器射出 4 发带酸的子弹。  
4. 子弹打到湿地：贴纸「酸/火」若再加「湿」→ 查反应表变蒸汽，地上冒蒸汽残留。  
5. 怪死了掉「线粒体碎片」进消化泡，煮好进仓库；仓库满了你得扔一张旧卡。

这就是整套方案在玩什么——**不是名词本身，是这条故事。**

## 第六章：你若只记这些词

1. **切片** = 战场身体改装板  
2. **格子/地板** = 可空，自带地板效果  
3. **器官** = 装格子或挂箭头上的零件（含刺突、绝缘管等）  
4. **箭头** = 能量只能按你画的方向走  
5. **货箱** = 正在被改的那包能量  
6. **基因** = 全厂规章（最多几条）  
7. **仓库** = 限容背包  
8. **贴纸反应** = 火+湿这类组合  

其余黑话都是这些的技术叫法。
