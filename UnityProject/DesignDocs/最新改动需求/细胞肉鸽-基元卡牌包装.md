# 细胞肉鸽：基元卡牌包装（空间邻接 + 双系统版）

> 化学引擎仍是做法 C。  
> 包装：**二维切片 + 玩家自定义有向流向 + 可空放 + 背包/切片双系统合成升级**。  
> **决定：二维；主流有向；不用三维。**

---

## 0. 二维还是三维？

**主游戏用二维**（原型方格四邻；可再换六边形）。  
三维不做核心拓扑（遮挡与操作易劝退）。

---

## 1. 玩家看到的两套系统

| 系统 | 名字（可改） | 作用 |
|------|--------------|------|
| **A. 培养切片** | 细胞蓝图 | 槽位摆放器官；画代谢箭头；战斗时进 ComposeEngine |
| **B. 储备囊** | 背包 / 质粒库 | 暂存拿到的元素；**容量有限**；满了必须丢弃或合成消化 |

```text
奖励/掉落 → 先进入【储备囊】（或可选直接装切片）
                ↓
     装入切片槽  ←→  卸回储备囊
                ↓
         两系统间合成 / 升级
                ↓
     切片上有向流 → ComposeEngine → 战斗生效
```

**空放：** 切片槽 **允许空着**；不强制填满。空槽仍保留槽位被动；主流能量只沿 **玩家画出的有向边** 走（见 §4）。

---

## 2. 三层映射

| 层 | 玩家 | 引擎 |
|----|------|------|
| 元素/卡牌 | 掉落、商店、奖励 | CardDef |
| 实例 | 在囊中或在某槽上 | PartInstance（Location = Bag \| SlotId） |
| 化学基元 | 仅切片上已装备且接入流的才每 Tick 结算 | IModule / IContract / SlotPassive |

**储备囊里的东西不参与战斗化学**（除非某基因写明「囊内被动」——默认不做，防规则爆炸）。

---

## 3. 储备囊（背包系统）

### 3.1 容量与丢弃

- 容量 SoftCap：如初始 **8**，可用扩张卡/事件提高到上限（如 16）  
- 获得新元素时：若 `count >= cap` → **必须** 选：丢弃囊中一件 / 丢弃新件 / 当场合成腾位  
- 不允许静默超容  

### 3.2 可放什么

与切片同类：器官、基因质粒、扩张道具、合成素材等。  
基因若「装备」进核区，仍占 **全局基因槽 k**，并从囊中移除（或变为已装备状态）。

### 3.3 与切片的转移

- **装上：** 囊 → 合法空槽（类型匹配）  
- **卸下：** 槽 → 囊（囊满则无法卸下，需先丢/合成）  
- **空放：** 槽可以一直空；空着就不提供该格 Module，但 `SlotPassive` 仍在  

---

## 4. 流向：玩家自定义有向图（默认）

### 4.1 规则

1. **邻接** = 两格相邻时 **允许连边**（几何前提）  
2. **流向** = 玩家在相邻槽之间画的 **有向箭头**（代谢管）  
3. Packet **只沿箭头** 从源走向汇；**不做无向全扩散**（省不可读性，也更好算）  
4. 箭头 SoftCap：如 `min(活性槽数, 已装器官数) × 系数`  
5. 允许 **多源、多汇、多条并行链**；允许分叉（一出多）与汇合（多进一，经 Merge 语义）  
6. **空槽可被箭头穿过**（仅传包 + 吃槽被动），或规则定为「空槽不可作中继」——原型推荐 **可穿过**，鼓励空放与槽地形成化学  

### 4.2 可选廉价无向（弱）

仅用于：邻格 **tag 催化**（如酸沼烤旁边一格），**不传能量主包**。  
主强度必须来自有向流，避免变回「途中糊放置」。

### 4.3 链怎么来

- 运行时：沿有向边做波前 / 拓扑传播（推荐）  
- 或：对每个 (源→汇) 可达路径预抽成线性列表再 `RunAssembly`  
- **起点不唯一，出口不唯一**；由玩家摆的源/汇器官 + 箭头决定  

```text
玩家：摆器官（可空槽）+ 画箭头
        ↓
有向 SimGraph
        ↓
出口 HitEvent（可多条）
        ↓
线性契约管道（基因等）
        ↓
战斗表现
```

## 5. 槽位：可扩展 + 固定被动 + 可空放

### 5.1 动态扩展

- 扩张卡/事件解锁邻接新槽（禁飞地）  
- 风险槽带负面被动  
- 槽太多 → 维持能耗 SoftCap  

### 5.2 槽类型被动（进化学）

| 槽类型 | 被动例子 | 引擎 |
|--------|----------|------|
| 胞质 | 微导热 | tag |
| 膜缘 | 易湿、减伤 | 弱修正 |
| 核周 | 基因效力 + | gene_potency |
| 分泌腔 | 出口形状/延迟 | 出口 Packet |
| 酸沼 | 过热/酸 tag | 路上改包 |
| 晶格 | 传导损耗 ↓ | 边 η |

空槽：**无 Module，有 Passive**。箭头经过时 `ApplyPassive` 仍执行。

### 5.3 卡与槽

| 卡 | 放入 | 引擎 |
|----|------|------|
| 器官（普通） | 胞质/分泌等（看 AllowedSlotTypes） | IModule·AttachTarget=Slot |
| 器官（膜缘限定） | 仅膜缘，如刺突/粘液/受体 | 同上，限制地板 |
| 器官（管类） | 挂在有向箭头上，如绝缘/过滤/阀 | IModule·AttachTarget=DirectedEdge |
| 基因 | 核区或全局基因栏 | IContract，限 k |
| 扩张/素材 | 一次性或囊内合成材料 | 元规则 |

## 6. 双系统合成与升级

### 6.1 合成台入口

在 **非战斗**（营地/细胞间隙菜单）打开「代谢合成」：

- 材料可来自：**储备囊** 与/或 **切片上已装备**（装备中的可标记为材料，合成后从原位置移除）  
- 产出进入：**指定系统**（默认进囊；囊满则要求改产出到空槽或丢弃）  

### 6.2 配方类型（例子）

| 类型 | 例 | 结果 |
|------|----|------|
| 同种升级 | 聚焦×2 → 聚焦+1 | 更高参的同 TypeId Module |
| 异种合成 | 散射+爆炸素材 → 爆裂散射器 | 新 CardDef |
| 基因重组 | 双倍+燃律素材 → 焦热双倍（仍限 k） | 新 Contract 或升级 |
| 槽改造 | 素材+目标空槽 → 普通胞质变晶格 | 改 SlotType |
| 消化拆解 | 高级器 → 基础素材×n（腾囊位） | 降稀有换容量 |

### 6.3 约束

- 配方数据驱动；**禁止**卡面写死「仅当切片上邻接某物才能合成」（合成是囊/菜单规则；邻接化学留给战斗图）  
- 战斗中默认不可合成（防操作过载）；精英事件可给「应急消化」一次性  

---

## 7. 生效流程（总览）

```text
掉落/商店 → 储备囊（满则丢弃抉择）
    ↔ 装卸 ↔ 切片槽（允许大量空槽）
    ↔ 合成升级（囊↔切片材料）
    → 玩家画有向代谢箭头
    → 战斗 GraphTick / FireFromSinks
    → ComposeEngine → 弹体/反应
```

## 8. 和魔法工艺 / 途中摆放的差异

| 常见做法 | 本包装 |
|----------|--------|
| 法杖瞬时序列 | 持久切片 + **有向管** |
| 无向邻接糊加成 | 主强度靠 **玩家画的流** |
| 只有身上 Build | **囊限容** 逼丢弃与合成决策 |
| 只能装备栏升级 | **双系统** 材料互通合成 |

---

## 9. 最小落地

1. 方格 3×3，可空放；箭头有向；多源多汇  
2. 储备囊容量 8；满员强制丢弃 UI  
3. 装/卸 切片↔囊  
4. 合成先做 2 条：同种升级 + 拆解腾位  
5. 槽类型 3 种；空槽可过管并吃被动  
6. 不做三维、不做无向主扩散
