## 0. 一句话产品

玩家在 **二维方格培养切片** 上放置器官、**自绘有向代谢管**，用 **基因** 改全局规则，在 **战场地形与残留** 上打出可组合的代谢弹；掉落进 **限容储备囊**，可装卸与合成；击杀掉落进 **消化泡** 炼成新器官。

核心爽感：**正交修饰叠乘 + tag 催化 + 每局取舍**，不是法杖搓咒，也不是无向途中糊放置。

## 2. 无限大如何成立（给程序与策划的铁律）

1. **所有战斗效果只读写下列通用容器**（见 §3）：`Packet` / `HitEvent` / `RuleVector` / `TagSet` / `Residue` / `Status`  
2. **新玩法 = 新基元或新反应行**，禁止给旧基元加「若存在某某则」  
3. **正交为默认**：两基元无催化时各自生效（NoOp 催化也是合法结果）  
4. **软帽与冲突代数**只在 `Normalize*`，保证任意叠自洽  
5. **内容表可无限加行**；代码种类（§4）冻结后只许加实例不许加「新职责种类」（若必须加种类 = 新版宪法，另开文档）

## 3. 通用数据宪法（字段冻结）

### 3.1 Packet（代谢包，在有向管上走）

| 字段 | 类型 | 本职 |
|------|------|------|
| `Energy` | float | 可用代谢能 |
| `Heat` | float | 热负荷 |
| `Shape` | enum | Bolt/Beam/Arc/Field/Wave/Spore |
| `Scale` | float | 弹体尺度（变大读此） |
| `Count` | float | 分裂数提示（散射读此；最终取整） |
| `Spin` | float | 自旋/绕转强度 |
| `Orbit` | float | 绕圆半径倾向 |
| `Tags` | TagSet | 元素与行为标签 |
| `Mult` | float | 本包临时倍率（默认 1） |
| `Payload` | dict | 仅扩展；不得替代上表语义 |

### 3.2 HitEvent（出口事件）

| 字段 | 本职 |
|------|------|
| `Damage` / `Heal` / `Poise` | 数值结果 |
| `Delay` | 延迟结算秒 |
| `Burn` / `Wet` / `Shock` / `Acid` / `Oil` | 元素附着量 |
| `Shape` `Scale` `Count` `Spin` `Orbit` | 出口形态/运动机制字段（次数、尺度、轨迹；**不是**「纯 VFX、不结算」——见 `HostApplyContract.md`） |
| `Tags` | 参与世界反应 |
| `LeaveResidue` | 命中/轨迹留下什么 |
| `ExplodeOnHit` | bool+半径参数 |
| `Payload` | 扩展 |

### 3.3 RuleVector（基因/全局正规形）

| 字段 | 本职 |
|------|------|
| `GlobalMult` | 双倍等 |
| `BurnOnHit` `WetOnHit` `ShockOnHit` `AcidOnHit` `OilOnHit` | 出口附着 |
| `DelaySec` | 延偿 |
| `BanRanged` `MeleeMult` | 哑火 |
| `ReflectMode` | none/projectile/melee |
| `ShareStatus` | 共相 |
| `SwarmK` | 寡兵 |
| `Lifesteal` `TakenMult` | 血债 |
| `RageOnce` | 绝境 |
| `GenePotency` | 核周等提供的基因效力 |
| `StackCount` | 软帽用 |
| `Payload` | 扩展 |

软帽：`soft = 1/(1+0.35*max(0,StackCount-1))` 作用于可缩放字段（冻结公式）。

### 3.4 Tag 词表（v1 冻结；只许追加不许改义）

**元素：** `Fire` `Water` `Wet` `Steam` `Shock` `Acid` `Oil` `Ice` `Light` `Dark`  
**行为：** `Charged` `Focused` `Split` `Orbiting` `Explosive` `Melee` `Ranged`  
**槽/地：** `Cytoplasm` `Membrane` `Perinuclear` `Secretory` `AcidFen` `Crystal`  
**世界：** `SugarFilm` `SaltFrost` `Shadow`  
**单位状态：** `Burning` `Soaked` `Oiled` `Stunned` `Frozen`

### 3.5 结算顺序（冻结）

**切片图 Tick：**  
源注入 → 沿有向边传包 → 每节点 `SlotPassive` → `Module.Step` → 汇出 HitEvent  

**契约管道（每出口）：**  
1 BanRanged → 2 DelayWrap → 3 ElementAttach → 4 Reflect → 5 Share → 6 SwarmScale → 7 Commit → 8 Lifesteal → 9 RageCheck → 10 HeatSettle → 11 WorldTagReactions

## 4. 基元种类总表（种类冻结）

下列 **9 种** 是全部参与或支撑化学的种类。美术与程序必须按种类建目录。

| 种类代码 | 中文 | 本职一句话 | 战斗中是否结算 |
|----------|------|------------|----------------|
| `SlotType` | 槽位地形 | 格的固定被动，改过路 Packet | 是（过管时） |
| `Organelle` | **器官** | 装在格子或有向管上的 Module；含原膜器/管壁 | 是 |
| `Gene` | 基因 | 写入 RuleVector | 是（全局） |
| `Terrain` | 战场地形 | 格子固有 Tag | 是（接触时） |
| `Residue` | 残留 | 寿命制 Tag 堆 | 是 |
| `Status` | 单位状态 | 挂在单位上的 Tag+量 | 是 |
| `Reaction` | 催化行 | tag 集合→结果（数据） | 是 |
| `Reagent` | 消化试剂 | 限时炼成器官 | 非即时战斗（消化 Tick） |
| `CardMeta` | 卡牌外壳 | 名字稀有度 ArtId；不直接算化学 | 否 |

**玩家对外只宣传 2 种可收集改装物：器官、基因。**

**禁止**再发明「既是基因又是器官」的混合种类；一张卡可绑定器官 + 解锁 Reaction，但种类边界清晰。

**已废除种类（勿再实现）：** `MembranePart`、`EdgeMod`。

## 5. 各类本职详规 + 美术规格

### 5.1 SlotType（槽位地形）

**本职：**  
- 不提供主动攻击；  
- 在 Packet 经过或驻留时调用 `ApplyPassive(Packet, ctx)`；  
- 可微调 `GenePotency` 等全局（核周）；  
- 空槽也生效。

**动态机制（强）：**  
被动强度可随 `Heat`/`Energy` 过路量变化（例：酸沼过热越高腐蚀越强），形成自反馈，但仍只改通用字段。

**v1 槽位实例（冻结列表）：**

| Id | 名称 | 本职效果 | ArtId |
|----|------|----------|-------|
| `slot_cytoplasm` | 胞质 | +tag Cytoplasm；Heat 传导微增 | `ui/slot/cytoplasm` |
| `slot_membrane` | 膜缘 | +Membrane；WetOnHit 微增；承伤修正由宿主读 TakenMult 微变 | `ui/slot/membrane` |
| `slot_peri` | 核周 | GenePotency += 0.1 | `ui/slot/perinuclear` |
| `slot_secretory` | 分泌腔 | 出口 Delay+0.15 或 Shape 倾向 Spore | `ui/slot/secretory` |
| `slot_acidfen` | 酸沼 | 过路 +Acid，Heat+；邻格弱无向 tag 渗 Acid（弱） | `ui/slot/acidfen` |
| `slot_crystal` | 晶格 | 边损耗 η 提高（Energy 少衰减） | `ui/slot/crystal` |

**美术：** 俯视菱形/方格底板 256×256；颜色区分类型；需 `empty` 与 `occupied` 两态遮罩；扩展锁定态 `locked`。

### 5.2 Organelle（器官）— 唯一「装上身体」的战斗零件种类

**本职：** `IModule.Step(Packet)→Packet`；可持有内部 state。  

**安装目标（数据字段，冻结）：**

| AttachTarget | 含义 | 例 |
|--------------|------|----|
| `Slot` | 装进格子；用 `AllowedSlotTypes` 限制地板 | 线粒体、刺突（仅膜缘） |
| `DirectedEdge` | 装在玩家画的有向管上，传包时改这条边 | 绝缘管、过滤管、单向阀 |

**角色标签（每器必选其一为主）：** `Source` / `Relay` / `Transform` / `Sink` / `Edge`

**程序接口提示：**

```csharp
enum AttachTarget { Slot, DirectedEdge }
OrganelleDef {
  Id, Role, AttachTarget,
  AllowedSlotTypes, // AttachTarget=Slot 时用；膜缘器官 = [slot_membrane]
  // Step 仍只改 Packet / 边上下文通用字段
}
```

传边时：先跑该边上的 Edge 器官，再进入目标格的 SlotPassive + Slot 器官。

**美术：**  
- 一律 `org/{id}.png`，512×512 透明底俯视  
- 膜缘类可偏「边饰」构图，程序旋转四方  
- 管类可偏「箭头段」构图，仍归 org 目录，禁止再开 `mem/`、`edge/` 种类目录  
- 槽内嵌 128×128 可选；过热变体可选  
- 禁止法术符文风

## 6. 双系统与合成（支撑化学的经济层）

| 规则 | 冻结内容 |

## 7. 有向图与空放（冻结操作语义）

1. 四邻可连；玩家画箭头；Packet 只走箭头  
2. 多源多汇合法  
3. 空槽可中继：只跑 SlotPassive  
4. 箭头 SoftCap = `min(ActiveSlots, max(1,PlacedParts)) * 2`（可配置常数，语义冻结）  
5. 弱无向：仅 AcidFen 等对邻格写 tag，不传 Energy  
6. **管类器官**（`AttachTarget=DirectedEdge`）装在箭头上；传包时先跑管器官再进目标格
