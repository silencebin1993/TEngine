## 冲突判定

- 新 GDD 规定“做成什么、玩家如何体验”；专项文档规定“保留系统内部如何工作”。
- 旧代码或旧文档已经存在，不代表其产品假设继续有效。
- 遇到冲突不得自行折中：先记录冲突，再按 GDD 和里程碑的迁移任务处理。
- 不删除历史完成事实；但历史事实不能反向否决已批准的新产品方向。
