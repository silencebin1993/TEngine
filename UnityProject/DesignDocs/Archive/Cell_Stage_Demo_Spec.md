# 文明织造 细胞阶段 Demo 设计规格

> 创建日期：2026-08-04
>
> 本文档替代原 `First_Playable_Spec.md` 中“细胞 -> 器官/组织 -> 生物”的三阶段 demo 定位。当前 Demo 只验证一个目标：细胞阶段本身能否支撑 1 小时 roguelite 构筑体验。
>
> 开发任务拆解见 `Cell_Stage_Demo_Task_Breakdown.md`。

## 1. 新 Demo 定位

当前 Demo 不再追求跨阶段继承，不进入器官/组织阶段，也不进入生物阶段。

玩家始终扮演一个细胞，在微观生态中吞噬、逃亡、突变、分裂、寄生、放电、筑巢、污染环境，并通过一轮又一轮细胞内进化选择形成不同 build。

一句话定位：

`在一小时的细胞生态战场中，通过吞噬与突变卡牌，把一个弱小细胞培养成能够改造整片微观生态的异化生命体。`

## 2. 产品承诺

本 Demo 必须让玩家明白：

- 细胞阶段不是教程阶段，而是一个可以独立成立的完整 roguelite 玩法。
- 进化不是“进入下一阶段”的按钮，而是局内构筑节点。
- 每个内部时期都不止一次构筑选择。玩家通过积累 `进化能`（等价于细胞阶段经验）反复升级选卡，小阶段推进主要负责解锁新卡池、敌人和生态事件。
- 同样是一局细胞阶段，不同卡牌组合应形成明显不同的生存方式。
- 一小时局内体验要从“求生”逐渐走向“支配生态”。

## 3. 设计支柱

- `吞噬是核心动词`
  玩家主要通过吞噬获取资源、改变体型、触发突变、打开下一轮选择。

- `进化是局内构筑`
  进化节点只改变细胞能力、生态关系和卡牌组合，不切换到其他阶段。

- `肉鸽来自机制组合`
  卡牌应优先改变行动后果、资源转化、敌我关系和环境规则，少做纯数值加成。

- `一小时必须有阶段感`
  虽然不进入新大阶段，但细胞阶段内部需要分成多个生态时期，每个时期有新敌人、新事件和新卡池。

- `内容巨大但系统复用`
  大量内容优先通过卡牌、词缀、事件和敌人行为参数组合产生，不为每张卡制作独立复杂系统。

## 4. 非目标

当前 Demo 不做：

- 器官/组织阶段独立菜单
- 生物阶段可玩关卡
- 文明、大明、废土、星海、宇宙终局
- 复杂剧情分支
- 多角色初始职业
- 完整局外养成
- 长篇教程

## 5. 单局目标时长

目标单局时长：约 60 分钟。

推荐阶段节奏：

| 时间 | 内部时期 | 玩家体验 | 核心压力 |
|---|---|---|---|
| 0:00-8:00 | 原生漂流期 | 熟悉移动、吞噬、体积判定 | 大型威胁、危险区 |
| 8:00-18:00 | 初次突变期 | 获得第一批突变卡，形成方向 | 食物竞争、追猎者 |
| 18:00-30:00 | 生态争夺期 | build 开始联动，敌人出现特化行为 | 群体围堵、资源稀缺 |
| 30:00-45:00 | 异化扩张期 | 玩家可污染环境、筑巢、召唤或连锁放电 | 精英细胞、生态反扑 |
| 45:00-58:00 | 微观灾变期 | 高强度事件轮换，build 进入完全体 | 多源压力同时出现 |
| 58:00-60:00 | 原核霸主战 | 最终压力测试 | 首领、环境崩坏 |

## 6. 新核心循环

短循环：

`移动 -> 判断能否吞噬 -> 吞噬/规避/反击 -> 吸收营养质与进化能碎片`

中循环：

`积累进化能 -> 升级 -> 3 选 1 突变卡 -> 改变玩法规则 -> 继续积累下一次升级`

长循环：

`选择路线 -> 多次升级构筑 -> 击败时期事件/精英 -> 解锁新卡池 -> 进入下一生态时期 -> 完成 60 分钟生存与霸主战`

## 7. 资源设计

| 资源 | 用途 | 来源 | 消耗 |
|---|---|---|---|
| `生命值` | 生存 | 吞噬、再生、部分卡牌 | 受击、毒区、透支卡 |
| `营养质` | 局内货币，用于刷新、购买临时补给、修复组织 | 食物、尸体、事件 | 商店、事件、修复 |
| `突变质` | 稀有构筑资源，用于升级卡牌或锁定路线 | 精英、事件、特殊食物 | 强化突变、移除负面 |
| `进化能` | 细胞阶段经验条，满后升级选卡 | 吞噬、击杀、完成事件、拾取进化能碎片 | 达阈值后清空当前条并提高下次阈值 |
| `污染度` | 高风险强度资源，越高越强也越危险 | 异化卡、污染事件 | 触发灾变、解锁高阶卡 |

关键调整：

- `进化能` 不再是下一阶段门票，而是细胞阶段的经验值。
- 每次 `进化能` 达阈值，只触发一次局内突变选择。
- 玩家可以在同一细胞阶段获得多次进化。

## 8. 进化节点规则

细胞阶段的进化节点采用“经验升级”逻辑，而不是“时期节点奖励”逻辑。

推荐升级频率：

- 0 到 10 分钟：约每 1 到 2 分钟升级一次，帮助玩家快速拿到核心卡。
- 10 到 30 分钟：约每 2 到 3 分钟升级一次，让 build 开始成型。
- 30 到 50 分钟：约每 3 到 4 分钟升级一次，主要通过精英、事件和高风险目标补充额外选择。
- 50 到 60 分钟：升级频率降低，但给终局前补强、精英奖励或原核遗产选择。

触发方式：

- 拾取或吸收 `进化能碎片` 后使经验条达到当前阈值
- 吞噬高价值目标直接获得大量进化能
- 击败精英细胞
- 完成特殊生态事件
- 进入新内部时期时可以给予一次保底选择，但这不是唯一构筑来源

选择形式：

- 常规升级：3 选 1
- 精英进化：4 选 1，至少 1 张稀有卡
- 污染进化：3 选 1，卡强但附带代价
- 修复进化：2 选 1，用于低血或弱构筑补偿

## 8.1 每个内部时期的选卡密度

| 内部时期 | 推荐常规升级次数 | 额外选择来源 | 目标卡牌总量 |
|---|---:|---|---:|
| 原生漂流期 | 3-4 次 | 第一次保底升级 | 3-4 张 |
| 初次突变期 | 4-5 次 | 首个小精英或事件 | 7-9 张 |
| 生态争夺期 | 4-5 次 | 精英奖励、事件奖励 | 12-15 张 |
| 异化扩张期 | 3-4 次 | 稀有卡池、路线强化 | 16-19 张 |
| 微观灾变期 | 2-3 次 | 异化卡、终局补强 | 19-22 张 |
| 原核霸主战 | 0-1 次 | 战前最终选择 | 20-24 张 |

设计目标：

- 一小时完整局结束时，玩家通常拥有 20 到 24 张卡。
- 前 10 分钟必须快速给卡，让玩家尽早感到 build 在生长。
- 中后期不靠频繁普通升级堆内容，而靠精英、事件、稀有卡和卡牌联动改变体验。

## 8.2 进化能碎片与经验来源

进化能不应只用 UI 数字增长表现，建议有可见拾取物或吸收反馈。

来源建议：

- 吞噬普通食物：少量进化能。
- 吞噬危险目标：中量进化能。
- 击杀追猎者：掉落进化能碎片。
- 击败精英：直接触发一次精英进化，并掉落突变质。
- 完成生态事件：给大量进化能或直接给一次选择。
- 高风险目标：例如带异常的细胞，吞噬后给额外进化能但附带副作用。

阈值建议：

- 第 1 次升级很快，约 60 到 90 秒。
- 第 2 到 5 次升级保持较快节奏。
- 第 6 次后逐步提高阈值，避免玩家后期只是在连续暂停选卡。
- 精英和事件奖励不受常规升级阈值限制。

## 8.3 卡池解锁规则

内部时期主要控制卡池解锁，而不是只发一次卡。

| 解锁节点 | 新增内容 |
|---|---|
| 原生漂流期 | 基础吞噬、基础机动、基础生存卡 |
| 初次突变期 | 三条首轮路线核心卡 |
| 生态争夺期 | 稀有卡、精英奖励卡、跨路线联动卡 |
| 异化扩张期 | 电化连锁、尸体联动、强控制卡 |
| 微观灾变期 | 异化卡、污染代价卡、终局补强卡 |
| 原核霸主战前 | 原核遗产或最终强化卡 |

## 9. 卡牌稀有度

| 稀有度 | 定位 | 设计要求 |
|---|---|---|
| 普通 | 建立基础循环 | 效果清晰，可直接改变一次行动后果 |
| 稀有 | 形成路线联动 | 至少能与两类系统产生组合 |
| 异化 | 高风险高收益 | 强机制变化，附带副作用或生态反扑 |
| 原核遗产 | 核心 build 定义卡 | 一局只出现少量，能改变整局策略 |

## 10. 路线原型

### 10.1 吞噬扩张

关键词：变大、撕裂、吞噬阈值、尸体回收、压迫。

核心体验：玩家通过近战、破体和尸体二次吞噬滚雪球，越来越像食物链顶端。

### 10.2 机动猎食

关键词：冲刺、残影、标记、穿体、风筝。

核心体验：玩家靠走位和冲刺把危险目标切成可处理的猎物。

### 10.3 电化统治

关键词：放电、导电、连锁、电荷、过载。

核心体验：玩家用电荷网络控制空间，从单体点杀走向全屏连锁。

### 10.4 孢子繁殖

关键词：孢子、分裂、召唤、感染、群体。

核心体验：玩家不只强化自己，而是制造附属体和感染源，让战场替自己工作。

### 10.5 菌毯筑巢

关键词：领地、菌毯、锚点、回复、改造地形。

核心体验：玩家逐渐把地图局部变成自己的生态位，形成阵地战。

### 10.6 异化污染

关键词：污染度、代价、灾变、强突变、不可控。

核心体验：玩家获得强力机制，但让生态压力变得更凶。

## 11. 首发大卡池

以下卡牌用于建立“大内容池”。实际首轮开发可以先取其中 20 到 30 张。

### 11.1 吞噬扩张卡

| 卡牌 | 稀有度 | 功能说明 | 联动方向 |
|---|---|---|---|
| `裂齿口器` | 普通 | 近战命中施加 `破体`，降低目标被吞噬的体积门槛 | 吞噬、处决 |
| `腐解胃袋` | 普通 | 敌人死亡后留下可二次吞噬的组织残块 | 尸体、电链、筑巢 |
| `贪食腺` | 普通 | 连续吞噬形成连吃层数，断连后清空 | 高速吞噬 |
| `反刍囊` | 普通 | 吞噬后吐出残渣，残渣吸引附近小型生物 | 聚怪、陷阱 |
| `寄生吻器` | 稀有 | 无法直接吞噬的中型目标可被寄生，持续削弱体积判定 | 风筝、消耗 |
| `囤积脂肪层` | 稀有 | 溢出营养转为储备组织，低血时自动消耗 | 生存、透支 |
| `酸蚀消化液` | 稀有 | 吞噬失败也会腐蚀目标，使其逐渐变成可吞噬状态 | 大型猎物 |
| `分食囊` | 稀有 | 大型目标死亡时裂成多个小食物块 | 连吃、召唤 |
| `吞噬回响` | 稀有 | 每次吞噬强化下一次近战/冲刺/放电 | 跨路线 |
| `食物链宣告` | 异化 | 处决目标后短时间内同类敌人恐惧逃散，但精英会更快锁定你 | 高压清场 |

| 卡牌 | 稀有度 | 功能说明 | 联动方向 |
|---|---|---|---|

| `穿体脉冲` | 普通 | 冲刺穿过敌人时附加导电或易伤种子 | 电化、近战 |
| `回折腱索` | 稀有 | 冲刺撞到障碍会反弹并获得二次位移 | 高操作 |

### 11.6 异化污染卡

| 卡牌 | 稀有度 | 功能说明 | 联动方向 |
|---|---|---|---|
| `污染腺体` | 普通 | 释放技能会积累污染度，污染度提高部分卡牌效果 | 高风险成长 |
| `危险食谱` | 稀有 | 吞噬异常敌人获得额外收益，但继承一种短暂副作用 | 异常吞噬 |
| `组织透支` | 稀有 | 立刻获得大量营养质或进化能，之后进入偿还期 | 爆发 |
| `蜕皮赌博` | 稀有 | 主动脱壳清除异常并重置部分冷却，但短时间防御降低 | 反打 |
| `高温代谢` | 异化 | 使用技能升温，温度越高越强，过热会自伤 | 输出代价 |
| `灾厄蜕变` | 异化 | 每次濒死复苏获得强突变，同时提升后续生态压力 | 翻盘 |
| `异化突变` | 原核遗产 | 每次进化随机强化一个系统并弱化另一个系统 | 变异局 |
| `原核王冠` | 原核遗产 | 污染度满时不再触发失败，而是进入霸主形态，持续消耗生命 | 终局爆发 |

## 12. 主动技能池

主动技能是卡牌之外的“可操作能力”。每局建议最终拥有 2 到 4 个主动技能。

| 技能 | 功能 | 适配路线 |
|---|---|---|
| `冲刺` | 快速位移，基础保命手段 | 全部 |
| `放电` | 中距离攻击，可触发导电 | 电化统治 |
| `酸雾` | 喷出持续伤害雾区 | 吞噬/污染 |
| `脱壳` | 留下旧壳诱敌，自己短暂无敌 | 机动/硬壳 |
| `孢子爆发` | 向四周释放孢子 | 孢子繁殖 |
| `筑巢` | 放置巢点或菌毯核心 | 菌毯筑巢 |
| `寄生` | 标记中型目标，持续削弱 | 吞噬/孢子 |
| `电场锚定` | 放置导电节点 | 电化/菌毯 |
| `恐惧分泌` | 逼退小型敌人 | 生存 |
| `过载` | 强化所有电系效果，结束后虚弱 | 电化/污染 |

## 13. 被动词缀池

被动词缀用于快速扩大内容量，可以附加到卡牌或事件奖励上。

| 词缀 | 效果方向 |
|---|---|
| `增殖` | 生成更多附属体或残块 |
| `导电` | 能与电系效果联动 |
| `腐蚀` | 持续削弱体积、护壳或速度 |
| `回流` | 返还体力、冷却或营养 |
| `裂变` | 效果结束时生成次级效果 |
| `拟态` | 复制上一次触发的弱版本 |
| `饥饿` | 低资源时更强 |
| `稳态` | 静止或筑巢时更强 |
| `过载` | 强化效果但带自损或冷却 |
| `共生` | 附属体越多，本体越强 |

## 15. 生态事件池

每 6 到 10 分钟触发一次生态事件，作为一小时局内的节奏变化。

| 事件 | 效果 | 奖励 |
|---|---|---|
| `营养潮汐` | 地图出现大量食物，但大型威胁同步增加 | 营养质 |
| `酸雨漂流` | 随机区域持续腐蚀 | 稀有突变质 |
| `低氧窗口` | 敌我移动变慢，吞噬收益提高 | 进化能 |
| `孢子爆季` | 孢子类敌人与资源同时出现 | 孢子卡概率提升 |
| `电荷风暴` | 地图生成导电区 | 电化卡概率提升 |
| `巢区塌陷` | 旧安全区失效，迫使迁移 | 高级卡选择 |
| `污染裂隙` | 异化卡出现率提高，但污染度上升 | 异化卡 |
| `原核遗响` | 出现一次原核遗产卡选择 | 高阶构筑 |

## 16. 一小时局内奖励节奏

建议一局至少提供：

- 16 到 20 次常规升级选卡
- 3 到 5 次精英奖励选择
- 2 到 3 次生态事件奖励
- 1 次 45 分钟后的原核遗产选择
- 1 次终局前补强选择

玩家最终应该拥有：

- 20 到 24 张已生效卡牌
- 2 到 4 个主动技能
- 1 到 2 个路线核心机制
- 1 个明显副作用或污染代价

## 17. Demo 文案方向

整体文案从“进化到下一阶段”改为“在细胞内部继续突变”。

### 17.1 主菜单文案

标题：

`细胞纪元 Demo`

副标题：

`从一个漂流细胞开始，在一小时内吞噬、突变、筑巢，成为这片微观海域的原核霸主。`

### 17.2 进化节点文案

标题：

`细胞内进化`

按钮：

`吸收突变`

### 17.3 时期切换文案

原生漂流期：

`你仍只是水流中的一点微光。先学会吞噬，再学会不被吞噬。`

初次突变期：

`细胞膜开始记住危险。每一次吞噬都在把你推向某种形态。`

生态争夺期：

`这片水域不再只是食物场。其他生命也在学习你的节奏。`

异化扩张期：

`你开始改变周围的环境。水流、尸体、菌毯和电荷都可以成为器官的延伸。`

微观灾变期：

`生态正在反扑。你已经不是猎物，但还不是唯一的答案。`

原核霸主战：

`这片微观海域只允许一个意志留下。`

## 19. 首轮文案落地优先级

第一优先级：

- 新 Demo 定位
- 1 小时局内节奏
- 进化节点文案
- 20 到 30 张细胞卡牌
- 5 个普通敌人
- 3 个精英敌人

第二优先级：

第三优先级：

- 局外解锁

- 更多首领
- 复杂事件链

## 20. 当前结论

新的 Demo 应该停止把细胞阶段当作三段继承链的第一段，而是把它当作一个完整游戏模式。

进化按钮的语义也要改变：

- 旧语义：达到门槛后进入器官/组织阶段。
- 新语义：达到门槛后在细胞阶段内获得一次突变选择。

只要这个方向成立，后续每个大阶段都可以按“一小时可独立成立”的标准继续扩展；但当前 Demo 只需要把细胞阶段做深，先证明“单阶段 roguelite 足够好玩”。
