# problem_2026-08-13 — HostApplyContract「纯表现」误导

## 问题现象

Preflight 将 `HitEvent.Count`/`Scale`/`Spin`/`Orbit` 判为「纯表现层、不影响结算」，与宪法（修饰轴正交进机制）及 story-004 Required（多段/半径）冲突；若 Worker 照做会把组合装成「假皮肤」。

## 文档位置

- `ComposeEngine/docs/HostApplyContract.md` 旧「可忽略（纯表现层参数）」整节（已删改）
- `DesignDocs/最新改动需求/代谢切片-冻结总案-基元与美术.md` §3.2 旧「弹体表现参数」措辞（易被读成不结算）
- `ComposeEngine` 模块注释：`Grow`「渲染/碰撞」、`OrbitSpin`「给宿主渲染层用」
- `production/session-state/preflight-decisions.md` D6（保留作史，已追认废弃口径）

## 正确 API / 语义

- `Count`：Multiplicity，有 Damage 时 `max(1, round(Count))` 次结算
- `Scale`：缩放命中/范围半径（可同步白模）
- `Spin`/`Orbit`：Motion 轴；可 stub，禁止「永不进机制」
- 真·VFX（闪光/拖尾/镜头）走 Presenter，不占用上述字段
